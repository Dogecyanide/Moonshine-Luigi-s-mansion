# Susamune V2.0.0 "Ghosts of Delfino" Pre-release 10 Testing / テストガイド

## English

### Installation

1. Back up the current launcher folder and `susamune.ini`.
2. Install all eight PR10 ZIP files together and preserve `theme` and
   `susamune_ghosts`.
3. Confirm both Homebrew Channel and the launcher show Pre-release 10.

Run the focused PAL cases first, repeat the core pair on JP, then do a US smoke
test when possible.

### 1. Direct secret Watch 2

Use the known PAL pairs:

- Personal 01 + 02: Bianco 3 Secret
- Personal 03 + 04: Sirena 2 Secret

For each pair, test both Ghost appearance choices.

Expected: the secret loads, both runners appear on their recorded QFT, and
Mario is invisible and cannot be controlled. Open the Ghosts tab briefly and
record the exact Target text. A healthy live pair says `Watching 2 (2/2)`;
`1/2` is valid only where one recording has not started or has already ended.
Persistent `Watch 2 loading` or `Watching 2 (0/2)` is a failure and must be
reported exactly.

### 2. Parent-to-secret Watch 2

Use Personal 09 + 10, the two-segment Bianco 3 routes.

1. Confirm both runners are visible and QFT-synchronised in Bianco.
2. Let the invisible anchor enter the secret naturally.
3. Confirm both runners return in the child segment, remain aligned to the
   recorded absolute QFT, and Target becomes `Watching 2 (2/2)`.
4. Test B and Start once during a transition and once in the secret. Normal
   visible Mario must be restored.

### 3. Locked regressions

1. Re-test Watch 1 with Personal 01 and Personal 09. Direct-secret and
   parent-to-secret QFT synchronisation must remain unchanged.
2. Re-test a normal-level Watch 2 pair and Race. Both models, opacity, end
   reload, and B/Start exit must still work.
3. Toggle Ghost Display Off or Disable Warps during Watch and confirm a visible,
   controllable Mario returns without stale observer state.

### 4. Library ranges

1. Confirm Personal headers 01-10 through 41-45 and Imported 01-10/11-12.
2. Up/Down must never select a header.
3. C-stick Left/Right must cycle range starts in normal browsing and while
   choosing ghost 2. A must still activate the highlighted real row.
4. Smoke-test protected PB save/delete and imported selection to confirm slot
   numbers did not move.

### 5. Safety smoke tests

- Retail Shine Select: Bianco 4/5 and Pianta 5.
- Protected PB Save/Discard, instant restart, Warp Wheel, and Exit Area.
- Crash-report rotation remains available at launcher-root
  `susamune_crash_a/b.txt` plus matching `.bin` files.

## 日本語

### インストール

1. 現在の launcher フォルダーと `susamune.ini` をバックアップします。
2. PR10 ZIP の 8 ファイルを必ず一緒に導入し、`theme` と
   `susamune_ghosts` を保持します。
3. Homebrew Channel と launcher の両方が Pre-release 10 を表示することを
   確認します。

まず PAL の重点項目を実行し、主要な組み合わせを JP でも繰り返してください。
可能なら US でもスモークテストを行います。

### 1. Secret 直接 Watch 2

既知の PAL 組み合わせを使用します。

- Personal 01 + 02: Bianco 3 Secret
- Personal 03 + 04: Sirena 2 Secret

各組み合わせを両方の Ghost appearance で確認します。

Secret 読み込み後、2 体が記録 QFT に表示され、Mario が透明かつ操作不能なら正常です。
Ghosts タブを短時間開き、Target の文字列をそのまま記録してください。正常な 2 体再生は
`Watching 2 (2/2)` です。`1/2` は片方の記録開始前・終了後だけ正常です。
`Watch 2 loading` または `Watching 2 (0/2)` が継続する場合は、文字列をそのまま
報告してください。

### 2. 親ステージから Secret の Watch 2

2 セグメントの Bianco 3 である Personal 09 + 10 を使用します。

1. Bianco 内で 2 体が表示され、QFT に同期することを確認します。
2. 透明なアンカーが自然に Secret へ入るまで待ちます。
3. 子セグメントで 2 体が戻り、記録時の絶対 QFT 同期を維持し、Target が
   `Watching 2 (2/2)` になることを確認します。
4. 遷移中と Secret 内で B / Start 終了を試します。通常の表示された Mario が
   必ず復元される必要があります。

### 3. 固定済み機能の回帰

1. Personal 01 と 09 で Watch 1 を再確認します。Secret 直接と親から Secret の
   QFT 同期が変化してはいけません。
2. 通常ステージの Watch 2 と Race を再確認します。両モデル、不透明度、終了後の
   再ロード、B / Start 終了が動作することを確認します。
3. Watch 中に Ghost Display Off または Disable Warps を切り替え、observer 状態が
   残らず、表示された操作可能な Mario に戻ることを確認します。

### 4. ライブラリ範囲

1. Personal 01-10 ～ 41-45、Imported 01-10 / 11-12 の見出しを確認します。
2. 上下操作で見出し自体が選択されてはいけません。
3. 通常一覧と 2 体目選択で、C スティック左右が各範囲先頭へ移動し、A が実際の
   選択行を実行することを確認します。
4. 保護 PB の保存・削除と Imported 選択を簡単に確認し、slot 番号が変わっていない
   ことを確認します。

### 5. 安全性スモークテスト

- retail Shine Select の Bianco 4/5 と Pianta 5
- 保護 PB の Save / Discard、instant restart、Warp Wheel、Exit Area
- launcher root の `susamune_crash_a/b.txt` と対応する `.bin` のローテーション
