# V2.0.0 "Ghosts of Delfino" Pre-release 7

## English

Pre-release 7 is a focused ghost-system stabilization build. It fixes the
retail Shine Select crash, removes the late start from Watch, and turns PB
protection into a save-first flow. It does not add the planned Records or
achievement content yet.

### Retail Shine Select safety

- Fixed a stage-lifetime alias that occurred only after retail Shine Select.
  Sunshine can allocate a new `TMarDirector` at the same address as the old
  one before asynchronous stage setup has finished. The ghost recorder could
  mistake that address match for a live stage and follow Mario or camera
  pointers that Shine Select had already overwritten.
- Ghost recording and visual fallback now pause until the running context is a
  fully initialized stage. Both visual flags are hidden during selector and
  load frames, while the pending route and recording remain intact for the
  destination.
- The memory reserve, savestate format, QFT code, and ghost file format are
  unchanged.

### Watch timing

- Watch and Watch 2 automatically use Sunshine's normal Stage Intro Skip path
  for viewer-owned stage entries. Secret-stage entrance scenes no longer wait
  for player input.
- Removed the extra 30-frame camera-settle hold. Playback now starts after the
  existing route-validation frame instead of several seconds late.
- The viewer override does not change the persisted Stage Intro Skip setting
  and is removed before the final playable reload.
- Camera framing for two runners that are extremely far apart remains a known
  retail-camera limitation; this build does not add an unsafe custom camera.

### PB ghost protection

- The protection prompt now uses `A: Ghosts / Save` and
  `B: Discard & continue`.
- A opens a save confirmation tied to the exact protected PB. The original
  restart, warp, IL start, savestate load, Exit Area, title exit, or natural
  departure remains suspended until a matching successful storage ACK.
- Two protected PBs are handled one at a time. If all 45 personal slots are
  full, the protected flow can explicitly delete a chosen safe personal slot,
  refresh the catalog, and save into the new empty slot. It never overwrites a
  ghost silently.
- Canceling or a storage error returns to protection with the PB and pending
  action intact.

### Compatibility

- Existing V3 `.smsghost` files remain compatible; no library reset is needed.
- Settings, binds, PBs, Records, achievements, progress, panorama, and
  `bgm.mp3` remain compatible.
- Ghost sample cadence, QFT timing, and result handling are unchanged.

## 日本語

Pre-release 7 は ghost system の stabilization に集中した build です。retail Shine Select
crash、Watch の遅い開始、PB protection の save-first flow を修正します。予定している
Records／achievement content は、ghost validation 完了後に追加するため、この build には
含まれません。

### Retail Shine Select safety

- retail Shine Select 後だけ発生する stage-lifetime alias を修正しました。async stage setup
  完了前に、新しい `TMarDirector` が古い director と同じ address に allocation されることが
  あります。ghost recorder は address 一致を live stage と誤認し、Shine Select が既に
  overwrite した Mario／camera pointer を参照する可能性がありました。
- running context が fully initialized stage になるまで recording と visual fallback を pause
  します。selector／load frame では両方の visual flag を hidden にしますが、pending route と
  recording は destination のために保持します。
- memory reserve、savestate format、QFT code、ghost file format は変更していません。

### Watch timing

- Watch／Watch 2 の stage entry では、Sunshine の通常の Stage Intro Skip path を viewer 用に
  自動で使用します。secret-stage entrance scene は player input を待ちません。
- 追加されていた 30-frame camera-settle hold を削除しました。数秒遅れて開始せず、既存の
  route-validation frame 後に playback を開始します。
- viewer override は persisted Stage Intro Skip setting を変更せず、最後の playable reload
  前に解除されます。
- runner 2 人が非常に離れた場合の framing は retail camera の既知の limitation です。この
  build では危険な custom camera を追加しません。

### PB ghost protection

- protection prompt を `A: Ghosts / Save`、`B: Discard & continue` に変更しました。
- A は exact protected PB に結び付いた save confirmation を開きます。matching storage ACK が
  success するまで、元の restart、warp、IL start、savestate load、Exit Area、title exit、
  natural departure は suspended のままです。
- protected PB が 2 つある場合は 1 つずつ処理します。personal slot 45 個がすべて full の
  場合、safe personal slot を明示的に delete、catalog refresh、新しい empty slot へ save
  できます。ghost を silent overwrite しません。
- cancel／storage error の場合は PB と pending action を保持したまま protection に戻ります。

### Compatibility

- 既存 V3 `.smsghost` file は互換です。library reset は不要です。
- settings、binds、PB、Records、achievements、progress、panorama、`bgm.mp3` は互換です。
- ghost sample cadence、QFT timing、result handling は変更していません。
