# Susamune V2.0.0 "Ghosts of Delfino" Pre-release 6 Testing / テストガイド

## Purpose / 目的

PR6 is a hardware-safety and viewer build. The decisive gates are the fresh-boot
Shine Select crash path, the delayed PB confirmation, and the new route viewer
with Shadow Mario and Piantissimo.

PR6 は hardware-safety と viewer の build です。fresh-boot Shine Select crash、遅延した
PB confirmation、Shadow Mario／Piantissimo route viewer が決定的な gate です。

## Hard safety rules / 必須の安全規則

- Back up the complete PR5 launcher app, `susamune_ghosts`, `susamune.ini`, PBs,
  Records, achievements, and progress before copying PR6.
- Keep QFT visible during timing tests. Any timing/result difference is a release
  blocker.
- Stop after a white screen, looping crash sound, input-dead screen, corrupted
  camera or Mario state, persistence corruption, or an unbounded load. Record
  region, disc ID, stage, exact action, and last visible message.
- Homebrew Channel must show `Susamune Launcher SIGMA` and
  `V2.0.0 "Ghosts of Delfino" Pre-release 6`.

- PR6 を copy する前に、PR5 launcher app、`susamune_ghosts`、`susamune.ini`、PB、
  Records、achievements、progress を完全に backup してください。
- timing test 中は QFT を表示します。timing／result の差は release blocker です。
- white screen、looping crash sound、input-dead screen、camera／Mario state の破損、
  persistence corruption、unbounded load があれば中止し、region、disc ID、stage、正確な
  action、最後の表示を記録します。
- Homebrew Channel には `Susamune Launcher SIGMA` と
  `V2.0.0 "Ghosts of Delfino" Pre-release 6` が表示される必要があります。

## Decisive Shine Select crash test / 決定的な Shine Select crash test

Run this from a fresh power-on, before Race or Watch.

Race／Watch を使う前の fresh power-on から実行します。

1. Load a normal save, walk from Delfino Plaza to the Bianco portal, open retail
   Shine Select, and enter Bianco Hills 4. Test JP and PAL independently.
2. Repeat with at least three other retail Shine Select entries, including one
   stage that shows native Shadow and one that uses the 2D fallback.
3. Return to Plaza between entries. No white screen, hang, looping crash sound,
   stale texture, or live-Mario visual corruption is allowed.
4. Repeat Bianco 4 after one Race and after one Watch 2 session. Ordinary camera
   code and model resources must still be clean.

1. normal save を load し、Delfino Plaza から Bianco portal まで歩き、retail Shine Select
   から Bianco Hills 4 に入ります。JP と PAL を別々に確認します。
2. native Shadow を表示する stage と 2D fallback の stage を含む、少なくとも 3 つの別の
   retail Shine Select entry でも繰り返します。
3. entry ごとに Plaza へ戻ります。white screen、hang、looping crash sound、stale texture、
   live Mario visual corruption は禁止です。
4. Race を 1 回、Watch 2 を 1 回行った後にも Bianco 4 を再確認します。通常 camera code と
   model resource が clean なままである必要があります。

## PB presentation and protection / PB presentation と保護

1. Earn an eligible selected-IL PB and do not save it. The complete retail Shine
   pose, camera, and result presentation must remain unobstructed.
2. The exact-name confirmation must appear only after that presentation, before
   the game can fade out or destroy the PB. B holds the stage; A deliberately
   discards and departs.
3. Save from the Ghosts tab during the celebration. After the storage ACK, the
   stage must depart without a phantom prompt.
4. During the celebration, request Instant Restart, Full Restart, Warp Wheel,
   another IL, and Savestate Load. These explicit destructive actions must still
   prompt immediately and remain responsive.
5. Repeat with two unsaved PB tokens. They must be shown one at a time without a
   silent discard or stale-token approval.

1. eligible selected-IL PB を出して保存しません。retail Shine pose、camera、result
   presentation が最後まで妨げられずに表示される必要があります。
2. exact-name confirmation は presentation の後、fade out や PB 破棄の前にだけ表示します。
   B は stage を hold、A は明示的に discard して departure します。
3. celebration 中に Ghosts tab から Save します。storage ACK 後は phantom prompt なしで
   stage を departure する必要があります。
4. celebration 中に Instant Restart、Full Restart、Warp Wheel、別 IL、Savestate Load を
   request します。これらの explicit destructive action は即座に prompt を出し、操作可能な
   ままである必要があります。
5. 2 つの unsaved PB token でも繰り返します。silent discard／stale-token approval なしで
   1 つずつ表示する必要があります。

## Watch route viewer / Watch route viewer

1. Select a ghost from a different stage and press Watch. It must load, warp to
   segment 1 automatically, and begin at the recorded start without showing
   normal Mario.
2. The retail camera must follow the ghost smoothly. It must not turn around,
   race ahead, orbit a stale point, or react to hidden Mario physics.
3. Press B once and Start once in separate runs. Each must stop Watch and reload
   the watched stage with visible, controllable Mario restored.
4. Let Watch reach the end. It must display the exact final sample once, then
   reload the watched stage. Pause/menu time must not advance viewer time.
5. Watch a multi-stage ghost through every route transition. Each recorded route
   must load in order; no recording, IL PB, attempts, play/area time, deaths,
   achievements, or Attempt Counter credit is allowed. Observer route loads may
   reset QFT through the normal stage-warp path, but must never award a result.
6. Trigger Savestate Load, fast-forward, an unexpected stage change, and a model
   fallback. Each path must stop safely and restore input/visibility.

1. 別 stage の ghost を選び Watch を押します。segment 1 へ自動 warp し、normal Mario を
   表示せず recorded start から始まる必要があります。
2. retail camera は ghost を smooth に追います。turn around、race ahead、stale point の
   orbit、hidden Mario physics への反応は禁止です。
3. 別々の run で B と Start を 1 回ずつ押します。Watch を停止して watched stage を reload
   し、visible／controllable Mario を復元する必要があります。
4. Watch を最後まで再生します。exact final sample を 1 回表示した後、watched stage を
   reload します。pause／menu 中は viewer time を進めてはいけません。
5. multi-stage ghost のすべての route transition を確認します。recorded route を順番に
   load し、recording、IL PB、attempts、play／area time、deaths、achievements、
   Attempt Counter credit は禁止です。observer route load は通常の stage-warp path で
   QFT を reset できますが、result を award してはいけません。
6. Savestate Load、fast-forward、unexpected stage change、model fallback を確認します。
   すべて安全に停止し、input／visibility を復元する必要があります。

## Watch 2 and appearance swap / Watch 2 と appearance swap

1. Set `Ghost appearance` to Shadow Mario. Race and Watch must use Shadow;
   Watch 2 must show Shadow as runner 1 and Piantissimo as runner 2.
2. Set it to Piantissimo. Race and Watch must use Piantissimo; Watch 2 must swap
   runner 1 to Piantissimo and runner 2 to Shadow.
3. Test two compatible ghosts with staggered starts and finishes. The camera must
   follow whichever runner is visible, including the secondary-only head or tail.
4. In water, secrets, hotel/casino, and a Shadow-Mario stage, verify independent
   animation, opacity, draw order, and no live-Mario or retail-actor corruption.
5. Incompatible Watch-2 routes must be refused with a clear message, not partly
   loaded or silently changed.

1. `Ghost appearance` を Shadow Mario にします。Race／Watch は Shadow、Watch 2 は
   runner 1 が Shadow、runner 2 が Piantissimo になる必要があります。
2. Piantissimo に変更します。Race／Watch は Piantissimo、Watch 2 は runner 1 が
   Piantissimo、runner 2 が Shadow に swap する必要があります。
3. start／finish がずれた compatible ghost 2 つを確認します。secondary-only の head／tail
   を含め、visible な runner を camera が追う必要があります。
4. water、secret、hotel／casino、Shadow Mario stage で independent animation、opacity、
   draw order、live Mario／retail actor corruption がないことを確認します。
5. incompatible Watch-2 route は clear message で拒否し、partial load／silent change は
   禁止です。

## Storage, memory, and launcher regression / Storage、memory、launcher 回帰

- During Watch 2, scan imports and load/export the largest valid ghost available.
  The transfer mailbox and second model heap must not corrupt each other.
- Recheck one V3 record/race/save/load/import/export, one partial ghost, and one
  15-minute/multi-segment boundary case. Existing PR5 ghosts must remain valid.
- Recheck panorama, outlined text, `bgm.mp3`, theme auto-creation, poweroff, and
  game handoff. Music must stop cleanly and restart on the next launcher boot.
- Recheck QFT, fast-forward rejection, savestate, four profiles, cosmetics,
  pause toggle, metadata, notifications, Sirena 8, Pinna EYG, and restart binds.
- Run the decisive tests on JP and PAL hardware. Run US parity on hardware or
  Dolphin plus one console cross-check, and record the final ZIP checksum.

- Watch 2 中に import scan と、可能な最大 valid ghost の load／export を行います。transfer
  mailbox と second model heap が互いを破損してはいけません。
- V3 record／race／save／load／import／export、partial ghost、15-minute／multi-segment boundary
  を再確認します。既存 PR5 ghost は valid なままである必要があります。
- panorama、outlined text、`bgm.mp3`、theme auto-creation、poweroff、game handoff を再確認
  します。music は clean に停止し、次の launcher boot で再開する必要があります。
- QFT、fast-forward rejection、savestate、4 profiles、cosmetics、pause toggle、metadata、
  notifications、Sirena 8、Pinna EYG、restart bind を再確認します。
- decisive test は JP／PAL hardware で実行します。US は hardware または Dolphin と console
  cross-check で parity を確認し、final ZIP checksum を記録します。
