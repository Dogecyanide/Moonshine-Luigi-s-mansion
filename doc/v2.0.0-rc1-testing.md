# Susamune V2.0.0 "Ghosts of Delfino" Release Candidate 1 Testing / テストガイド

## English

### Status and installation

RC1 is source-stable for this acceptance pass, but its final observer-input and
Watch 2 changes are not yet hardware-qualified.

1. Back up the current launcher folder, `susamune.ini`, and
   `susamune_ghosts`.
2. Install all eight RC1 package files together. Preserve `theme`, BGM, ghosts,
   imports, settings, PBs, Records, achievements, and progress.
3. Confirm Homebrew Channel and the visible launcher screen both show
   `V2.0.0 "Ghosts of Delfino" Release Candidate 1`.
4. Run the complete focused matrix on PAL and JP. Perform the US smoke matrix
   at the end. Do not mix files from an earlier pre-release.

Prepare one direct-secret ghost, a compatible direct-secret pair, one
parent-to-secret route, and a compatible parent-to-secret pair. Existing PAL
fixtures may use Personal 01/02 for Bianco 3 Secret, 03/04 for Sirena 2 Secret,
and 09/10 for the two-segment Bianco 3 route if those slots are unchanged.

### 1. Direct-secret Watch 1 and Watch 2

Use Stage Intro Skip Off and run these cases in both Bianco and Sirena secrets.
Test Watch 1 first, then repeat the complete sequence with Watch 2.

1. Launch Watch. During the retail intro, press and keep holding B through the
   transition into active ghost playback.
2. The intro may react to B, but Watch must not end when active playback begins.
   Confirm the runner or both runners continue and Mario remains invisible and
   uncontrollable.
3. Release B and Start completely. Watch must continue after the release.
4. Press B again as a new post-intro input. Watch must end exactly once and the
   cleanup reload must restore a visible, controllable Mario.
5. Relaunch and repeat steps 1-4 with Start held during the intro and a new
   Start press after release. Test B and Start separately; do not chord them.
6. Relaunch as an A control. Use A during the intro, release it, and press A
   once more during active playback. A must never end Watch. Finish with a
   release followed by a new B press.

For Watch 2, confirm both tracks validate and appear at their recorded QFT.
The Target row should settle at `Watching 2 (2/2)` while both recordings are
active. `1/2` is valid only before one recording starts or after it ends;
persistent `Watch 2 loading` or `Watching 2 (0/2)` is a failure.

### 2. Parent-to-secret Watch 1 and Watch 2

1. Start the recorded parent stage and allow the invisible camera anchor to
   enter the matching secret loading zone naturally.
2. There must be no `Unexpected stage change`. The exact child segment must
   load on the recorded absolute QFT timeline. In Watch 2, both tracks must
   return before Mario is hidden for observer control.
3. During the child intro, hold B until child playback is active. Confirm the
   observer continues, release B/Start completely, then use a new B press to
   exit.
4. Repeat the entire transition with Start held and a new Start press.
5. Repeat once with A during the child intro. A must not end observer mode.
6. Run each sequence once in Watch 1 and once in Watch 2. After every exit,
   confirm Mario visibility/input, camera, intro setting, bind suppression,
   Records suppression, IL eligibility, and Attempt Counter state recover.
7. If practical, enter an unrelated destination. Exact-route mismatch must end
   Watch safely rather than following or guessing a segment.

### 3. Watch 2 hardening checks

1. Run Shadow Mario primary/Piantissimo secondary, then swap appearances.
   Confirm animation, opacity, and model fallback for both tracks.
2. Open the Ghosts tab briefly at initial loading, live playback, and a child
   segment. Record the exact Target text if it remains loading or reports fewer
   visible tracks than expected.
3. During a natural loading-zone departure, watch for one-frame visible or
   controllable Mario, a stale outgoing actor, late secondary spawn, duplicated
   model, or loss of camera ownership. Any occurrence is a blocker.
4. Toggle Ghost Display Off and Disable Warps in separate runs. Each must stop
   Watch with a visible, controllable Mario and no stale observer state.

### 4. Ghost library and action controls

1. Confirm non-selectable Personal headers 01-10, 11-20, 21-30, 31-40, and
   41-45, plus Imported 01-10 and 11-12.
2. Up/Down must never select a header. C-stick Left/Right must visit every
   range start and wrap, both in normal browsing and while choosing ghost 2.
3. A must activate or change the highlighted real row. Confirm personal slot
   IDs, imported IDs, protected-PB save/delete, and export targets did not move.
4. With Ghost Display Off, reject Watch and Watch 2. Selection must return to
   Ghost Display; A must enable it, L/R must switch tabs, and the configured
   menu bind must close the menu.
5. Confirm the action prompt remains A Race, Y Watch, and X Watch 2. RC1 has no
   Race 2 or Z Race 2 action.

### 5. Normal-stage and safety regressions

1. In an ordinary level, run Race, Watch 1, and Watch 2 with both appearance
   choices and several opacity values. Check QFT sync, animation, camera,
   natural completion, B exit, Start exit, and fast-forward abort.
2. Confirm Watch awards no IL PB, Records result, achievement, or attempt-count
   credit. Normal play after cleanup must be eligible again.
3. Recheck retail Shine Select into Bianco 4/5 and Pianta 5.
4. Recheck protected PB Save/Discard, savestate load, instant/full restart,
   Warp Wheel, Exit Area, theme panorama/BGM, pause toggle, and metadata.

### 6. Region acceptance matrix

- PAL: complete sections 1-5 with both direct-secret and parent-to-secret
  fixtures.
- JP: complete sections 1-4 and the normal Race/Watch/Watch 2 plus protected-PB
  regressions from section 5.
- US smoke: one direct-secret Watch 1 and Watch 2, one parent-to-secret Watch 2,
  one fresh B exit, one fresh Start exit, the A control, library range
  navigation, and one normal-level Race.

Record region, disc ID, real disc versus ISO, source device, ghost slots, stage,
appearance, exit button, whether the button was held across the intro, Target
text, and the exact last visible state for every failure. Do not report RC1 as
hardware-qualified until the required matrix is green.

If the Wii hard-crashes, leave the crash screen visible for about five seconds,
then power-cycle and preserve the newest/highest-generation
`susamune_crash_a.txt/.bin` or `susamune_crash_b.txt/.bin` pair from the
launcher-device root. An exception-free hang may not create a report.

## 日本語

### 状態とインストール

RC1 はこの acceptance test 用に source-stable としますが、最後の observer input と
Watch 2 の変更はまだ実機合格済みではありません。

1. 現在の launcher folder、`susamune.ini`、`susamune_ghosts` を backup します。
2. RC1 package の 8 files を必ず一緒に導入します。`theme`、BGM、ghost、import、setting、
   PB、Records、achievement、progress を保持してください。
3. Homebrew Channel と launcher 画面の両方が
   `V2.0.0 "Ghosts of Delfino" Release Candidate 1` を表示することを確認します。
4. PAL と JP で focused matrix 全体を実行し、最後に US smoke matrix を行います。
   以前の pre-release file を混ぜないでください。

direct-secret ghost と compatible な 2 体、parent-to-secret route と compatible な 2 体を
用意します。slot が変わっていなければ、既存 PAL fixture は Bianco 3 Secret の Personal
01/02、Sirena 2 Secret の 03/04、2-segment Bianco 3 route の 09/10 を使用できます。

### 1. Direct-secret Watch 1／Watch 2

Stage Intro Skip を Off にし、Bianco と Sirena の Secret の両方で確認します。最初に Watch 1、
次に同じ全手順を Watch 2 で繰り返します。

1. Watch を開始します。retail intro 中に B を押し、active ghost playback に入るまで
   hold し続けます。
2. intro が B に反応しても、active playback 開始時に Watch が終了してはいけません。
   runner（Watch 2 では両方）が継続し、Mario が透明かつ操作不能であることを確認します。
3. B と Start を完全に release します。release 後も Watch は継続する必要があります。
4. post-intro の新しい input として B をもう一度押します。Watch は 1 回だけ終了し、cleanup
   reload 後に Mario が表示され操作可能になる必要があります。
5. 再起動し、intro 中に Start を hold、release 後に新しい Start press で steps 1-4 を
   繰り返します。B と Start は別々にテストし、同時押ししないでください。
6. A control として再起動します。intro 中に A を使って release し、active playback 中にも
   A を 1 回押します。A で Watch が終了してはいけません。最後は release 後の新しい B で
   終了します。

Watch 2 では両 track が validate され、recorded QFT に表示されることを確認します。両記録が
active な間、Target は `Watching 2 (2/2)` になる必要があります。`1/2` は片方の開始前または
終了後だけ正常です。`Watch 2 loading`／`Watching 2 (0/2)` が継続する場合は failure です。

### 2. Parent-to-secret Watch 1／Watch 2

1. 記録された parent stage を開始し、invisible camera anchor が matching secret loading zone
   へ自然に入るまで待ちます。
2. `Unexpected stage change` が出ず、exact child segment が recorded absolute QFT timeline で
   load される必要があります。Watch 2 は両 track が復帰した後だけ Mario を observer 用に
   非表示にします。
3. child intro 中に B を hold し、child playback が active になっても observer が継続する
   ことを確認します。B／Start を完全に release した後、新しい B press で終了します。
4. Start hold と新しい Start press で transition 全体を繰り返します。
5. child intro 中の A でも 1 回確認します。A で observer mode を終了してはいけません。
6. 各 sequence を Watch 1 と Watch 2 で実行します。終了ごとに Mario visibility／input、camera、
   intro setting、bind suppression、Records suppression、IL eligibility、Attempt Counter が
   restore されることを確認します。
7. 可能なら unrelated destination に入ります。exact-route mismatch では segment を推測せず、
   Watch を安全に終了する必要があります。

### 3. Watch 2 安全性確認

1. Shadow Mario primary／Piantissimo secondary で実行し、appearance を入れ替えます。両 track の
   animation、opacity、model fallback を確認します。
2. initial loading、live playback、child segment で Ghosts tab を短時間開きます。loading が
   継続する場合や visible track 数が不足する場合は Target text をそのまま記録します。
3. natural loading-zone departure で、1-frame の visible／controllable Mario、stale outgoing
   actor、late secondary spawn、duplicate model、camera ownership loss がないか確認します。
   1 つでも発生すれば blocker です。
4. Ghost Display Off と Disable Warps を別々に試します。どちらも Watch を終了し、表示された
   controllable Mario に戻り、stale observer state を残してはいけません。

### 4. Ghost library と action 操作

1. 選択不能な Personal 01-10、11-20、21-30、31-40、41-45、および Imported 01-10、
   11-12 header を確認します。
2. Up／Down で header を選択してはいけません。通常一覧と ghost 2 chooser の両方で C stick
   Left／Right がすべての range start を循環する必要があります。
3. A で highlighted real row を実行・変更します。personal slot ID、imported ID、protected-PB
   save／delete、export target が移動していないことを確認します。
4. Ghost Display Off で Watch／Watch 2 を拒否させます。Ghost Display row に戻り、A で有効化、
   L／R で tab 移動、configured menu bind で menu close ができる必要があります。
5. action prompt が A Race、Y Watch、X Watch 2 のままであることを確認します。RC1 に Race 2
   または Z Race 2 はありません。

### 5. 通常 stage と safety 回帰

1. ordinary level で Race、Watch 1、Watch 2 を両 appearance と複数 opacity で実行します。
   QFT sync、animation、camera、natural completion、B exit、Start exit、fast-forward abort を
   確認します。
2. Watch が IL PB、Records result、achievement、attempt count を加算しないことを確認します。
   cleanup 後の normal play は再び eligible になる必要があります。
3. retail Shine Select の Bianco 4/5 と Pianta 5 を再確認します。
4. protected PB Save／Discard、savestate load、instant/full restart、Warp Wheel、Exit Area、
   theme panorama／BGM、pause toggle、metadata を再確認します。

### 6. Region acceptance matrix

- PAL: direct-secret と parent-to-secret fixture で sections 1-5 をすべて実行します。
- JP: sections 1-4 全体、および section 5 の normal Race／Watch／Watch 2 と protected-PB
  regression を実行します。
- US smoke: direct-secret Watch 1／Watch 2、parent-to-secret Watch 2、新しい B exit、新しい
  Start exit、A control、library range navigation、normal-level Race を各 1 回実行します。

failure ごとに region、disc ID、real disc／ISO、source device、ghost slot、stage、appearance、
exit button、intro をまたいで hold したか、Target text、最後に見えた正確な状態を記録します。
required matrix が green になるまで RC1 を hardware-qualified と報告しないでください。

Wii が hard crash した場合、crash screen のまま約 5 秒待って power-cycle し、launcher-device
root の最新／最大 generation の `susamune_crash_a.txt/.bin` または
`susamune_crash_b.txt/.bin` pair を保存してください。exception-free hang では report が
作成されない場合があります。
