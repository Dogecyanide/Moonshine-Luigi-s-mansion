# Susamune V2.1.0 Release Candidate 2 "Hot Streak"

This changelog covers RC2 changes from RC1 only.

## Bianco 2 splits

- Restored the rollout checkpoint that was removed from RC1 by mistake.
- Bianco 2 now splits, in order, on rollout at `Y >= 3200`, accepted Petey
  entry cutscene, and Petey ground-pound hits 1, 2, and 3.
- The same sequence is available when the Bianco 2 IL is started in physical
  episode 1 or episode 2. There is no spin-jump checkpoint.

## Shadow Mario talk splits

- Restored Shadow Mario talk checkpoints for Shadow Mario ILs whose Shadow
  Mario actor is registered as a standalone stage actor.
- Each route produces one checkpoint when Shadow Mario reaches his
  down-and-waiting-to-talk state; approaching or fighting him does not create
  an early or duplicate split.

## V7 split-stat migration

- Split-stat storage advances from V6 to V7 for the restored Bianco 2
  checkpoint layout.
- RC1 V6 journals migrate automatically. Bianco 2 keeps its attempts,
  finishes, Time played, and compatible Gold segments, but its split PB
  identity and PB segments reset so the first eligible complete RC2 run can
  establish a baseline for the new layout.
- Bianco 2's catalog IL PB is unchanged. Unrelated routes retain their split
  statistics and PB/Gold data.
- V7 writes separate A/B journals. V6 files remain read-only migration and
  rollback sources.
