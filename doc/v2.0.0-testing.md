# Susamune V2.0.0 "Ghosts of Delfino" Testing / テストガイド

## English

This is the focused acceptance pass for the full V2.0.0 release. It validates
the changes made after Release Candidate 1 and smoke-tests the already qualified
ghost foundation; it is not a request to repeat every earlier pre-release test.

### Status and installation

1. Back up the current Homebrew Channel app folder, `susamune.ini`, all PB and
   Records journals, `susamune_ghosts`, `susamune_ghost_import`, theme assets,
   and custom BGM.
2. Install all eight files from `Susamune-V2.0.0-Ghosts-of-Delfino.zip`
   together. Do not combine its executable, XML, or mod binaries with an older
   package.
3. Confirm Homebrew Channel shows `Susamune Launcher` and
   `V2.0.0 "Ghosts of Delfino"`. Confirm the visible launch screen shows the
   same version and a Build ID. `SIGMA`, `Pre-release`, and `Release Candidate`
   must not appear in the active package identity.
4. Preserve existing settings, PBs, achievements, statistics, personal ghosts,
   imported ghosts, theme, and BGM. The Records total must be **154** active
   achievements after synchronization.
5. Boot JP, PAL, and US once. Each must reach gameplay, open the Ghosts and
   Records tabs, and load the correct region's existing configuration.

Record the displayed Build ID before testing. Use expendable ghost slots or a
backed-up library for save/delete tests.

### Gate 1: Watch exit input

Run with Stage Intro Skip Off so the retail intro accepts B or Start. Test B and
Start separately; do not chord them.

1. Start Watch 1 in a normal level. Hold B from the intro through the first
   visible active ghost frames. Watch must continue while B is held.
2. Release both B and Start completely. Watch must continue after release.
3. Press B once as a fresh active-playback input. Watch must exit exactly once,
   reload cleanly, and return a visible, controllable Mario.
4. Repeat steps 1-3 with Start held and a fresh Start press.
5. Repeat with A during the intro and active playback. A must never exit Watch;
   finish with a release followed by a fresh B press.
6. Repeat the B and Start cases in one direct secret with Watch 2. Both ghosts
   must appear at their recorded QFT and remain active through the intro hold.
7. Run one recorded parent-to-secret Watch. Hold an exit button during the
   child intro, release it, and use a fresh press. The release gate must reset
   for the child segment; there must be no `Unexpected stage change`.

Any immediate exit from an intro hold, or any fresh B/Start press that fails to
exit active playback, is a release blocker.

### Gate 2: Auto race target

1. Open Ghosts and confirm `Auto race target` offers `Last attempt` and
   `Last success`; a fresh/default configuration selects `Last attempt`.
2. With `Last attempt`, make a distinctive partial attempt and restart. On the
   next attempt, the automatic race ghost must reproduce that partial and end
   at the recorded interruption point.
3. Select `Last success`, complete an attempt, and begin another. Interrupt the
   new attempt and restart. The completed ghost must remain the automatic race
   target; the partial must not replace it.
4. Switch to `Last success` while an inherited automatic partial is selected,
   then start the next attempt. The partial must clear rather than being called
   a success.
5. Pin a personal-library ghost and repeat an interrupted attempt. The pinned
   target must remain pinned. Confirm Watch, Watch 2, PB Save/Discard, and
   explicit ghost saves behave the same under both policies.
6. Reboot after changing the choice and confirm the per-region setting persists.

### Gate 3: Ghost library and release UI

1. Confirm non-selectable Personal headers 01-10, 11-20, 21-30, 31-40, and
   41-45, plus Imported headers 01-10 and 11-12.
2. Up/Down must never select a header. C-stick Left/Right must visit every range
   start and wrap in normal browsing and in the second-ghost chooser. A must
   activate the highlighted real row; physical slot identities must not move.
3. Confirm the action prompt is A Race, Y Watch, and X Watch 2. There must be no
   Race 2 or Z action.
4. Use Ghost Display Off to reject Watch and Watch 2. The ordinary menu must
   remain usable and closable.
5. Exercise normal saves, scans, and Watch without an error. Temporary test
   notices or `GHOST TEST` diagnostic chatter must not appear. Legitimate
   storage errors and ordinary status messages must remain readable.

2. Use a Reds/timed-challenge route to confirm the result follows QFT even when
   the visible retail IGT timer differs.
3. Where a PB is exactly equal to a threshold, synchronize it and confirm the
   achievement remains locked; a genuinely faster PB may unlock it.
4. Load a profile containing qualifying historical PBs. The 24 time-only
   achievements may reconcile from it. `Nutty` must not reconcile from an old

### Gate 5: lifetime ghost progress

1. Before scanning or saving, record the Global and regional values of
   `Ghosts saved` and `Ghost time saved`. Merely scanning pre-existing files
   must not change either value; V2.0.0 does not reconstruct past saves.
2. Record a valid ghost, save it to an expendable Personal slot, and wait for
   the success acknowledgement. `Ghosts saved` must increase by exactly one,
   `Ghost time saved` must increase by that recording's duration, and `Ghastly!`
   must unlock at the first lifetime save.
3. Open a save confirmation and cancel it. Neither statistic may change. If a
   storage failure occurs naturally, it also must not count; do not remove a
   mounted device merely to manufacture this test.
4. Reboot and verify the values and unlock persist. On Wii, boot a second region
   and confirm its Global view includes the successful save while its regional
   view remains separate.
5. Verify the remaining Special descriptions and tiers: `Spectral!` at five
   minutes, `Specular!` at 25 saves, `Ectoplasmic!` at one hour, `Wraithlike!`
   at 250 saves, and `Phantasmal!` only after total saved duration is strictly
   greater than 50 hours. The higher thresholds use the same acknowledged-save
   path and do not require destructive repetition for a package smoke test.

### Gate 6: release regressions

1. Run Race, Watch 1, and Watch 2 in a normal level and secret. Check QFT sync,
   animation, both appearances, opacity, camera, natural completion, and cleanup.
2. Confirm Watch awards no PB, Records result, achievement, attempt, or ghost-save
   credit. Normal play after cleanup must be eligible again.
3. Enter Bianco 4, Bianco 5, and Pianta 5 through retail Shine Select. Each must
   load without a white-screen/audio-loop crash.
4. Recheck protected PB Save/Discard, instant and full restart, Warp Wheel, Exit
   Area, savestate load, pause toggle, panorama, custom font readability, BGM,
   metadata, and popup positioning.
5. Confirm an existing `susamune.ini`, V3 ghost library, PB profiles, and Records
   journals load without migration loss.

### Hardware acceptance and crash reports

- PAL and JP: complete Gates 1-3 and the successful-save path in Gate 5; run the
  representative achievement and regression cases in Gates 4 and 6.
- US: boot smoke, one normal Watch fresh-B exit, one Last-success retention case,
  one QFT achievement, and one existing-library load.
- Do not publish the archive if fresh B/Start exit, save acknowledgement, Records
  persistence, or any retail Shine Select case fails.

If the Wii raises a hard exception, leave the crash screen visible for about
five seconds before power-cycling. Preserve the newest/highest-generation
`susamune_crash_a.txt/.bin` or `susamune_crash_b.txt/.bin` pair from the root of
the device that launched Susamune. An exception-free hang may not create a log.

Report region and disc ID, real disc versus ISO, launch/storage device, Build ID,
stage and ghost slots, exact input sequence, displayed QFT and IGT, expected
result, actual result, and the last visible state.

## 日本語

これは V2.0.0 正式版の focused acceptance test です。Release Candidate 1 後の変更を確認し、
すでに検証した Ghost 基盤を smoke-test します。過去の pre-release test 全体を再実行する必要は
ありません。

### 状態とインストール

1. 現在の Homebrew Channel app folder、`susamune.ini`、PB／Records journal、
   `susamune_ghosts`、`susamune_ghost_import`、theme、custom BGM を backup します。
2. `Susamune-V2.0.0-Ghosts-of-Delfino.zip` の 8 files を必ず一緒に導入します。古い package の
   executable、XML、mod binary を混ぜないでください。
3. Homebrew Channel と launcher 画面が `Susamune Launcher`、
   `V2.0.0 "Ghosts of Delfino"`、Build ID を表示することを確認します。active package identity に
   `SIGMA`、`Pre-release`、`Release Candidate` が残ってはいけません。
4. 既存 setting、PB、achievement、stat、Personal／Imported ghost、theme、BGM が保持され、
   Records の有効な実績総数が **154** になることを確認します。
5. JP、PAL、US を各 1 回起動し、gameplay、Ghosts／Records tab、region ごとの設定を確認します。

テスト前に表示された Build ID を記録してください。save／delete test は backup 済み library または
消してよい slot で行います。

### Gate 1: Watch 終了入力

Stage Intro Skip を Off にし、B と Start を別々に確認します。

1. normal level で Watch 1 を開始し、intro から ghost の active frame まで B を hold します。
   hold 中に Watch が終了してはいけません。
2. B と Start を完全に release します。release だけでは Watch を継続する必要があります。
3. active playback 中の新しい B press で 1 回だけ終了し、visible／controllable Mario に戻ること。
4. Start hold、release、新しい Start press でも同じ手順を行います。
5. intro／active 中の A では終了しないことを確認し、最後に fresh B で終了します。
6. direct secret の Watch 2 でも B／Start を確認します。2 ghost が recorded QFT に出現し、intro
   hold を越えて継続する必要があります。
7. parent-to-secret Watch で child intro をまたいで同じ手順を行います。child segment ごとに
   release gate が reset され、`Unexpected stage change` が出ないことを確認します。

intro hold で直ちに終了する場合、または active 中の fresh B／Start で終了できない場合は blocker です。

### Gate 2: Auto race target

1. Ghosts の `Auto race target` に `Last attempt`／`Last success` があり、新規設定では
   `Last attempt` が選ばれることを確認します。
2. `Last attempt` で特徴の分かる未完走 attempt を作って restart し、次 attempt の自動 ghost が
   その未完走を再現して中断地点で終わることを確認します。
3. `Last success` で 1 回完走後、次 attempt を中断して restart します。完走 ghost が残り、
   未完走に置き換わってはいけません。
4. automatic partial がある状態から `Last success` に変えて次 attempt を開始し、その partial が
   success として扱われず clear されることを確認します。
5. Personal ghost を pin して中断 attempt を行い、pin が維持されることを確認します。両 policy で
   Watch、Watch 2、PB Save／Discard、明示的な ghost save が変化しないことも確認します。
6. 設定変更後に reboot し、region ごとに保持されることを確認します。

### Gate 3: Ghost library と release UI

1. 選択不能な Personal 01-10、11-20、21-30、31-40、41-45、および Imported 01-10、11-12
   header を確認します。
2. Up／Down で header を選択せず、C-stick 左右で全 range 先頭を循環し、A で実 row を実行すること。
   normal browsing と ghost 2 chooser の両方で行い、physical slot ID が移動しないことを確認します。
3. prompt が A Race、Y Watch、X Watch 2 で、Race 2／Z action がないことを確認します。
4. Ghost Display Off で Watch／Watch 2 を拒否させても、通常 menu を操作・終了できること。
5. normal save／scan／Watch で `GHOST TEST` など一時 diagnostic が表示されず、正規の error／status は
   読めることを確認します。

### Gate 4: 新しい Times 実績

English section の 25-entry table を Records で照合し、tier、route、strict QFT limit が一致することを
確認します。description はすべて QFT であり retail IGT ではありません。

1. normal Shine、Reds、100-coin、Delfino route を各 1 つ、threshold 未満の eligible attempt で
   完走し、解除と reboot 後の保持を確認します。
2. retail timer が表示される Reds／timed challenge で、retail IGT と異なっても QFT result だけで
   判定されることを確認します。
3. exact threshold と同値の PB がある場合は locked のまま、それより速い PB で解除可能なこと。
4. qualifying PB profile から time-only 24 個が再判定されることを確認します。`Nutty` は old PB から
   解除されず、Ricco 8 を Yoshi なしの live run で 45 秒未満にした場合だけ解除されます。
5. qualifying run 中に savestate／assist を使い、invalid attempt では解除されないことを確認します。

### Gate 5: lifetime Ghost progress

1. scan／save 前に Global と region の `Ghosts saved`／`Ghost time saved` を記録します。既存 file を
   scan しただけでは変化しないことを確認します。V2.0.0 は過去の save を backfill しません。
2. valid ghost を消してよい Personal slot に保存し、success ACK を待ちます。`Ghosts saved` が正確に
   1、`Ghost time saved` が記録時間分増え、最初の lifetime save で `Ghastly!` が解除されること。
3. save confirmation を cancel し、両 stat が変化しないこと。自然に storage failure が起きた場合も
   count してはいけませんが、この test のために mounted device を抜かないでください。
4. reboot 後も値と解除が保持されること。Wii で別 region を起動し、Global には加算分が含まれ、
   region view は独立していることを確認します。
5. 残りの条件を確認します。`Spectral!` は 5 分、`Specular!` は 25 saves、`Ectoplasmic!` は 1 時間、
   `Wraithlike!` は 250 saves、`Phantasmal!` は 50 時間と同値ではなく超えた時だけです。高い threshold
   は同じ ACK path を使用するため、package smoke test で無理に大量上書きする必要はありません。

### Gate 6: 正式版 regression

1. normal level と secret で Race、Watch 1、Watch 2 を行い、QFT sync、animation、両 appearance、
   opacity、camera、natural completion、cleanup を確認します。
2. Watch で PB、Records result、achievement、attempt、ghost-save credit が増えず、cleanup 後の通常 play
   が再び eligible になること。
3. retail Shine Select から Bianco 4、Bianco 5、Pianta 5 に入り、white-screen／audio-loop crash が
   起きないこと。
4. protected PB Save／Discard、instant／full restart、Warp Wheel、Exit Area、savestate load、pause、
   panorama、custom font、BGM、metadata、popup position を簡易確認します。
5. 既存 `susamune.ini`、V3 ghost library、PB profile、Records journal が migration loss なく読めること。

### 実機 acceptance と crash report

- PAL／JP: Gates 1-3、Gate 5 の success-save、Gates 4／6 の代表 case を実行します。
- US: boot、normal Watch の fresh B exit、Last-success retention、QFT 実績 1 個、既存 library load を
  smoke-test します。
- fresh B／Start exit、save ACK、Records persistence、retail Shine Select のいずれかが失敗した package
  は公開しないでください。

Wii が hard exception を出した場合、crash screen のまま約 5 秒待ってから power-cycle します。
Susamune を起動した device の root にある最新／最大 generation の
`susamune_crash_a.txt/.bin` または `susamune_crash_b.txt/.bin` pair を保存してください。
exception-free hang では log が作成されない場合があります。

報告には region／disc ID、real disc／ISO、launch/storage device、Build ID、stage／ghost slot、正確な
input sequence、表示 QFT／IGT、期待結果、実際の結果、最後に見えた状態を含めてください。
