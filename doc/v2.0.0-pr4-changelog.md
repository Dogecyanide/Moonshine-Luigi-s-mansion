# V2.0.0 "Ghosts of Delfino" Pre-release 4

## English

Pre-release 4 is a rapid hardware-test hotfix for the remaining Pre-release 3
PB-warning and launcher-theme failures. It also adds the first bounded visual
Watch mode. It remains experimental and is not a release candidate.

### Nonblocking unsaved-PB protection

- Removed every PB-discard confirmation dialog. The dialogs used frozen game
  states and could become unresponsive from both the IL menu and Exit Area.
- A destructive IL start, Exit Area, Warp Wheel selection, or Warp Last now
  shows `Unsaved PB: repeat action to discard` and immediately returns control.
  Repeating the exact same action for the same PB and destination within 15
  seconds authorizes it.
- A held A button cannot approve the warning. IL selection requires a release
  and a new press; Exit Area requires choosing Exit Area again.
- The guard revalidates the PB after CARD activity and clears authorization on
  savestate load, stage handoff, timeout, changed destination, or changed PB.
- Only a newly accepted and still-unsaved IL PB is protected. Equal/slower,
  assisted, imported, partial, and saved ghosts do not warn. Route-preserving
  restarts do not warn.

### Visual Watch mode

- Pressing A on a saved ghost now opens an action chooser: A races it, Y watches
  it, and X selects a second saved ghost to watch.
- Watch follows the primary ghost with the camera and plays its recorded Shadow
  Mario animation on an independent visual timeline. If only ghost 2 is active
  at the beginning or end, the camera follows its marker. B or Start exits.
- Two-ghost Watch uses the animated Shadow model for ghost 1 and a numbered cyan
  marker for ghost 2. This deliberately reuses the existing record/playback
  buffers and adds no fixed MEM2 reservation.
- Watch is a current-area visual viewer, not a deterministic gameplay replay.
  It does not drive doors, NPCs, loading zones, RNG, or game state, and it stops
  on a stage change, savestate load, fast-forward, or the end of the selected
  route segment.
- Recording and IL/Records credit are disabled while Watch is active. Starting
  Watch is refused while an unsaved PB ghost still needs to be saved.

### Launcher panorama hotfix

- Replaced the high-peak PNG path with bounded row-by-row decoding directly
  into the Wii GX texture layout. The known Mare 1024x480 panorama now passes
  the production PowerPC decoder.
- The launcher creates `theme` beside the app automatically. A present rejected
  image now shows a short nonfatal reason instead of silently doing nothing.
- Missing, malformed, wrong-size, or out-of-memory images fall back to the stock
  background; a final texture-free fallback remains available if memory is
  exceptionally constrained.
- Custom music remains disabled. `bgm.mp3` is ignored and cannot initialize the
  PR2 audio path.

### Compatibility

- Pre-release 3 V3 `.smsghost` files remain compatible; no ghost-library reset
  is required for PR4.
- Settings, binds, PBs, Records, achievements, progress, and the PR2 cosmetic,
  pause, metadata, notification, route, restart, and fast-forward fixes remain
  intact.
- QFT timing, capture cadence, and result code are unchanged.

## 日本語

Pre-release 4 は、Pre-release 3 の実機テストで残った PB warning と launcher theme の
問題を修正する緊急 hotfix です。最初の bounded visual Watch mode も追加します。
引き続き実験版であり、release candidate ではありません。

### Blocking しない未保存 PB 保護

- PB 破棄確認 dialog をすべて廃止しました。旧 dialog は game state を freeze しており、
  IL menu と Exit Area の両方で操作不能になる可能性がありました。
- 破棄の可能性がある IL start、Exit Area、Warp Wheel、Warp Last は
  `Unsaved PB: repeat action to discard` と表示し、すぐ操作を返します。15 秒以内に
  同じ PB／destination に対して全く同じ操作を繰り返すと実行されます。
- A を押し続けても承認されません。IL selection は一度離して再度押し、Exit Area は
  Exit Area をもう一度選ぶ必要があります。
- CARD 処理後に PB を再確認し、savestate load、stage handoff、timeout、destination／PB
  の変更時には承認を破棄します。
- 保護対象は、新しく正式に受理され、まだ保存されていない IL PB だけです。同タイム／
  遅い run、assisted、imported、partial、保存済み ghost は警告しません。同一 route の
  restart も警告しません。

### Visual Watch mode

- 保存済み ghost で A を押すと action chooser が開きます。A は Race、Y は Watch、
  X は 2 体目の Watch ghost 選択です。
- Watch は primary ghost を camera で追い、記録済み Shadow Mario animation を独立した
  visual timeline で再生します。開始／終了時に ghost 2 だけが active の場合は、その
  marker を追います。B または Start で終了します。
- 2-ghost Watch では ghost 1 を animated Shadow model、ghost 2 を番号付き cyan marker
  で表示します。既存の record／playback buffer を再利用し、新しい固定 MEM2 領域は
  追加しません。
- Watch は current-area visual viewer であり、deterministic gameplay replay では
  ありません。door、NPC、loading zone、RNG、game state は操作せず、stage change、
  savestate load、fast-forward、選択 route segment の終了時に停止します。
- Watch 中は recording と IL／Records credit を無効化します。未保存 PB ghost がある場合は
  保存するまで Watch を開始できません。

### Launcher panorama hotfix

- peak memory の大きかった PNG 経路を、Wii GX texture へ直接 row-by-row decode する
  bounded 実装に置き換えました。既知の Mare 1024x480 panorama は production PowerPC
  decoder を通過します。
- launcher は app の隣に `theme` directory を自動作成します。存在する画像を拒否した
  場合は、何も起きない代わりに短い nonfatal reason を表示します。
- missing、malformed、wrong-size、out-of-memory image は stock background に fallback
  します。memory が極端に少ない場合にも texture-free fallback が残ります。
- custom music は引き続き無効です。`bgm.mp3` は無視され、PR2 audio path を初期化しません。

### Compatibility

- Pre-release 3 の V3 `.smsghost` はそのまま使用できます。PR4 で ghost library の reset は
  不要です。
- settings、binds、PB、Records、achievements、progress、および PR2 の cosmetic、pause、
  metadata、notification、route、restart、fast-forward 修正は維持されます。
- QFT の timing、capture cadence、result code は変更していません。
