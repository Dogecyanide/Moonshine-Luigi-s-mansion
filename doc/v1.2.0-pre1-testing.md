# Susamune V1.2.0 Pre-Release 1 testing

**Trial By Sunshine - ALPHA**

This is an unfinished test build. Back up `susamune.ini`, the Susamune PB
journals, and Dolphin slot B before installing it. V1.2 alpha progress formats
may change before release.

## Priority checks

- Confirm the Homebrew Channel and launcher both identify the build as
  `V1.2.0 Pre-Release 1` and `ALPHA`.
- Test a fresh install and an upgrade from V1.1.0. Existing settings, binds,
  display layouts, and every IL PB profile must survive unchanged.
- Exercise all six pilot achievements (one per tier). Check the nested list,
  details, progress, coloured-outline unlock notifications, simultaneous PB
  and achievement banners, and persistence after reboot. This alpha has no
  achievement chime yet.
- Check global and regional statistics, including playtime, attempts, PBs,
  deaths, Creation editing, and area time. Internal areas must count toward
  their parent course rather than creating extra entries.
- Repeat persistence tests on JP, US, and PAL. Cover Wii launches from SD and,
  where available, USB. Dolphin Records are session-only in this alpha; its
  existing settings and IL PB persistence must still regress cleanly.
- Regression-test savestate save/load, IL PB recording, PB profiles, restarts,
  the warp wheel, the mod menu, and settings saves.

## Reporting

Include the game region, Wii or Dolphin version, launch/storage device, exact
steps, expected and actual result, and the launcher checksum shown on screen.
Attach `susamune.ini` only after removing anything you consider private.

Airstrip reset commands remain a known V1.1 limitation; Airstrip IL and PB
recording should still work.

Practice assists do not yet invalidate pilot achievements. In particular,
Fast Forward can invalidate the meaning of a time target; anti-cheese policy is
still a V1.2 design decision, so test the detectors rather than the prestige of
these provisional unlocks. Stage Intro Skip retains its existing PB-invalidating
rule and also invalidates challenge/timed achievement results.
