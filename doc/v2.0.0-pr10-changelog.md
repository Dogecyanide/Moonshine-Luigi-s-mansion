# V2.0.0 "Ghosts of Delfino" Pre-release 10

## English

Pre-release 10 is a focused Watch 2 hardware test build. The ghost file format
is unchanged and existing V3 libraries remain valid.

### Watch 2 hardening

- Watch 2 now keeps the second ghost's runtime metadata separate from normal
  recording, PB, and storage-ack ownership while continuing to use the bounded
  record-slot payload.
- Every loaded observer segment validates both ghosts, not only the primary.
- The invisible camera-anchor Mario is restored on the exact frame a loading
  zone starts, before the outgoing stage heap can be destroyed. The new stage
  is hidden only after both tracks configure successfully.
- Materialisation movement remains retail-controlled until the stage reaches
  normal play; this avoids reintroducing the earlier pre-normal input hang.
- The Ghosts tab Target row now reports `Watch 2 loading` or
  `Watching 2 (visible/2)`. This makes any remaining hardware failure
  diagnosable without a special debug build.

Static review found no invalid ghost, route mismatch, duplicate setup, model
overlap, or external Watch-2-only cancellation in the reported PAL files. This
is therefore deliberately described as safe hardening awaiting hardware proof,
not as a confirmed root-cause fix.

### Ghost library navigation

- Personal ghosts now have non-selectable 01-10, 11-20, 21-30, 31-40, and
  41-45 range headers.
- Imported ghosts have 01-10 and 11-12 range headers.
- C-stick Left/Right jumps among these range starts in both normal browsing and
  the second-ghost chooser. Up/Down still selects only real rows; slot identity,
  PB saving, deletion, and import behavior are unchanged.

Race 2 is no longer planned. The existing A Race, Y Watch, and X Watch 2
actions remain unchanged.

## 日本語

Pre-release 10 は Watch 2 の実機確認に集中したテストビルドです。
ゴーストファイル形式は変更されず、既存の V3 ライブラリをそのまま使用できます。

### Watch 2 の安全性改善

- 2 体目のゴースト用ランタイム情報を、通常の録画、PB、保存 ACK の管理から
  分離しました。サンプル本体は従来どおり境界確認済みの record slot を使用します。
- Observer の各セグメント読み込み時に、メインだけでなく 2 体目のルートも検証します。
- ローディングゾーン開始と同じフレームで、ステージヒープ破棄より前に透明な
  カメラ用 Mario を復元します。次のステージでは、2 体とも設定に成功した後だけ
  Mario を非表示にします。
- ステージが通常状態になるまでは retail の materialise 動作を維持し、以前の
  pre-normal 入力停止を再発させません。
- Ghosts タブの Target 行に `Watch 2 loading` または
  `Watching 2 (表示数/2)` を表示します。特別なデバッグ版なしで、残る不具合の
  状態を判別できます。

静的確認では、報告された PAL ファイルに破損、ルート不一致、二重 setup、
モデル領域の重複、Watch 2 専用の外部キャンセルは見つかりませんでした。
そのため、これは原因確定済み修正ではなく、安全性を確認した実機テスト候補です。

### ゴーストライブラリの移動

- Personal に 01-10、11-20、21-30、31-40、41-45 の選択不能な範囲見出しを
  追加しました。
- Imported に 01-10 と 11-12 の範囲見出しを追加しました。
- 通常一覧と 2 体目選択の両方で、C スティック左右により各範囲先頭へ移動します。
  上下は実際の行だけを選び、slot ID、PB 保存、削除、import の動作は変わりません。

Race 2 は追加しません。既存の A Race、Y Watch、X Watch 2 は変更ありません。
