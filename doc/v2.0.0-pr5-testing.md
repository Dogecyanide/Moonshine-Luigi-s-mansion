# Susamune V2.0.0 "Ghosts of Delfino" Pre-release 5 Testing / テストガイド

## Purpose / 目的

PR5 is a focused hardware-safety build. It repairs the input-dead confirmation
screens, protects accepted unsaved PB ghosts consistently, removes the Watch
camera hook from ordinary Shine Select, and restores optional launcher music.

PR5 は hardware-safety に集中した build です。操作不能になった確認画面、受理済み未保存
PB ghost の保護、通常 Shine Select からの Watch camera hook 除去、optional launcher music
を修正します。

## Hard safety rules / 必須の安全規則

- Back up the complete PR4 launcher app, `susamune_ghosts`, `susamune.ini`, PBs,
  Records, achievements, and progress before copying PR5.
- Keep QFT visible during timing tests. Any timing/result difference is a release
  blocker.
- Stop after a hard crash, white screen, looping crash sound, input-dead screen,
  persistence corruption, or camera/input that is not restored. Record region,
  disc ID, stage, exact input, and last visible message.
- Test with one complete package only. Homebrew Channel must show
  `Susamune Launcher SIGMA` and
  `V2.0.0 "Ghosts of Delfino" Pre-release 5`.

- PR5 を copy する前に、PR4 launcher app、`susamune_ghosts`、`susamune.ini`、PB、
  Records、achievements、progress を完全に backup してください。
- timing test 中は QFT を表示します。timing／result の差は release blocker です。
- hard crash、white screen、looping crash sound、input-dead screen、persistence corruption、
  camera／input が戻らない問題があれば中止し、region、disc ID、stage、正確な input、
  最後の表示を記録します。
- 1 つの完全な package だけを使用します。Homebrew Channel には
  `Susamune Launcher SIGMA` と
  `V2.0.0 "Ghosts of Delfino" Pre-release 5` が表示される必要があります。

## Decisive JP/PAL smoke test / 決定的な JP／PAL smoke test

1. Open retail Shine Select and enter Bianco Hills 4. Repeat once on JP and PAL.
   The intro must load normally: no white screen, hang, or looping crash sound.
2. Enter one different Shine through retail Shine Select as a control.
3. Start and exit Watch, then repeat Bianco 4 once. The camera hook must have
   restored the retail instruction.
4. Achieve an eligible selected-IL PB and leave its ghost unsaved. Open an IL
   that would leave the level. The confirmation must remain animated and accept
   a release followed by a new A or B press on both JP and PAL.
5. Open the Ghost Race/Watch chooser. Hold the opening A, release it, then test
   A Race, Y Watch, X Watch 2, and B Cancel. No held opener may select an action,
   and no screen may become input-dead.
6. Confirm Ghost Display and Ghost Opacity now appear at the top of the Ghosts
   tab, change from A and C-stick left/right, and no longer duplicate in UI.
7. Verify the panorama, outlined launcher text, and `bgm.mp3` together, then
   launch the game. There must be no black screen or audio-thread hang.

1. retail Shine Select から Bianco Hills 4 に入ります。JP と PAL で 1 回ずつ繰り返します。
   intro は white screen、hang、looping crash sound なしで正常に load する必要があります。
2. control として別の Shine も retail Shine Select から 1 つ開始します。
3. Watch を開始して終了し、Bianco 4 をもう一度確認します。camera hook は retail
   instruction に復元されている必要があります。
4. eligible selected IL PB を達成して ghost を未保存のままにし、別 IL を選びます。
   確認画面は動き続け、JP／PAL の両方で一度 release した後の新しい A／B press を
   受け付ける必要があります。
5. Ghost Race／Watch chooser を開きます。opening A を押し続け、一度離してから
   A Race、Y Watch、X Watch 2、B Cancel を確認します。opening button の hold で action が
   選ばれたり、input-dead screen になったりしてはいけません。
6. Ghost Display と Ghost Opacity が Ghosts tab 上部に移動し、A と C-stick left／right で
   変更でき、UI category に duplicate していないことを確認します。
7. panorama、outlined launcher text、`bgm.mp3` を同時に確認して game を launch します。
   black screen や audio-thread hang があってはいけません。

## Unsaved-PB protection / 未保存 PB の保護

Create a fresh accepted PB before each destructive-path group. The prompt must
show the PB ghost name. A means deliberate discard and B means cancel/keep. The
button that opened a screen must not also confirm it; release and press again.

各 destructive-path group の前に新しい受理済み PB を作ります。prompt は PB ghost name を
表示する必要があります。A は明示的な discard、B は cancel／keep です。screen を開いた
button だけで confirm してはいけません。一度離してからもう一度押します。

1. Test retail Exit Area, Exit Area level select, Warp Wheel, Warp Last, instant
   level select, Instant Restart, Full Restart, parent restart, and return to
   title. Cancel once, then confirm once. Cancel must leave the PB saveable;
   confirm must execute exactly once and remove only the shown PB.
2. Enter an ordinary pipe/door/loading-zone departure with an unsaved PB. It
   must not silently destroy it. Cancel/hold must return safely; deliberate
   confirmation may continue the departure.
3. Test Savestate Load. Savestate Save must remain immediate and harmless;
   Load must confirm before destroying an accepted PB.
4. Test Ghost Target Clear, loading/racing another ghost, Watch/Watch 2, profile
   changes that replace a target, and any other Ghost action that needs the
   record/playback buffer. No accepted PB may disappear without confirmation.
5. Save the PB instead. The Save prompt must name that PB even if another run or
   imported race target exists. After the successful storage ACK, the original
   destructive action must proceed without a stale warning.
6. After an accepted PB, confirm Instant Restart. The discarded PB must no
   longer appear as a phantom `Save ...?` candidate.
7. If record and playback both hold accepted unsaved PBs, the action must show
   them one at a time and execute only after both are saved or discarded.
8. Exercise cancel, CARD busy, savestate restore, stage handoff, and changed
   ghost identity while a prompt is open. A stale token must never authorize a
   different PB or leave input disabled.
9. Equal/slower, assisted, fast-forward, partial, imported, and already-saved
   ghosts must not be mislabeled as accepted unsaved PBs.

1. retail Exit Area、Exit Area level select、Warp Wheel、Warp Last、instant level
   select、Instant Restart、Full Restart、parent restart、title return を確認します。
   1 回 cancel、1 回 confirm します。cancel 後は PB を保存でき、confirm は 1 回だけ実行され、
   表示中の PB だけを削除する必要があります。
2. 未保存 PB のまま通常の pipe／door／loading-zone departure に入ります。silent discard は
   禁止です。cancel／hold は安全に戻り、明示的な confirm 後だけ departure を続けます。
3. Savestate Load を確認します。Savestate Save は即時で安全なまま、Load は受理済み PB を
   破棄する前に confirm する必要があります。
4. Ghost Target Clear、別 ghost の load／Race、Watch／Watch 2、target を置き換える profile
   change、および record／playback buffer が必要な Ghost action を確認します。受理済み PB が
   confirmation なしで消えてはいけません。
5. discard ではなく PB を Save します。別 run や imported race target が存在しても Save
   prompt はその PB 名を表示する必要があります。storage ACK 成功後は stale warning なしで
   元の destructive action を実行できます。
6. 受理済み PB 後に Instant Restart を confirm します。破棄済み PB が phantom
   `Save ...?` candidate として残ってはいけません。
7. record と playback の両方に受理済み未保存 PB がある場合、1 つずつ表示し、両方を
   save または discard するまで action を実行してはいけません。
8. prompt 中の cancel、CARD busy、savestate restore、stage handoff、ghost identity change を
   確認します。stale token が別 PB を許可したり input disabled を残したりしてはいけません。
9. 同タイム／遅い、assisted、fast-forward、partial、imported、保存済み ghost を受理済み
   未保存 PB と誤認してはいけません。

## Launcher theme and BGM / Launcher theme と BGM

1. Delete `theme`, boot once, and verify the launcher recreates it beside the
   app on the launcher device.
2. Add a valid exact 1024x480 `background.png`. Black text must have a clear
   white outline on both bright and dark parts of the panorama.
3. Add the known Mare `bgm.mp3` (3,111,007 bytes) and reboot repeatedly. Music
   must start, loop, and remain responsive while storage devices are checked.
4. Launch JP/PAL/US, return to the loader where supported, and use poweroff.
   Music must stop cleanly before every handoff; no black screen or stuck audio
   thread is allowed.
5. Test missing, truncated, malformed, and over-4-MiB MP3 files. Each must fall
   back to silence with a nonfatal message, while the panorama and game launch
   still work.
6. If available, test launcher-on-SD/game-on-USB and launcher-on-USB/game-on-disc.
   Both theme files must follow the launcher device and app directory.

1. `theme` を削除して一度 boot し、launcher device 上の app の隣に自動作成されることを
   確認します。
2. 正確に 1024x480 の有効な `background.png` を追加します。panorama の明るい部分と暗い
   部分の両方で、black text に明確な white outline が必要です。
3. 既知の Mare `bgm.mp3`（3,111,007 bytes）を追加して複数回 reboot します。storage device
   check 中も music が開始、loop し、launcher が操作可能である必要があります。
4. JP／PAL／US を launch し、対応する場合は loader return と poweroff も確認します。
   music はすべての handoff 前に clean に停止し、black screen／stuck audio thread は禁止です。
5. missing、truncated、malformed、4 MiB 超の MP3 を確認します。nonfatal message と silence に
   fallback し、panorama と game launch は引き続き動作する必要があります。
6. 可能なら launcher-on-SD／game-on-USB と launcher-on-USB／game-on-disc を確認します。
   両方の theme file は launcher device と app directory に従う必要があります。
