# Susamune V2.1.0 Pre-Release 3 "Hot Streak" Testing

This is the English hardware acceptance pass for Pre-Release 3. Please include
the disc region and whether the test used Wii hardware or Dolphin in reports.

## Identity and smoke test

1. Confirm Homebrew Channel shows `Susamune Launcher DELTA` and
   `V2.1.0 Pre-Release 3 "Hot Streak"`.
2. Boot the normal save and confirm Settings, binds, PBs, achievements, ghosts,
   themes, and BGM are still present.
3. Open Settings and confirm Creation remains under Presentation and Stage
   session display is no longer duplicated in Display.

## Retail Exit Area — priority blocker gate

1. Start a Streaking session, pause before finishing, choose Exit Area, and
   confirm the streak ends immediately without `Course warp cancelled`.
2. Repeat from a Stage Loader playlist.
3. Repeat with Area Lock enabled. Explicit Exit Area must still leave.
4. Confirm all three return to post-Corona Plaza, never Flooded Plaza.
5. Use the Warp Wheel to visit Flooded Plaza once, warp into a normal level,
   then use Exit Area. The return must be post-Corona Plaza.
6. With a threatened PB ghost, verify Exit Area shows the normal exact-token
   save/discard flow and exits only after every threatened PB is resolved.

## Completion/departure ordering — priority blocker gate

1. Complete the last required Streaking Shine, then press B+D-up during the
   Shine demo. The session report must appear before the restart loads.
2. Dismiss the report. Confirm the requested restart then proceeds.
3. Repeat with the last entry of a Stage Loader playlist.
4. Repeat without pressing a restart. The report must appear before the
   natural level departure.
5. Confirm PB protection appears after the session report, not before it.
6. Reset normally in the middle of an unfinished attempt. It must remain an
   ordinary fast reset and must not wait for a result screen.

## Queue and built-in playlists

1. Fill all 120 positions, including duplicate routes. Position 120 must run;
   position 121 must be rejected cleanly.
2. Remove and reorder the first, middle, and last rows. C-left/right world
   jumps and A add/remove must keep selecting the intended rows.
3. Load Fast Any% and verify it contains 43 routes in the supplied order,
   including Pinna Park EYG after Pinna 4.
4. Load All Secrets and verify its nine Secret routes.
5. Load Reds World Tour and verify its 24 routes, including Gelato 4 Inside,
   Airstrip Reds, Grass Secret, Pachinko, and Lily Pad.
6. Run Fast Any% with Fast Text enabled. It must remain enabled through Pianta
   4, turn off for Pianta 5 and its retries, then restore for Pianta 6.
7. Cancel during Pianta 5 and confirm the user's Fast Text preference restores.
8. Start with Fast Text disabled and confirm the preset never turns it on.

## Custom playlist SD journal

1. Save and reload Custom 1, Custom 4, and Custom 7 with different lengths,
   including a 120-entry list and duplicates.
2. Power-cycle between saves and confirm the newest valid generation loads.
3. Confirm a built-in preset can be saved as a custom route order. Reloading
   that custom list must not claim the built-in Pianta 5 automation.
4. Test while disc reads are busy; the request may wait but must not corrupt,
   hang, or starve DI.

## Session display and report

1. In the Stage Loader menu, cycle Full notification, Counter, and Off with A
   and C-left/right. Reopen the game and confirm the choice persisted.
2. Counter must remain compact; Off must hide transient notices only.
3. Final reports are mandatory in all three display modes.
4. Verify attempts, completes, active time, and average time across successful
   finishes, target misses, deaths, and resets. Golds should display `--`.

## Regression gates

1. Test Yoshi, fruit, the Pinna spring, Secret/Reds routing, and Pinna EYG.
2. Test IL Select and Warp Wheel as explicit ways to abandon an unfinished
   session and select another level.
3. Test Watch enter/exit, intro skip input release, savestate save/load, and
   Pause Title with no stuck input or invisible modal.
4. Run ghost-format, ghost-storage, playlist persistence, protected-QFT hash,
   MEM1/MEM2 bounds, manifest, BPS, and all-six-region build verification.
