# V2.0.0 "Ghosts of Delfino" Pre-release 8

## English

Pre-release 8 fixes the remaining ghost timing and retail Shine Select
failures found during PR7 hardware testing. It also adds persistent crash
reports for future console diagnostics. The PB save/discard flow is unchanged
from PR7 and remains compatible.

### Retail Shine Select crash

- Fixed the generic Shine Select-to-stage crash on JP and PAL. A natural
  Delfino Plaza entry can auto-arm an IL. During the next asynchronous stage
  load, the newly allocated director is not ready and its HUD pointer is not
  initialized. IL tracking could follow that arbitrary pointer before
  `setupObjects()` completed.
- IL tracking now requires a fully live stage before reading director, HUD,
  Mario, or FLUDD objects. Context-independent PB storage and attempt cleanup
  continue during selectors and loads.
- This explains why Bianco 4, Bianco 5, and Pianta 5 crashed through retail
  Shine Select but loaded through Susamune Level Select.

### Correct-QFT ghost playback

- Race no longer holds the first pose during the recording-validity settle
  window. It seeks the current QFT immediately and safely reseeks if the clock
  later rebases.
- Watch and Watch 2 no longer start a separate wall clock after normal gameplay
  begins. They use the same live QFT stored in the ghost, so entrance scenes,
  materialization, and secret intros consume the correct amount of recorded
  time.
- Later route segments translate their local reset QFT onto the recorded
  absolute timeline. Watch 2 retains each runner's recorded stagger.
- The V3 ghost format and existing ghost libraries are unchanged.

### Persistent crash reports

- Fatal CPU exceptions now publish a bounded, CRC-protected report from the
  crashed PPC to Nintendont's ARM kernel. No allocation or file access occurs
  inside the exception callback.
- Once disc I/O is idle, the kernel rotates
  `susamune_crash_a.txt` / `susamune_crash_b.txt` and matching `.bin` files at
  the root of the launcher device.
- Reports include the region/build identity, exception registers, scene and
  director breadcrumbs, a validated stack backtrace, and bounded PC, LR,
  stack, director, and Mario memory windows. They do not attempt an unsafe full
  RAM dump.
- A true infinite loop that raises no CPU exception cannot be captured by this
  mechanism.

### Compatibility

- Settings, binds, V3 ghosts, PBs, Records, achievements, progress, savestates,
  panorama, and `bgm.mp3` remain compatible.
- QFT source, ghost file layout, memory reserve, and savestate format are
  unchanged.

## 日本語

Pre-release 8 は PR7 hardware test で残った ghost timing と retail Shine Select
failure を修正します。また、今後の console diagnosis 用に persistent crash report を
追加します。PR7 の PB save／discard flow は変更せず、互換です。

### Retail Shine Select crash

- JP／PAL の generic Shine Select-to-stage crash を修正しました。Delfino Plaza の natural
  entry は IL を auto-arm できます。次の async stage load 中、新しい director は未準備で、
  HUD pointer も initialize されていません。IL tracking が `setupObjects()` 完了前に arbitrary
  pointer を参照する可能性がありました。
- IL tracking は director、HUD、Mario、FLUDD object を読む前に fully live stage を要求します。
  context-independent PB storage と attempt cleanup は selector／load 中も継続します。
- Bianco 4、Bianco 5、Pianta 5 が retail Shine Select では crash し、Susamune Level Select
  では load できた差を説明する修正です。

### Correct-QFT ghost playback

- Race は recording-validity settle window 中に first pose を hold しません。current QFT を
  immediately seek し、後から clock rebase が発生しても安全に seek し直します。
- Watch／Watch 2 は normal gameplay 後に別の wall clock を開始しません。ghost に保存された
  live QFT と同じ clock を使用し、entrance scene、materialization、secret intro の時間を
  recorded timeline 上で正しく消費します。
- 後続 route segment は local reset QFT を recorded absolute timeline へ translate します。
  Watch 2 は runner ごとの recorded stagger を保持します。
- V3 ghost format と既存 ghost library は変更していません。

### Persistent crash reports

- fatal CPU exception は crashed PPC から Nintendont ARM kernel へ bounded／CRC-protected report
  を publish します。exception callback 内では allocation／file access を行いません。
- disc I/O が idle になった後、launcher device root の `susamune_crash_a.txt`／
  `susamune_crash_b.txt` と matching `.bin` を rotate します。
- region／build identity、exception register、scene／director breadcrumb、validated stack
  backtrace、bounded PC／LR／stack／director／Mario memory window を記録します。unsafe な full
  RAM dump は行いません。
- CPU exception を発生しない真の infinite loop は、この mechanism では capture できません。

### Compatibility

- settings、binds、V3 ghosts、PB、Records、achievements、progress、savestate、panorama、
  `bgm.mp3` は互換です。
- QFT source、ghost file layout、memory reserve、savestate format は変更していません。
