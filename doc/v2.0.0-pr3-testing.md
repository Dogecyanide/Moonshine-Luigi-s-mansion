# Susamune V2.0.0 "Ghosts of Delfino" Pre-release 3 Testing / テストガイド

## Purpose / 目的

Pre-release 3 is a focused safety and ghost-animation rebuild. It replaces the
Pre-release 2 ghost format, removes the unsafe launcher MP3 path, and replaces
the discard-warning heuristic with an unsaved-PB-only rule. This remains an
experimental test build, not a release candidate.

Pre-release 3 は、安全性とゴーストアニメーションに集中した再構築版です。
Pre-release 2 のゴースト形式を置き換え、危険だったランチャーの MP3 経路を削除し、
破棄警告を「未保存の PB のみ」に変更します。これは引き続き実験用テスト版であり、
リリース候補ではありません。

## Hard safety rules / 必須の安全規則

- Keep QFT visible during every timing test. Its timing, capture cadence, and
  result logic must match Pre-release 2 exactly.
- Back up `susamune_ghosts` before testing. V1/V2 ghosts are intentionally
  unsupported by the new V3 animation format. Start PR3 with an empty library.
- Do not mix launcher files from different packages. The Homebrew Channel must
  show `Susamune Launcher SIGMA` and `V2.0.0 "Ghosts of Delfino" Pre-release 3`.
- Keep `susamune.ini`, PB, Records, progress, and achievement files. Only the
  ghost library is intentionally reset.
- Stop immediately on a freeze, black screen, QFT discrepancy, heap warning,
  corrupted save, or real-Mario visual corruption. Record the region, stage,
  action, and last visible message.

- すべての計測テストで QFT を表示してください。計測、capture cadence、result
  logic は Pre-release 2 と完全に一致する必要があります。
- テスト前に `susamune_ghosts` をバックアップしてください。新しい V3
  アニメーション形式では V1/V2 ゴーストを意図的に非対応とします。PR3 は空の
  ghost library から開始してください。
- 異なるパッケージのランチャーファイルを混ぜないでください。Homebrew Channel
  には `Susamune Launcher SIGMA` と
  `V2.0.0 "Ghosts of Delfino" Pre-release 3` が表示される必要があります。
- `susamune.ini`、PB、Records、progress、achievement は保持してください。
  意図的にリセットするのは ghost library だけです。
- freeze、black screen、QFT の差、heap 警告、save corruption、実 Mario の表示異常が
  あれば直ちに中止し、region、stage、操作、最後のメッセージを記録してください。

## Package and migration preflight / パッケージと移行の事前確認

1. Verify that `TESTING.md` is this complete non-empty bilingual guide.
2. Move the old `susamune_ghosts` directory to a dated backup. Do not delete it
   until PR3 has passed testing.
3. Copy only the seven files from one fresh launcher package into the launcher
   app directory.
4. Boot once without a `theme` directory. Confirm the launcher creates it on
   the same device and in the same app directory from which it was launched.
5. Confirm all four PB profiles, settings, binds, Records, achievements, and
   global progress still load.
6. Place one old V1/V2 `.smsghost` in the import directory. It must be refused
   as unsupported and must never be interpreted as V3.

1. `TESTING.md` が、この完全な空でない日英ガイドであることを確認します。
2. 旧 `susamune_ghosts` directory を日付付き backup へ移動します。PR3 のテストが
   完了するまで削除しないでください。
3. 1 つの新しい launcher package から 7 files のみを app directory へコピーします。
4. `theme` directory がない状態で一度起動し、起動元と同じ device、同じ app
   directory に自動作成されることを確認します。
5. 4 PB profiles、settings、binds、Records、achievements、global progress が保持されて
   いることを確認します。
6. 旧 V1/V2 `.smsghost` を import directory に置きます。unsupported として拒否され、
   V3 として解釈されないことを確認します。

## Ghost animation and rendering / ゴーストのアニメーションと描画

1. Record standing, walking, running, jumping, spin jumping, diving, sliding,
   wall-kicking, swimming, talking, carrying, and shine-grab samples.
2. Race each sample. The visible model must be the retail Shadow Mario model,
   not ordinary Mario, and it must not remain in the bind-pose/T-pose.
3. Stop, turn, talk, or spin with the live Mario while the ghost follows a
   different recorded action. The ghost must follow its recorded base-body
   animation rather than copying the live player's current pose.
4. Expect a bounded approximation: PR3 records the base body animation and
   phase, but not motion blending, FLUDD, hands, accessories, Yoshi, or other
   secondary rigs. Report pops or wrong base-body animations separately from
   those documented omissions.
5. Test 25%, 50%, 75%, and 100% opacity. The complete 3D silhouette must change
   monotonically; real Mario's goop/material must not change.
6. Test parent stages and child stages, including Sirena 4's hotel/casino/secret
   route. Missing native assets must use the cyan fallback without crashing.
7. Record and play a 14:58 or longer ghost. The 15-minute cap, multi-stage
   timing, and partial-save behavior must remain intact.

1. standing、walking、running、jump、spin jump、dive、slide、wall kick、swim、talk、
   carry、shine grab を含む ghost を記録します。
2. 各 ghost と race し、通常の Mario ではなく retail Shadow Mario model が表示され、
   bind pose／T-pose のままにならないことを確認します。
3. live Mario で停止、方向転換、会話、spin を行いながら、ghost に別の動作を再生させます。
   ghost は live player の現在 pose ではなく、記録した base-body animation に従う必要が
   あります。
4. PR3 は bounded approximation です。base body animation と phase は記録しますが、
   motion blend、FLUDD、hands、accessories、Yoshi、secondary rigs は記録しません。
   既知の省略と、誤った base-body animation／大きな pop は分けて報告してください。
5. opacity 25%、50%、75%、100% を確認します。3D silhouette 全体が段階的に変化し、
   実 Mario の goop／material が変化してはいけません。
6. Sirena 4 の hotel／casino／secret route を含む parent／child stage を確認します。
   native asset がない場合は crash せず cyan fallback を使用する必要があります。
7. 14:58 以上の ghost を記録・再生し、15 分上限、multi-stage timing、partial save が維持
   されていることを確認します。

## Unsaved PB protection / 未保存 PB の保護

The warning protects only a newly accepted IL personal-best ghost that has not
been saved. It must not warn for an equal/worse run, ordinary partial ghost,
imported target, assisted run, fast-forwarded run, or route-preserving restart.

警告対象は、新しく IL PB として正式に受理され、まだ保存されていない ghost のみです。
同タイム／遅い run、通常の partial ghost、imported target、assisted run、fast-forward run、
同一 route restart では警告してはいけません。

1. Finish an eligible selected IL with a new PB and do not save its ghost.
2. Try a Warp Wheel course change, IL start, Warp Last, and any other supported
   Susamune course departure. Each destructive departure must show the PB name.
3. Press B. The prompt must close, Mario must resume, and no warp may occur.
   Repeat opening and cancelling at least ten times; there must be no softlock.
4. Open again and press A. The requested departure must occur exactly once.
5. Earn another PB, save its ghost successfully, then depart. No warning should
   appear for that saved PB.
6. Run an equal/worse result and an assisted/fast-forward result. Neither may
   create PB protection.
7. Use Instant Restart and Full Restart on the same logical route. Neither may
   warn. Child/parent transitions inside one multi-stage route must not warn.
8. Earn an unsaved PB, open retail pause, and choose Exit Area. Retail pause must
   resume safely before Susamune shows its modal. B resumes gameplay; A performs
   the Exit Area destination exactly once. Never hold a closed retail pause menu.
9. Repeat step 8 with Exit Area Everywhere and its level selector enabled.
10. Repeat prompt tests while CARD/config I/O is busy, after a savestate load,
    and with warps disabled. No stale warp, duplicate warp, or hidden prompt is
    allowed.

1. eligible な selected IL で新 PB を達成し、ghost を保存しません。
2. Warp Wheel course change、IL start、Warp Last、その他対応する Susamune course
   departure を試します。破棄の可能性がある場合は PB 名を表示する必要があります。
3. B を押します。prompt が閉じ、Mario が再開し、warp は発生してはいけません。
   10 回以上繰り返しても softlock してはいけません。
4. 再度開いて A を押し、要求した departure が 1 回だけ実行されることを確認します。
5. 別の PB を達成して ghost の保存完了後に departure します。保存済み PB の警告は
   表示されてはいけません。
6. 同タイム／遅い result と assisted／fast-forward result を実行し、PB protection が
   作成されないことを確認します。
7. 同じ logical route で Instant Restart と Full Restart を使います。警告してはいけません。
   1 つの multi-stage route 内の child／parent transition も警告してはいけません。
8. 未保存 PB を作り、retail pause の Exit Area を選びます。Susamune modal の前に retail
   pause が安全に resume する必要があります。B は gameplay 再開、A は Exit Area を 1 回
   だけ実行します。閉じた retail pause menu を保持してはいけません。
9. Exit Area Everywhere と level selector を有効にして手順 8 を繰り返します。
10. CARD／config I/O 中、savestate load 後、warps disabled でも prompt を確認します。
    stale warp、二重 warp、非表示 prompt は許可されません。

## Launcher theme safety / ランチャーテーマの安全性

1. Boot with an empty auto-created `theme` directory. Stock background and
   normal launch must work.
2. Place the known Mare `background.png` (exactly 1024x480) in that directory.
   Reboot repeatedly and launch JP, US, and PAL. It must display without a black
   screen or hang, then release its memory before kernel handoff.
3. Test missing, malformed, wrong-dimension, and over-limit PNG files. Each must
   fall back to the stock background and continue booting.
4. Place `bgm.mp3` beside the image. PR3 intentionally ignores custom music;
   the file's presence must never initialize audio or change boot behavior.
5. Test the launcher from SD and USB where available, including an ISO on the
   other device. The theme path follows the launcher device, not the game device.

1. 自動作成された空の `theme` directory で起動し、stock background と通常起動を確認します。
2. 既知の Mare `background.png`（正確に 1024x480）を置き、複数回再起動して JP／US／PAL
   を起動します。black screen／hang せず表示され、kernel handoff 前に memory が解放される
   必要があります。
3. missing、malformed、wrong-dimension、over-limit PNG を試します。すべて stock background
   へ fallback し、boot を続行する必要があります。
4. `bgm.mp3` を画像の隣に置きます。PR3 は custom music を意図的に無視します。
   file が存在しても audio 初期化や boot 動作を変えてはいけません。
5. 可能なら SD／USB の両方から launcher を起動し、game ISO を別 device に置く組合せも
   確認します。theme path は game device ではなく launcher device に従います。

## Required regional pass / 必須 region テスト

Use at least one PAL tester, one JP tester, and one independent third tester.
Run the complete animation, PB prompt, QFT, and launcher-theme core on PAL and
JP hardware. Run US parity on hardware or Dolphin plus an independent console
cross-check. Cross-region sharing requires JP->PAL, PAL->JP, and at least one
US-involved direction. Record build checksum, disc ID, device layout, and every
failure's exact reproduction steps.

PAL tester 1 人、JP tester 1 人、独立した 3 人目を使用します。PAL／JP hardware では、
animation、PB prompt、QFT、launcher theme の core test をすべて実行します。US は hardware、
または Dolphin と独立 console cross-check で parity を確認します。cross-region sharing は
JP->PAL、PAL->JP、US を含む方向を最低 1 つ確認します。build checksum、disc ID、device
layout、failure の正確な再現手順を記録してください。
