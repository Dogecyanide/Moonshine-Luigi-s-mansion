# Susamune V2.0.0 "Ghosts of Delfino" Pre-release 8 Testing / テストガイド

## Purpose / 目的

PR8 validates three release blockers: retail Shine Select loading, correct-QFT
Race/Watch playback, and permanent hardware crash reporting. Do not begin the
planned Records/achievement expansion until this matrix is green.

PR8 は retail Shine Select load、correct-QFT Race／Watch playback、permanent hardware
crash report の 3 blocker を validate します。この matrix が green になるまで、予定している
Records／achievement expansion は開始しません。

## Hard safety rules / 必須の安全規則

- Back up the PR7 launcher app, `susamune_ghosts`, `susamune.ini`, PBs, Records,
  achievements, and progress before copying PR8.
- Homebrew Channel must show `V2.0.0 "Ghosts of Delfino" Pre-release 8`.
- Stop after a white screen, looping crash sound, input-dead screen, unbounded
  load, persistence corruption, or failure to restore Mario/camera state.
- After any hard crash, leave the Wii on the crash screen for about five
  seconds, power-cycle, then copy every `susamune_crash_a/b.txt` and `.bin` file
  from the launcher-device root. Record region, disc ID, real disc versus ISO,
  ISO device, stage, and exact action.

- PR8 を copy する前に、PR7 launcher app、`susamune_ghosts`、`susamune.ini`、PB、
  Records、achievements、progress を backup してください。
- Homebrew Channel は `V2.0.0 "Ghosts of Delfino" Pre-release 8` を表示する必要があります。
- white screen、looping crash sound、input-dead screen、unbounded load、persistence
  corruption、Mario／camera restore failure が発生したら中止してください。
- hard crash 後は crash screen のまま約 5 秒待ち、power-cycle してから launcher-device root
  の `susamune_crash_a/b.txt` と `.bin` をすべて copy してください。region、disc ID、real
  disc／ISO、ISO device、stage、exact action も記録します。

## 1. Retail Shine Select / retail Shine Select

Run these first from a fresh power-on, before loading a Race or Watch target.

Race／Watch target を load する前の fresh power-on から最初に実行します。

1. Load the same normal save used for PR7. Walk from Delfino Plaza into the
   Bianco portal and enter Bianco 4, then Bianco 5, through retail Shine
   Select. Both must load without a white screen or looping crash sound.
2. Enter Pianta 5 through its retail Shine Select. This is the third confirmed
   PR7 crash case and must also load.
3. Use Susamune Level Select for B4, B5, and P5 as controls. Compare episode,
   spawn, story state, QFT start, and ghost recording behavior.
4. Repeat at least five more retail Shine Select entries, including JP and PAL.
   Test US parity if available. Repeat once with an ISO and once with a real
   disc if both paths are available.
5. Repeat B4 after Race, Watch, Watch 2, saving a PB ghost, and rebooting the
   launcher. No selector/load frame may show stale Mario, metadata, or ghosts.

1. PR7 と同じ normal save を load します。Delfino Plaza から Bianco portal に入り、retail
   Shine Select で Bianco 4、次に Bianco 5 を開始します。white screen／looping crash sound
   なしで load する必要があります。
2. Pianta 5 を retail Shine Select から開始します。PR7 で確認された 3 番目の crash case
   なので、これも正常に load する必要があります。
3. control として Susamune Level Select から B4、B5、P5 を開始し、episode、spawn、story
   state、QFT start、ghost recording behavior を比較します。
4. retail Shine Select の別 entry を少なくとも 5 つ、JP／PAL で確認します。可能なら US parity、
   ISO path、real disc path も確認します。
5. Race、Watch、Watch 2、PB ghost save、launcher reboot 後にも B4 を再確認します。
   selector／load frame 中に stale Mario、metadata、ghost を表示してはいけません。

## 2. Race timing / Race timing

1. Race a saved ghost in an ordinary stage with QFT visible. Compare live QFT
   with the ghost at the start, after materialization, and at three landmarks.
   The ghost must seek immediately; there must be no roughly one-second first-
   pose hold.
2. Repeat with a secret whose entrance intro is not manually skipped. The ghost
   must already be at the recorded QFT when gameplay begins.
3. Repeat with a late manual intro skip and with persisted Stage Intro Skip On
   and Off. A clock rebase may reseek, but must not freeze, teleport permanently,
   or corrupt recording eligibility.
4. Repeat a multi-stage route and a cross-region JP↔PAL/US import.

1. QFT を表示し、ordinary stage で saved ghost と Race します。start、materialization 後、
   3 landmark で live QFT と ghost を比較します。immediate seek が必要で、約 1 秒の first-pose
   hold は禁止です。
2. entrance intro を manual skip しない secret でも繰り返します。gameplay 開始時点で ghost は
   recorded QFT の位置にいる必要があります。
3. late manual intro skip、persisted Stage Intro Skip On／Off でも確認します。clock rebase 後の
   reseek は許可しますが、freeze、permanent teleport、recording eligibility corruption は禁止です。
4. multi-stage route と JP↔PAL／US cross-region import でも繰り返します。

## 3. Watch and Watch 2 timing / Watch／Watch 2 timing

1. With persisted Stage Intro Skip Off, Watch a normal-stage ghost and a Gelato
   secret ghost. Playback must initialize as soon as live QFT is readable,
   including opening states, rather than waiting for `STATE_NORMAL`.
2. Keep QFT visible. At the end of any intro, the runner must be at the sample
   corresponding to that QFT, not at its first pose.
3. Watch 2 identical ghosts to confirm overlap, then ghosts with different
   recorded starts to confirm their stagger is preserved.
4. Test a multi-segment route. Later segments must translate their reset local
   QFT onto the recorded route timeline without a late spawn.
5. End using B, Start, natural completion, fast-forward refusal, and an
   unexpected route failure. Mario input/visibility, camera, intro setting,
   Records eligibility, and Attempt Counter must recover.
6. Very distant runners may still frame imperfectly with the retail camera.
   Unbounded acceleration or failure to restore remains a blocker.

1. persisted Stage Intro Skip Off で normal-stage ghost と Gelato secret ghost を Watch します。
   `STATE_NORMAL` を待たず、opening state を含め live QFT が readable になった時点で playback
   を initialize する必要があります。
2. QFT を表示します。intro 終了時、runner は first pose ではなく、その QFT に対応する sample
   にいる必要があります。
3. identical ghost 2 つで Watch 2 の overlap を確認し、recorded start が異なる ghost で stagger
   が保持されることを確認します。
4. multi-segment route を確認します。後続 segment は reset local QFT を recorded route timeline
   に translate し、late spawn を起こしてはいけません。
5. B、Start、natural completion、fast-forward refusal、unexpected route failure で終了します。
   Mario input／visibility、camera、intro setting、Records eligibility、Attempt Counter を restore
   する必要があります。
6. 非常に離れた runner は retail camera で imperfect framing になる場合があります。ただし
   unbounded acceleration／restore failure は blocker です。

## 4. Crash-report validation / crash report validation

Do not intentionally corrupt a normal console merely to create a report. If a
natural exception occurs during this matrix:

report 作成だけを目的に normal console を意図的に corrupt しないでください。この matrix 中に
natural exception が発生した場合:

1. Confirm that the usual retail crash screen/behavior still occurs; the
   Susamune callback must not replace the game's handler.
2. Leave the crash screen up for about five seconds, power-cycle, and check the
   launcher-device root for the newest `susamune_crash_a.txt` or
   `susamune_crash_b.txt` and matching `.bin`.
3. Confirm the text names the correct JP/US/PAL region, PR8 build, exception,
   SRR0/LR, scenes, and last selector/stage breadcrumb.
4. Reproduce once more only if safe. The opposite A/B slot must be written so
   the first report remains recoverable.
5. Send both `.txt` and `.bin`; the binary is authoritative if formatting was
   interrupted. Absence of a report from a pure infinite loop is expected.

1. usual retail crash screen／behavior が継続することを確認します。Susamune callback は game の
   handler を replace してはいけません。
2. crash screen のまま約 5 秒待ち、power-cycle 後に launcher-device root の最新
   `susamune_crash_a.txt`／`susamune_crash_b.txt` と matching `.bin` を確認します。
3. text に正しい JP／US／PAL region、PR8 build、exception、SRR0／LR、scene、最後の
   selector／stage breadcrumb が含まれることを確認します。
4. 安全な場合だけもう一度再現します。反対側 A／B slot が書かれ、最初の report を保持する
   必要があります。
5. `.txt` と `.bin` の両方を送ってください。formatting が interrupted の場合は binary が
   authoritative です。pure infinite loop では report がないことがあります。
