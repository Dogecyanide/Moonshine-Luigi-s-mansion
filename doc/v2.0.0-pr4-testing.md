# Susamune V2.0.0 "Ghosts of Delfino" Pre-release 4 Testing / テストガイド

## Purpose / 目的

PR4 removes the unresponsive PB dialogs, repairs custom panorama loading, and
adds a bounded current-area visual Watch mode. It is an experimental hardware
test build, not a release candidate.

PR4 は操作不能になった PB dialog を廃止し、custom panorama を修正し、bounded な
current-area visual Watch mode を追加します。これは実機テスト用の実験版であり、
release candidate ではありません。

## Hard safety rules / 必須の安全規則

- Keep QFT visible during timing tests. Any QFT difference is release-blocking.
- Back up the PR3 `susamune_ghosts` directory, but do not clear it: V3 ghosts
  should remain compatible.
- Copy one complete PR4 package only. Homebrew Channel must show
  `Susamune Launcher SIGMA` and
  `V2.0.0 "Ghosts of Delfino" Pre-release 4`.
- Preserve `susamune.ini`, PBs, Records, achievements, and progress.
- Stop on a freeze, black screen, QFT discrepancy, corrupted persistence,
  camera that cannot be exited, or real-Mario visual corruption. Record region,
  stage, selected ghost, input, and last message.

- timing test 中は QFT を表示してください。QFT の差は release blocker です。
- PR3 の `susamune_ghosts` を backup しますが、削除しないでください。V3 ghost は互換で
  ある必要があります。
- 1 つの完全な PR4 package だけをコピーします。Homebrew Channel には
  `Susamune Launcher SIGMA` と
  `V2.0.0 "Ghosts of Delfino" Pre-release 4` が表示される必要があります。
- `susamune.ini`、PB、Records、achievements、progress を保持してください。
- freeze、black screen、QFT の差、persistence corruption、終了不能な camera、実 Mario の
  表示異常があれば中止し、region、stage、ghost、input、最後の message を記録します。

1. `TESTING.md` が完全で空でない日英 guide、`CHANGELOG.md` が PR4 の説明であることを

2. PR4 をコピーする前に live launcher app と `susamune_ghosts` を backup します。
3. 4 PB profiles、settings、binds、Records、achievements、progress、PR3 V3 personal
   ghosts、imported V3 ghosts が保持されていることを確認します。
4. launcher の `theme` directory を削除して一度起動し、launcher device 上の app の隣に
   自動作成されることを確認します。
5. `bgm.mp3` が存在しても無視されることを確認します。

## PB repeat guard: IL regression / PB repeat guard：IL 回帰確認

1. Finish an eligible selected IL with a new PB and leave its ghost unsaved.
2. In the IL menu, press A on a different IL. The menu must remain responsive
   and show `Unsaved PB: repeat action to discard`; no dialog may open.
3. Keep holding A beyond the menu repeat delay. It must not start the IL.
4. Release A, then press A again on the exact same IL within 15 seconds. It must
   start once.
5. Repeat step 2, then select a different IL, wait over 15 seconds, load a
   savestate, or save the PB ghost. Stale approval must not authorize a warp.
6. Repeat while CARD/config I/O is busy. A changed PB must cancel the delayed
   departure; the same approved PB may leave once I/O is idle.
7. Verify equal/slower, assisted, fast-forward, partial, imported, and saved
   ghosts never trigger this warning.

1. eligible な selected IL で新 PB を達成し、ghost を未保存のままにします。
2. IL menu で別 IL に A を押します。menu は操作可能なまま
   `Unsaved PB: repeat action to discard` を表示し、dialog は開いてはいけません。
3. menu repeat delay を超えて A を押し続けても IL を開始してはいけません。
4. A を離し、15 秒以内に同じ IL で再度 A を押すと 1 回だけ開始する必要があります。
5. 手順 2 の後で別 IL を選ぶ、15 秒以上待つ、savestate load、または PB ghost を保存し、
   stale approval が warp を許可しないことを確認します。
6. CARD／config I/O 中にも繰り返します。PB が変われば delayed departure は cancel され、
   同じ approved PB なら I/O idle 後に出発できます。
7. 同タイム／遅い、assisted、fast-forward、partial、imported、saved ghost では警告が
   出ないことを確認します。

## PB repeat guard: Exit and warps / PB repeat guard：Exit と warp

1. With an unsaved PB, choose retail Exit Area. Sunshine must resume normally,
   show the nonblocking warning, and accept input immediately.
2. Choose Exit Area again within 15 seconds. It must leave once. There must be
   no frozen pause object, modal, or softlock.
3. Repeat step 1 at least ten times without the second Exit selection. Gameplay
   must resume every time.
4. Repeat with Exit Area Everywhere/level select enabled and with Disable Warps
   enabled. The exact second Exit must still follow the intended retail/selected
   destination safely.
5. Test Warp Wheel, Warp Last, and instant level selection. First action warns;
   the exact repeated action leaves. A changed destination warns again.
6. Test Instant Restart, Full Restart, and route-preserving parent restart.
   These must never warn or discard the PB ghost.
7. Load a savestate or enter a natural loading zone after the first warning.
   Approval must be cleared.

1. 未保存 PB がある状態で retail Exit Area を選びます。Sunshine は通常 resume し、
   nonblocking warning を表示し、すぐ入力可能である必要があります。
2. 15 秒以内に Exit Area をもう一度選びます。1 回だけ出発し、frozen pause object、
   modal、softlock があってはいけません。
3. 2 回目を選ばず手順 1 を 10 回以上繰り返し、毎回 gameplay に戻れることを確認します。
4. Exit Area Everywhere／level select enabled と Disable Warps enabled でも繰り返します。
   正確な 2 回目の Exit は意図した retail／selected destination へ安全に移動します。
5. Warp Wheel、Warp Last、instant level selection を確認します。1 回目は warning、同じ操作を
   繰り返すと出発し、destination が変われば再度 warning する必要があります。
6. Instant Restart、Full Restart、route-preserving parent restart は警告せず、PB ghost を
   破棄してはいけません。
7. 最初の warning 後に savestate load または natural loading zone へ入り、approval が
   消えることを確認します。

## Watch mode / Watch mode

1. Enter the exact route represented by a saved V3 ghost. In Ghosts, press A on
   its row. The chooser must require a new press and show A Race, Y Watch,
   X select ghost 2, and B cancel.
2. Hold the A that opened the chooser. It must not immediately Race. Release it,
   then press A to verify ordinary Race still works.
3. Open again and press Y. After loading, the menu closes and the camera follows
   the animated primary Shadow ghost. Mario input is disabled during Watch.
4. Press B, then repeat using Start. Each must end Watch immediately, restore
   player control, and leave the camera usable.
5. Select X, choose a different saved ghost with A, and verify ghost 1 is the
   animated Shadow model while ghost 2 is a numbered cyan marker. They must be
   ahead/behind according to their own route times. If only ghost 2 is active
   at the earlier start or later end, the camera must follow its marker.
6. Try selecting the same ghost twice, an unsafe/missing row, a ghost without a
   segment for the current exact route, and a row changed during loading. Each
   must refuse/cancel safely.
7. Open/close the menu, retail pause, fast-forward, load a savestate, finish the
   segment, and enter a loading zone. Watch must pause or stop as documented,
   never retain disabled input or a stale camera.
8. Attempt an IL/PB/Records result during Watch. It must not receive credit and
   no new ghost recording may replace either watched track.
9. Leave an unsaved PB ghost, then attempt Watch. It must refuse until that PB
   is saved or deliberately discarded.
10. Repeat with personal/imported and JP/US/PAL cross-region V3 ghosts. Watch is
    visual-only: it is expected not to activate doors, NPCs, RNG, or transitions.

1. 保存済み V3 ghost が表す exact route に入り、Ghosts で row に A を押します。chooser は
   新しい press を要求し、A Race、Y Watch、X ghost 2 選択、B cancel を表示します。
2. chooser を開いた A を押し続けても直ちに Race してはいけません。一度離して A を押し、
   通常 Race が動くことを確認します。
3. 再度開いて Y を押します。load 後に menu が閉じ、camera が animated primary Shadow
   ghost を追います。Watch 中は Mario input が disabled になります。
4. B で終了し、Start でも繰り返します。直ちに Watch が終了し、player control と camera
   が正常に戻る必要があります。
5. X を選び、別の saved ghost を A で選びます。ghost 1 は animated Shadow model、
   ghost 2 は番号付き cyan marker で、各 route time に応じて ahead／behind になります。
   早い start／遅い end で ghost 2 だけが active の場合は camera が marker を追います。
6. 同じ ghost 2 回、unsafe／missing row、current exact route segment のない ghost、load 中に
   変化した row を試します。すべて安全に refuse／cancel する必要があります。
7. menu／retail pause、fast-forward、savestate load、segment finish、loading zone を確認します。
   Watch は仕様通り pause／stop し、input disabled や stale camera を残してはいけません。
8. Watch 中に IL／PB／Records result を試します。credit は付かず、新しい ghost recording が
   watched track を上書きしてはいけません。
9. 未保存 PB ghost を残して Watch を開始し、PB を保存または明示的に破棄するまで拒否される
   ことを確認します。
10. personal／imported および JP／US／PAL cross-region V3 ghost で繰り返します。Watch は
    visual-only であり、door、NPC、RNG、transition を動かさないことは仕様です。

## Launcher panorama / Launcher panorama

1. Boot with an empty auto-created `theme` directory. Stock background and
   launch must work.
2. Place the known Mare `background.png` (688,061 bytes, exactly 1024x480) in
   that directory. Reboot repeatedly; the panorama must appear and JP/US/PAL
   launch must not black-screen or hang.
3. Test a second valid 1024x480 PNG. Common RGB/RGBA/palette/gray images should
   either display or show a clear nonfatal rejection reason.
4. Test malformed, truncated, wrong-dimension, and over-2-MiB files. A short
   reason must appear and stock/solid fallback must continue booting.
5. Place `bgm.mp3` beside the image. It must remain ignored and must not change
   boot behavior.
6. If possible, test launcher-on-SD/game-on-USB and launcher-on-USB/game-on-disc.
   The theme path always follows the launcher device.

1. 自動作成された空の `theme` directory で stock background と launch を確認します。
2. 既知の Mare `background.png`（688,061 bytes、正確に 1024x480）を置き、複数回 reboot
   します。panorama が表示され、JP／US／PAL launch が black-screen／hang してはいけません。
3. 別の有効な 1024x480 PNG を確認します。一般的な RGB／RGBA／palette／gray image は表示、
   または明確な nonfatal rejection reason を出す必要があります。
4. malformed、truncated、wrong-dimension、2 MiB 超を試します。短い reason を表示し、
   stock／solid fallback で boot を続行する必要があります。
5. `bgm.mp3` を隣に置きます。無視され、boot 動作を変更してはいけません。
6. 可能なら launcher-on-SD／game-on-USB と launcher-on-USB／game-on-disc を確認します。
   theme path は常に launcher device に従います。
