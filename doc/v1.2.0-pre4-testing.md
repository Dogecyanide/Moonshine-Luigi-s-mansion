## English test guide

### Setup

- Confirm the Homebrew Channel metadata, launcher, and Records footer identify
  `V1.2.0 Pre-Release 4`, `Susamune Launcher ALPHA`, and
  `Trial By Sunshine`.
- Unless a step says otherwise, turn Stage Intro Skip off and do not load a
  savestate during the attempt.
- `Misc > RESET > Reset Records` is available for clean testing. After using
  it, wait until Records says `Progress saved`, then freshly restart or reload
  the target IL before testing a detector.
- On Dolphin, Records are still session-only. Perform the JP/US/PAL persistence
  checks on Wii/Nintendont.

### 1. GBS streak counter and lifecycle

Use **Getting There!** in Records > Achievements > Streaks. It has no time
limit: even a slow valid Gelato 8 finish counts.

1. With it locked, confirm its list row shows `0 / 5`.
2. Start in Gelato 1, perform GBS, and collect Gelato 8's Shine. Confirm the
   row shows `1 / 5`.
3. After the result has appeared, use Instant Restart and finish the same route
   again. It must show `2 / 5`; Instant Restart after a recorded result must
   not erase the streak.
4. Load a savestate during the next attempt, then check the row. It must return
   to `0 / 5`. A death, abandoned attempt, invalid attempt, or a completed
   different IL must likewise break an unfinished streak.
5. Finish the GBS route five clean times in succession. The row must advance
   through `1 / 5` to `5 / 5`, and unlock only on the fifth finish.

The counter is live-session progress; rebooting or Reset Records clears an
unfinished streak.

For the Ricco 100 alias smoke test, open **Deep End Dividend**, start Ricco 100
(E3) from Ricco 3, and finish under `1:55.000`. One run is enough for PR4: its
row must move from `0 / 5` to `1 / 5`.

### 2. NoHover correction

**NoHover** now means: collect Gelato 8's Shine from Gelato 1 without using
Hover or mounting Yoshi. Fruit is explicitly allowed and is necessary for the
route.

- Positive: use the required fruit, never use Hover or mount Yoshi, and collect
  the Shine. NoHover must unlock.
- Negative Hover: after Reset Records and a fresh restart, use Hover once and
  finish. It must remain locked.
- Negative Yoshi: reset and restart again, mount Yoshi, and finish. It must
  remain locked.

### 3. Hot Tub eligibility

Hot Tub requires Mario to enter the actual swimming state while alive in
Corona Mountain. Ordinary lava contact or dying does not count.

1. With Hot Tub locked, freshly load Corona, save and load a savestate, then
   use the fish-hit/lava setup to enter swimming. It must remain locked.
2. Use a full/default restart or leave and freshly reload Corona. Without
   loading a savestate, enter swimming while alive. Hot Tub must unlock.

This checks both savestate invalidation and the fresh-restart re-arm fix.

### 4. Reset Records and Factory Reset

Before resetting, record the Global, JP, US, and PAL values, retain a known PB,
and unlock one challenge that cannot be reconstructed from PBs (Hot Tub is
suitable).

1. Choose `Misc > RESET > Reset Records` and accept both confirmations.
2. Confirm Records stats, achievements, and live streak counters become zero.
   PB profiles, settings, binds, and Creation layouts must remain unchanged.
3. Wait for `Progress saved` before shutting down. Boot JP, US, and PAL in turn.
   All three regional Records banks and Global must remain reset.
4. Set a setting or bind away from its default and note the current PB and
   Records values. Run `Factory reset`. Settings, binds, and layouts should
   return to defaults, while PBs and Records must stay unchanged. This smoke
   test only needs one region.

Reset Records does **not** erase PB files. On boot or PB-profile reconciliation,
any elapsed-time, PB-coverage, or mastery achievement already proven by a
retained PB can unlock again. This is expected. Use an empty PB profile before
Reset Records when a completely blank achievement test is required.

### 5. Optional challenge confirmation

This is a useful confirmation, not a PR4 blocker:

- **Exterminator:** kill every Cataquack in Gelato 8. Leaving one alive must
  not unlock it; killing the final one must unlock it.

Report region, Wii/Nintendont or Dolphin, launcher checksum, exact restart or
savestate path, expected result, actual result, and the before/after counter.

## 日本語テストガイド

### 準備

- Homebrew Channelのメタデータ、ランチャー、Records画面下部に
  `V1.2.0 Pre-Release 4`、`Susamune Launcher ALPHA`、
  `Trial By Sunshine` と表示されることを確認してください。
- 特記がない限り、Stage Intro SkipをOFFにし、挑戦中にセーブステートを
  ロードしないでください。
- 初期化して試す場合は `Misc > RESET > Reset Records` を使用できます。
  実行後はRecordsに `Progress saved` と表示されるまで待ち、対象ILを
  新しくリスタートまたは再ロードしてから判定を試してください。
- DolphinのRecordsは引き続きセッション限定です。JP/US/PAL間の保存確認は
  Wii実機のNintendontで行ってください。

### 1. GBS連続回数とリセット条件

Records > Achievements > Streaks の **Getting There!** を使用します。
この実績にタイム条件はありません。遅い完走でも、有効なGelato 8完走なら
1回として数えられます。

1. 未解除の状態で、一覧の右側が `0 / 5` になっていることを確認します。
2. Gelato 1からGBSを行い、Gelato 8のShineを取得します。`1 / 5` に
   進むことを確認します。
3. リザルト表示後にInstant Restartを使い、同じルートをもう一度完走します。
   `2 / 5` になることを確認します。記録後のInstant Restartで連続回数が
   消えてはいけません。
4. 次の挑戦中にセーブステートをロードし、一覧を確認します。`0 / 5` に
   戻る必要があります。死亡、途中放棄、無効な挑戦、別ILの完走でも、
   未完成の連続回数はリセットされます。
5. GBSを有効な状態で5回連続完走します。`1 / 5` から `5 / 5` まで進み、
   5回目だけで解除されることを確認します。

このカウンターは現在のセッション内の連続記録です。再起動または
Reset Recordsで、未完成の連続回数は消えます。

Ricco 100の別エントリー判定は **Deep End Dividend** で簡単に確認します。
Ricco 3からRicco 100 (E3)を開始し、`1:55.000`未満で完走してください。
PR4では1回だけで十分です。`0 / 5` から `1 / 5` に進むことを確認します。

### 2. NoHoverの条件修正

**NoHover** の正しい条件は「Gelato 1からGelato 8のShineを、Hoverを
使わず、Yoshiに乗らず取得する」です。フルーツの使用は明確に許可されており、
このルートには必要です。

- 成功例: 必要なフルーツを使い、Hoverを使わずYoshiにも乗らずShineを
  取得すると解除されること。
- Hover失敗例: Reset Records後に新しくリスタートし、Hoverを一度使って
  完走しても解除されないこと。
- Yoshi失敗例: もう一度リセットとリスタートを行い、Yoshiに乗って完走しても
  解除されないこと。

### 3. Hot Tubの有効判定

Hot Tubは、Corona MountainでMarioが生存中に実際の「泳ぎ状態」へ入ると
解除されます。溶岩に触れただけ、または死亡しただけでは解除されません。

1. Hot Tubが未解除の状態でCoronaを新しくロードします。セーブステートを
   保存してロードした後、魚の攻撃と溶岩を使う手順で泳ぎ状態へ入ります。
   この場合は解除されないことを確認します。
2. Full/Default Restartを使うか、Coronaを出て新しくロードし直します。
   セーブステートをロードせず、生存中に泳ぎ状態へ入ると解除されることを
   確認します。

これにより、セーブステートによる無効化と、新しいリスタート後の再有効化を
同時に確認できます。

### 4. Reset RecordsとFactory Reset

リセット前にGlobal、JP、US、PALの値を記録し、既知のPBを残してください。
また、PBから復元できないChallenge実績を1つ解除してください
（Hot Tubが適しています）。

1. `Misc > RESET > Reset Records` を選び、2段階の確認を承認します。
2. Recordsの統計、実績、進行中の連続カウンターが0になることを確認します。
   PBプロフィール、設定、ボタン割り当て、Creationレイアウトは残る必要があります。
3. 電源を切る前に `Progress saved` になるまで待ちます。JP、US、PALを順番に
   起動し、3地域すべてのRecordsとGlobalがリセット済みのままか確認します。
4. 設定またはボタン割り当てを初期値から変更し、現在のPBとRecords値を
   記録してから `Factory reset` を実行します。設定、割り当て、レイアウトは
   初期値へ戻り、PBとRecordsは変化しないことを確認します。この確認は
   1地域だけで十分です。

Reset RecordsはPBファイルを削除しません。起動時またはPBプロフィールの
再照合時に、保存済みPBだけで条件を証明できるタイム実績、PB登録数実績、
Course Mastery実績が再解除される場合があります。これは正常です。完全に空の
実績状態が必要な場合は、PBのないプロフィールを選んでからReset Recordsを
実行してください。

### 5. 任意のChallenge再確認

次の確認は有用ですが、PR4の必須項目ではありません。

- **Exterminator:** Gelato 8のCataquackを全滅させる。1匹残した状態では
  解除されず、最後の1匹を倒した時に解除されること。

報告には、地域、Wii/NintendontまたはDolphin、ランチャーのチェックサム、
リスタートやセーブステートの正確な手順、期待した結果、実際の結果、
カウンターの前後を含めてください。
