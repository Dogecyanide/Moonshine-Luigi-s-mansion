# V2.0.0 "Ghosts of Delfino" Pre-release 3

## English

Pre-release 3 is a focused safety hotfix for the first Pre-release 2 hardware
test. It is still experimental and is not a release candidate.

### Ghosts

- Replaced the bind-pose Shadow Mario approximation with recorded base-body
  animation IDs and animation phase. Ghost animation now follows the recorded
  run instead of copying the live Mario or remaining in a T-pose.
- Kept the retail Shadow Mario model, independent transform playback,
  multi-stage timing, partial saves, the 15-minute cap, and cross-region
  sharing.
- Introduced the V3 `.smsghost` format. V1 and V2 ghosts are intentionally
  unsupported, so the Pre-release 3 test library starts empty.
- Base-body animation is recorded; motion blending, FLUDD, hands, accessories,
  Yoshi, and other secondary rigs remain outside this prototype.

### Unsaved PB protection

- The departure warning now protects only a newly accepted, unsaved IL PB
  ghost. Equal or slower runs, ordinary partial recordings, imported targets,
  assisted runs, and route-preserving restarts do not trigger it.
- Replaced the unsafe closed-pause wait with a resume-first Exit Area flow.
  Sunshine resumes normally before Susamune asks for confirmation, removing
  the Pre-release 2 softlock path.
- Exit Area, Exit Area level select, Warp Wheel, Warp Last, and IL departures
  revalidate the exact PB ghost that would be discarded before leaving.

### Launcher theme safety

- The launcher now creates its `theme` directory automatically beside the app
  on the device from which the launcher was started.
- Hardened optional `background.png` loading. It must be a valid 1024x480 PNG;
  missing or invalid files fall back to the stock background.
- Disabled custom MP3 playback for Pre-release 3 after the first hardware test
  exposed an unsafe DSP/IOS lifecycle. A present `bgm.mp3` is ignored.

### Preserved from Pre-release 2

- Separate outfit controls, Disable Retail Pause, horizontal metadata, movable
  and scalable notifications, Sirena 8 hotel start, Pinna EYG restart handling,
  death/save-box Full Restart, and fast-forward IL invalidation remain intact.

## 日本語

Pre-release 3 は、Pre-release 2 の最初の実機テスト結果に対応する安全性重視の
hotfix です。引き続き実験版であり、release candidate ではありません。

### ゴースト

- bind pose の Shadow Mario approximation を、記録した base-body animation ID と
  animation phase に置き換えました。ghost は live Mario の pose をコピーせず、
  T-pose のままにもならず、記録した run の animation に従います。
- retail Shadow Mario model、独立 transform playback、multi-stage timing、partial
  save、15 分上限、cross-region sharing は維持されます。
- V3 `.smsghost` format を導入しました。V1／V2 ghost は意図的に非対応となるため、
  Pre-release 3 の test library は空の状態から開始します。
- 記録対象は base-body animation です。motion blend、FLUDD、hands、accessories、
  Yoshi、その他 secondary rig は今回の prototype には含まれません。

### 未保存 PB の保護

- departure warning は、新しく正式に受理された未保存 IL PB ghost のみを保護します。
  同タイム／遅い run、通常の partial recording、imported target、assisted run、
  同一 route restart では表示されません。
- 閉じた pause menu を待機させる危険な方式を廃止し、resume-first の Exit Area
  flow に変更しました。Susamune の確認前に Sunshine が通常 resume するため、
  Pre-release 2 の softlock 経路を解消します。
- Exit Area、Exit Area level select、Warp Wheel、Warp Last、IL departure は、出発直前に
  実際に破棄される PB ghost を再確認します。

### Launcher theme の安全性

- launcher は、起動元 device の app directory 内に `theme` directory を自動作成します。
- optional `background.png` の読み込みを強化しました。有効な 1024x480 PNG のみを
  使用し、missing／invalid file は stock background に fallback します。
- 最初の実機テストで DSP／IOS lifecycle の危険性が判明したため、Pre-release 3 では
  custom MP3 playback を無効化しました。`bgm.mp3` が存在しても無視されます。

### Pre-release 2 から維持される機能

- 個別 outfit control、Disable Retail Pause、metadata horizontal layout、notification
  の移動／scale、Sirena 8 hotel start、Pinna EYG restart、death／save box Full Restart、
  fast-forward IL invalidation は維持されます。
