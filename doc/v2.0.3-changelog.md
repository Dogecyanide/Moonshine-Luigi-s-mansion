# Susamune V2.0.3 "Ghosts of Delfino"

## English

V2.0.3 is a focused hardware hotfix for rendering regressions found while testing
V2.0.2. It does not change the V4 ghost format, ghost-library capacities, or
saved settings. Existing V3 and V4 files remain compatible.

### Ghost attachments

- Fixed V4 Yoshi playback showing the correct mounted rider animation without
  drawing Yoshi. An unhatched live Yoshi can hide shapes in the retail model
  data shared by the private ghost copy; ghost submission now makes those
  shapes visible without leaving the current player's Yoshi altered.
- Added playback for the exact retail Noki Bay `TJumpBase` spring. Existing V4
  recordings already preserve its object identity, so they can display the
  spring without being re-recorded. The spring follows the ghost's right hand
  in Race, Watch, and Watch 2.
- The five supported fruits remain unchanged. Unknown, missing, or unsupported
  held actors still fail closed: only the attachment is hidden and playback
  continues.

### Known issue: Secret IL eligibility

- The attempted FLUDD-emission check still does not reliably revoke Records/PB
  eligibility for a standalone Secret IL on hardware. V2.0.3 ships with this
  restriction unenforced; do not rely on a saved time being no-FLUDD.
- Red-coin ILs remain eligible when FLUDD is used, including Reds that share the
  same secret scene. Full-level attempts also remain eligible before and after
  entering a secret.

The Personal slot 01 name regression is not changed again in V2.0.3. Its
V2.0.2 fix has been confirmed on hardware and remains in place.

The QFT implementation and time source, V4 wire layout, PB-save policy, Records
journals, achievements, savestate format, settings/binds ordering, and fixed
MEM2/storage budgets are unchanged.

## 日本語

V2.0.3 は、V2.0.2 の実機テストで見つかった rendering regression に絞った hotfix です。
V4 ghost format、ghost library capacity、保存済み setting は変更しません。既存の V3／V4
file はそのまま使用できます。

### Ghost attachment

- V4 Yoshi playback で rider の搭乗 animation は正しいのに Yoshi 本体が表示されない問題を
  修正しました。現在の player 側 Yoshi が unhatched の場合、private ghost copy と共有する
  retail model data の shape が非表示になることがあります。ghost 描画時だけ必要な shape を
  visible にし、player 側 Yoshi の状態は変更したままにしません。
- Noki Bay の exact retail `TJumpBase` spring を描画できるようにしました。既存 V4 recording
  には object identity が保存済みなので、record し直さなくても spring を表示できます。
  Race／Watch／Watch 2 で ghost の右手に追従します。
- 対応済みの 5 種類の fruit は変更ありません。unknown／missing／unsupported held actor は
  従来通り fail closed し、attachment だけを非表示にして playback を続行します。

### Known issue: Secret IL eligibility

- standalone Secret IL の FLUDD emission による Records／PB invalidation は、実機でまだ
  reliable に動作しません。V2.0.3 ではこの制限が enforce されないため、保存された time を
  no-FLUDD 記録として扱わないでください。
- 同じ secret scene を共有する Reds を含め、Red-coin IL は FLUDD 使用後も eligible のままです。
  Full-level attempt も secret に入る前後を問わず eligible のままです。

Personal slot 01 の name regression は V2.0.3 で再変更していません。V2.0.2 の fix が実機で
確認され、そのまま維持されています。

QFT implementation／time source、V4 wire layout、PB-save policy、Records journal、achievement、
savestate format、setting／bind 順序、固定 MEM2／storage budget は変更していません。
