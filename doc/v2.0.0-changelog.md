# Susamune V2.0.0 "Ghosts of Delfino"

## English

V2.0.0 is the full Ghosts of Delfino release. The distribution archive is
`Susamune-V2.0.0-Ghosts-of-Delfino.zip`; Homebrew Channel and the launch screen
identify it as `Susamune Launcher` and `V2.0.0 "Ghosts of Delfino"` with no
pre-release or release-candidate suffix.

### Ghost racing and watching

- Ghosts record on the same QFT timeline used by the mod's timers. They can be
  raced, watched alone, or watched in compatible pairs with Shadow Mario or
  Piantissimo appearances.
- Watch supports direct-secret starts and recorded parent-to-secret loading-zone
  transitions. Observer Mario remains an invisible camera anchor and returns to
  normal when viewing finishes or is canceled.
- B and Start used during a stage intro cannot leak into viewer exit. Each Watch
  segment ignores exit input while warping, then waits for one raw controller
  sample with both buttons released. Only a fresh B or Start press during active
  playback exits.
- The Ghosts tab has an `Auto race target` choice. `Last attempt` is the default
  and can race the preceding interrupted attempt; `Last success` promotes only
  completed automatic recordings. Pinned library ghosts, Watch, PB protection,
  and explicit saves are unchanged by this choice.
- Personal and imported libraries use non-selectable ten-slot range headers.
  C-stick Left/Right jumps between range starts, Up/Down selects real rows, and
  A activates the selected row. Stored slot numbers do not move.
- The stored-ghost action prompt remains A Race, Y Watch, and X Watch 2. Race 2
  was deliberately canceled and there is no Z action.

`Ghosts saved` and `Ghost time saved` are also visible as lifetime Records
statistics. They advance only after the storage side acknowledges a successful
save, so canceled, failed, retried, or stale requests cannot inflate them. They
begin prospectively with V2.0.0; existing ghost files are not counted merely by
scanning the library. The Global view sums the region journals.

### Release cleanup and compatibility

- Temporary Ghost test notices and diagnostic chatter were removed from the
  release UI. User-facing storage errors and status remain.
- Permanent exception capture remains enabled. The launcher device receives
  rotating `susamune_crash_a.txt/.bin` and `susamune_crash_b.txt/.bin` pairs.
- Existing settings, binds, PB profiles, Records progress, V3 ghost libraries,
  themes, and BGM remain compatible. New setting, statistic, and achievement
  identifiers were appended without moving established IDs.
- The ghost format, savestate format, QFT source, MEM1 reserve, and launcher
  storage layout are unchanged from the release-candidate foundation.

## 日本語

V2.0.0 は Ghosts of Delfino の正式版です。配布 archive は
`Susamune-V2.0.0-Ghosts-of-Delfino.zip` です。Homebrew Channel と launcher
画面では `Susamune Launcher`、`V2.0.0 "Ghosts of Delfino"` と表示され、
Pre-release／Release Candidate の suffix は付きません。

### Ghost の Race／Watch

- Ghost は mod の timer と同じ QFT timeline で記録されます。Shadow Mario または
  Piantissimo の外見で、Race、Watch、compatible な 2 体同時 Watch ができます。
- direct-secret 開始と、記録された parent-to-secret loading-zone transition に対応します。
  observer 用 Mario は camera anchor として非表示になり、Watch の完了・cancel 後は通常状態へ
  戻ります。
- stage intro で使った B／Start は viewer 終了入力へ漏れません。各 Watch segment は warp 中の
  終了入力を無視し、active playback に入ってから raw controller で両方の release を 1 sample
  確認します。その後の新しい B／Start press だけが Watch を終了します。
- Ghosts tab に `Auto race target` を追加しました。default の `Last attempt` は直前の未完走も
  race 対象にできます。`Last success` は完走した自動記録だけを採用します。pinned library
  ghost、Watch、PB protection、明示的な save の動作は変わりません。
- Personal／Imported library は選択不能な 10-slot ごとの range header を表示します。C-stick
  左右で range 先頭へ移動し、上下で実 row を選び、A で実行します。保存 slot 番号は移動しません。
- stored-ghost prompt は A Race、Y Watch、X Watch 2 のままです。Race 2 は正式に取りやめ、
  Z action はありません。

### Records と実績

Records は有効な実績 154 個になりました。Any% 中心ではなかった route に Times 実績を 25 個
追加しました。上記 English table の全条件は strict QFT (`result < limit`) であり、Sunshine の
retail IGT timer は一切使用しません。exact threshold と同値では解除されず、それより速い result
だけが対象です。

保存済み PB profile から、time 条件だけの 24 個は再判定できます。`Nutty` は過去の PB data に
Yoshi 使用情報がないため、live run でのみ解除できます。

Ghost の保存回数／保存時間には、各 tier 1 個ずつ Special 実績を追加しました。

| Tier | Achievement | 条件 |
|---|---|---|
| Bronze | Ghastly! | Ghost を 1 個保存 |
| Silver | Spectral! | Ghost を合計 5 分保存 |
| Gold | Specular! | Ghost を 25 個保存 |
| Diamond | Ectoplasmic! | Ghost を合計 1 時間保存 |
| Demon | Wraithlike! | lifetime で Ghost を 250 個保存 |
| Frontier | Phantasmal! | lifetime の Ghost 保存時間が 50 時間を超える |

`Ghosts saved` と `Ghost time saved` は lifetime Records stats としても表示されます。storage side
から成功 ACK を受け取った場合だけ増えるため、cancel、failure、retry、stale request で二重加算
されません。V2.0.0 導入後からの prospective count であり、既存 library を scan しただけでは
過去分を加算しません。Global 表示は 3 region の journal を合算します。

### 正式版 cleanup と互換性

- 一時的な Ghost test notice／diagnostic 表示を release UI から削除しました。通常の storage
  error と status は残っています。
- permanent exception capture は有効です。launcher device root に rotating pair の
  `susamune_crash_a.txt/.bin`／`susamune_crash_b.txt/.bin` を保存します。
- 既存の setting、bind、PB profile、Records progress、V3 ghost library、theme、BGM は互換です。
  新しい setting／stat／achievement ID は append-only で、既存 ID を移動していません。
- ghost format、savestate format、QFT source、MEM1 reserve、launcher storage layout は
  release-candidate 基盤から変更していません。
