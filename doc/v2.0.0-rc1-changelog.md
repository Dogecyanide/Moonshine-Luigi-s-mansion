# V2.0.0 "Ghosts of Delfino" Release Candidate 1

## English

Release Candidate 1 is the source-stable hardware-validation candidate for
Ghosts of Delfino. It rolls forward the Ghosts menu and route fixes from
Pre-release 9, the Watch 2 hardening from Pre-release 10, and one deterministic
observer-exit input fix. These RC1 changes have not yet passed the hardware
matrix in the accompanying testing guide.

### Deterministic intro/exit input fix

- B and Start are viewer exit controls, but Sunshine can also consume them
  during a stage intro. Previously, a button still held when Watch entered
  active playback could be interpreted immediately as an exit request.
- Every Watch segment now begins with B/Start exit input disarmed. Active
  playback must observe both buttons fully released before it accepts a new B
  or Start press as an exit.
- This release gate is reset for direct-secret starts and every natural
  parent-to-secret segment handoff. An intro-skip hold cannot end Watch on the
  first active frame; release followed by a fresh B or Start press still exits.
- A is not a viewer exit control and remains an explicit control case for the
  hardware matrix.

### Watch 2 secret hardening

- The second observer track keeps its runtime metadata separate from normal
  recording, PB, and storage-ack ownership while retaining the bounded sample
  payload.
- Every loaded segment validates both observer routes. The next stage hides
  Mario only after both tracks configure successfully.
- The invisible camera-anchor Mario is restored when a loading zone starts,
  before the outgoing stage heap is destroyed. Retail materialisation remains
  in control until normal play begins.
- The Ghosts Target row reports Watch 2 loading and visible-track counts so a
  failed hardware case can be described without a debug build.
- Exact recorded parent-to-secret transitions remain eligible to continue;
  unrelated stage changes still stop observer mode safely.

### Ghost library and controls

- Personal slots are divided by non-selectable 01-10, 11-20, 21-30, 31-40,
  and 41-45 headers. Imported slots use 01-10 and 11-12 headers.
- C-stick Left/Right jumps between section/range starts in normal browsing and
  in the second-ghost chooser. Up/Down selects real rows and A activates the
  selected row; stored slot identities do not move.
- A rejected Watch request, including Ghost Display Off, returns control to
  the ordinary menu instead of leaving the private chooser active.
- Release-gated raw input remains in place for destructive confirmations and
  protected-PB flows.

### Deliberate scope

- Race 2 was considered and canceled for V2.0.0. The action prompt remains
  A Race, Y Watch, and X Watch 2; there is no Z Race 2 action.
- The V3 ghost format, existing ghost libraries, PB storage, savestate format,
  QFT source, MEM1 reserve, and launcher storage layout are unchanged.
- Permanent rotating exception reports remain available at launcher-device
  root as `susamune_crash_a/b.txt` with matching `.bin` files.

## 日本語

Release Candidate 1 は、Ghosts of Delfino のソースを固定して実機検証するための
候補版です。Pre-release 9 の Ghosts メニュー／ルート修正、Pre-release 10 の
Watch 2 安全性改善、および observer 終了入力の決定的な不具合修正を含みます。
RC1 の新しい変更は、付属テストガイドの実機 matrix をまだ完了していません。

### Intro と終了入力の決定的な修正

- B と Start は viewer の終了ボタンですが、Sunshine の stage intro でも使用されます。
  以前は、Watch が active playback に入った瞬間にボタンが押されたままだと、直ちに
  終了要求として扱われる場合がありました。
- 各 Watch segment の開始時は B／Start 終了入力を無効状態にします。active playback
  中に両方の完全な release を確認した後だけ、新しい B または Start press を終了として
  受け付けます。
- この release gate は direct-secret 開始時と、自然な parent-to-secret segment 移動ごとに
  reset します。intro-skip の hold では最初の active frame に Watch を終了せず、release 後の
  新しい B／Start press では通常どおり終了します。
- A は viewer の終了ボタンではなく、実機 matrix の明示的な control case として確認します。

### Watch 2 の Secret 安全性改善

- 2 体目 observer track の runtime metadata を、通常 recording、PB、storage ACK の所有情報から
  分離しました。sample payload は従来どおり bounded な領域を使用します。
- 読み込まれた各 segment で両方の observer route を検証します。次の stage では 2 track の
  configure が成功した後だけ Mario を非表示にします。
- loading zone 開始時、outgoing stage heap が破棄される前に invisible camera-anchor Mario を
  restore します。normal play までは retail materialisation の制御を維持します。
- Ghosts の Target 行に Watch 2 loading と visible track 数を表示し、debug build なしでも
  実機 failure の状態を報告できます。
- 記録と完全一致する parent-to-secret transition は継続し、無関係な stage change では
  observer mode を安全に終了します。

### Ghost library と操作

- Personal slot に選択不能な 01-10、11-20、21-30、31-40、41-45 header を追加しました。
  Imported slot は 01-10 と 11-12 です。
- 通常一覧と 2 体目 chooser で C stick 左右が section／range 先頭へ移動します。上下は実際の
  row だけを選択し、A で選択 row を実行します。保存 slot の identity は移動しません。
- Ghost Display Off を含む Watch 拒否後は private chooser を残さず、通常 menu の操作を
  取り戻します。
- destructive confirmation と protected-PB flow では、raw input の release gate を維持します。

### 意図的な scope

- Race 2 は検討後、V2.0.0 では追加しないことにしました。action prompt は A Race、Y Watch、
  X Watch 2 のままで、Z Race 2 はありません。
- V3 ghost format、既存 ghost library、PB storage、savestate format、QFT source、MEM1 reserve、
  launcher storage layout は変更していません。
- permanent rotating exception report は launcher-device root の
  `susamune_crash_a/b.txt` と対応する `.bin` に引き続き保存されます。
