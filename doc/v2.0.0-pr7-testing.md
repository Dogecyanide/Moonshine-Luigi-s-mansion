# Susamune V2.0.0 "Ghosts of Delfino" Pre-release 7 Testing / テストガイド

## Purpose / 目的

PR7 validates the complete ghost feature set before any new Records or
achievements are added. The release-blocking checks are retail Shine Select,
Watch timing, and the save-first PB protection flow.

PR7 は新しい Records／achievement を追加する前に、ghost feature set 全体を validate する
build です。retail Shine Select、Watch timing、save-first PB protection flow が release
blocker です。

## Hard safety rules / 必須の安全規則

- Back up the PR6 launcher app, `susamune_ghosts`, `susamune.ini`, PBs, Records,
  achievements, and progress before copying PR7.
- Keep QFT visible for timing comparisons. Stop after a white screen, looping
  crash sound, input-dead screen, unbounded load, persistence corruption, or
  Mario/camera state that is not restored.
- Record region, disc ID, stage, exact action, and last visible message for any
  failure. Homebrew Channel must show `V2.0.0 "Ghosts of Delfino" Pre-release 7`.

- PR7 を copy する前に、PR6 launcher app、`susamune_ghosts`、`susamune.ini`、PB、
  Records、achievements、progress を backup してください。
- timing comparison 中は QFT を表示します。white screen、looping crash sound、
  input-dead screen、unbounded load、persistence corruption、Mario／camera state が
  restore されない場合は中止してください。
- failure の region、disc ID、stage、exact action、最後の visible message を記録します。
  Homebrew Channel は `V2.0.0 "Ghosts of Delfino" Pre-release 7` を表示する必要があります。

## 1. Decisive retail Shine Select A/B / 決定的な retail Shine Select A/B

Run this from a fresh power-on before loading a race target or using Watch.

Race target／Watch を使用する前の fresh power-on から実行します。

1. Load a normal save, walk from Delfino Plaza into the Bianco portal, use
   retail Shine Select, and enter Bianco 4. Repeat with Bianco 5.
2. Start Bianco 4 and 5 through Susamune Level Select as controls. Both paths
   must load the same stages without a white screen or looping crash sound.
3. Repeat retail Shine Select with at least three other destinations. Include a
   Shadow-model stage and a stage that uses a 2D fallback.
4. Repeat the retail B4/B5 test after Race, Watch, Watch 2, a saved ghost, and a
   launcher reboot. Test JP and PAL independently; perform US parity as well.
5. During the selector and black loading frames, no stale ghost marker, Mario,
   camera, toast, or metadata may appear. The destination may begin recording
   only after its stage setup is complete.

1. normal save を load し、Delfino Plaza から Bianco portal に入り、retail Shine Select で
   Bianco 4 を開始します。Bianco 5 でも繰り返します。
2. control として Susamune Level Select から Bianco 4／5 を開始します。どちらの path でも
   white screen／looping crash sound なしで同じ stage を load する必要があります。
3. retail Shine Select から他の destination を少なくとも 3 つ確認します。Shadow model stage
   と 2D fallback stage を含めます。
4. Race、Watch、Watch 2、ghost save、launcher reboot 後にも retail B4／B5 を再確認します。
   JP と PAL を別々に test し、US parity も確認します。
5. selector／black loading frame 中に stale ghost marker、Mario、camera、toast、metadata を
   表示してはいけません。destination の recording は stage setup 完了後だけ開始します。

## 2. Watch start and secret intros / Watch start と secret intro

1. Set persisted `Stage Intro Skip` to Off. Watch a Gelato secret ghost whose
   first segment begins in the secret. No input may be required to dismiss the
   entrance scene.
2. The first recorded pose must appear at the start. Movement must begin after
   the single route-validation frame; there must be no 30-frame or multi-second
   hold.
3. End Watch with B, Start, and natural completion in separate runs. The final
   playable reload must restore visible, controllable Mario and must use the
   user's persisted intro setting. Confirm the setting remains Off after reboot.
4. Repeat Watch 2 and a multi-segment route containing two secret entries. Each
   viewer-owned intro must auto-skip, with no late spawn at either boundary.
5. Repeat with persisted Stage Intro Skip On. It must remain On after Watch.

1. persisted `Stage Intro Skip` を Off にし、最初の segment が secret 内で始まる Gelato ghost
   を Watch します。entrance scene を閉じる input は不要です。
2. 最初の recorded pose を start で表示し、1 route-validation frame 後に movement を開始する
   必要があります。30-frame／数秒の hold は禁止です。
3. 別々の run で B、Start、natural completion により Watch を終了します。最後の playable
   reload は visible／controllable Mario と user の persisted intro setting を復元します。
   reboot 後も setting が Off のままであることを確認します。
4. Watch 2 と secret entry を 2 つ含む multi-segment route でも繰り返します。各 viewer-owned
   intro を auto-skip し、どちらの boundary でも late spawn を起こしてはいけません。
5. persisted Stage Intro Skip On でも再確認し、Watch 後も On のままであることを確認します。

## 3. PB save-first protection / PB save-first protection

1. Earn an eligible selected-IL PB and leave its ghost unsaved. Allow the full
   retail Shine pose/camera/result presentation to finish.
2. At the protection screen, press A. Ghosts must open on a confirmation for
   that exact PB and a safe empty personal slot. A confirms Save; B returns to
   protection. The original departure must wait for a successful storage ACK.
3. Repeat and press B on the protection screen. Only the named PB may be
   discarded, then the original action continues. A held opening button must
   never confirm either choice.
4. Repeat for natural Shine departure, Exit Area, title exit, Warp Wheel,
   Instant Restart, Full Restart, IL start, and Savestate Load.
5. Create two protected PB tokens. Each must receive its own prompt and exact
   save/discard decision before the action is released.
6. Fill all 45 personal slots. A must open the protected full-library flow:
   C Up/Down chooses, X requests deletion, A confirms deletion, and the catalog
   refreshes before offering the new empty slot. B always returns safely. No
   overwrite is allowed.
7. Test storage error, timeout, write-protected/full SD, and a save that finishes
   late. The PB and original action must remain protected until the exact ACK.

1. eligible selected-IL PB を出し、ghost を未保存にします。retail Shine pose／camera／result
   presentation を最後まで表示します。
2. protection screen で A を押します。Ghosts は exact PB と safe empty personal slot の
   confirmation を開く必要があります。A は Save confirm、B は protection に戻ります。
   successful storage ACK まで元の departure を release してはいけません。
3. もう一度行い、protection screen で B を押します。named PB だけを discard してから元の
   action を続行します。opening button の hold で choice を confirm してはいけません。
4. natural Shine departure、Exit Area、title exit、Warp Wheel、Instant Restart、Full Restart、
   IL start、Savestate Load で繰り返します。
5. protected PB token を 2 つ作ります。action release 前に、それぞれ exact save／discard
   decision を表示する必要があります。
6. personal slot 45 個を full にします。A は protected full-library flow を開き、C Up/Down で
   choose、X で delete request、A で delete confirm、catalog refresh 後に new empty slot を
   offer します。B は常に安全に戻ります。overwrite は禁止です。
7. storage error、timeout、write-protected／full SD、late save completion を確認します。
   exact ACK まで PB と original action を保護する必要があります。

## 4. Complete ghost regression / ghost 全体の回帰

- Record, race, save, load, import, export, delete, and partial-save one V3
  ghost. Repeat a JP↔PAL/US cross-region import and a multi-stage route.
- Test Shadow Mario and Piantissimo as primary appearance, all opacity values,
  Watch 2 staggered starts/ends, water, secrets, hotel/casino, and native Shadow
  stages. Missing assets must fall back independently without a crash.
- Test B/Start/end cleanup, pause/menu timing, fast-forward refusal, savestate
  cancellation, unexpected route failure, and Disable Warps. Mario input,
  visibility, route, and camera must recover.
- Snapshot Records, achievements, play/area time, deaths, attempts, and Attempt
  Counter before Watch/Watch 2. They must not gain viewer credit. Observer warps
  may reset QFT through the normal stage-load path but may not award a PB/result.
- With runners very far apart, imperfect retail-camera framing is known; camera
  corruption, unbounded acceleration, or failure to restore remains a blocker.
- Recheck the largest valid ghost transfer during Watch 2, launcher panorama and
  `bgm.mp3`, four profiles, cosmetics, pause toggle, metadata, notifications,
  Sirena 8, Pinna EYG, and restart binds.

- V3 ghost 1 つで record、race、save、load、import、export、delete、partial-save を確認します。
  JP↔PAL／US cross-region import と multi-stage route でも繰り返します。
- primary appearance の Shadow Mario／Piantissimo、すべての opacity、Watch 2 の staggered
  start／end、water、secret、hotel／casino、native Shadow stage を確認します。missing asset は
  crash せず runner ごとに fallback する必要があります。
- B／Start／end cleanup、pause／menu timing、fast-forward refusal、savestate cancellation、
  unexpected route failure、Disable Warps を確認します。Mario input、visibility、route、camera
  を restore する必要があります。
- Watch／Watch 2 前に Records、achievements、play／area time、deaths、attempts、Attempt
  Counter を snapshot します。viewer credit を加算してはいけません。observer warp は通常の
  stage-load path で QFT を reset できますが、PB／result を award してはいけません。
- runner が非常に離れた場合、retail camera framing の不完全さは known です。ただし camera
  corruption、unbounded acceleration、restore failure は blocker です。
- Watch 2 中の最大 valid ghost transfer、launcher panorama／`bgm.mp3`、4 profile、cosmetics、
  pause toggle、metadata、notifications、Sirena 8、Pinna EYG、restart bind を再確認します。
