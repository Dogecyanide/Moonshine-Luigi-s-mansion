# Susamune V2.0.1 "Ghosts of Delfino"

## English

V2.0.1 is a focused compatibility and safety hotfix for the Ghosts of Delfino
release.

### Ghost recording and playback

- Fixed a hardware crash when a recorded rider animation resolved to Sunshine's
  out-of-band animation sentinel. Ghost rendering now accepts only the 199
  proven retail Mario BCK slots; an unsupported pose falls back safely instead
  of indexing beyond that table.
- New recordings use ghost format V4. It keeps the same 16-byte sample stride,
  15-minute duration limit, file-size ceiling, and MEM2 slot layout as V3 while
  recording per-sample Yoshi mount/colour state and held-object identity.
- A V4 recording can describe seven distinct held-object identities. Further
  objects remain explicitly marked as held-but-unknown rather than invalidating
  the recording. V3 ghosts remain readable. V2.0.0 readers safely refuse V4
  files instead of misinterpreting them.
- Attachment state is captured now so new ghost progress is not permanently
  missing it. Rendering Yoshi and held objects is intentionally deferred; this
  hotfix still renders the established Mario/Piantissimo ghost models.
- Watch now carries the retail camera's smoothed vertical anchors with the
  invisible Mario anchor. This prevents the camera from falling increasingly
  far below ghosts on routes with large elevation changes.

### PB protection and storage

- Added `PB ghost save` to the Ghosts tab with `Ask`, `Auto-Save`, and
  `Don't ask`. The default is `Ask` and the choice persists per region.
- In `Ask`, A opens the protected Ghosts save flow. B now continues without
  saving by removing PB protection only; it no longer deletes the completed
  in-memory track, so ordinary restarts and departures can still promote it as
  a race target.
- `Auto-Save` writes each protected PB to the first empty Personal slot and
  waits for its exact storage acknowledgement before continuing. A full library,
  unavailable storage, an error, or a timeout falls back to `Ask` without losing
  the PB. B also switches a pending automatic flow to `Ask`.
- `Don't ask` continues immediately without saving or erasing the completed
  track. Power-off, game reset, and loading an older savestate cannot preserve
  volatile unsaved memory; save first when the recording must survive those
  operations.
- A full 45-slot Personal library is never overwritten. The protected save
  flow lets the player choose a slot, press X, confirm deletion with A or cancel
  with B, refreshes the catalog after the delete acknowledgement, and then
  offers the newly empty slot.
- Ordinary Personal and Imported deletion also remains X followed by an A/B
  confirmation. Unsafe Personal slots are immutable; quarantined or
  forward-version Imported files remain removable behind that confirmation so
  a bad import cannot become permanent.
- Closed two modal edge cases: automatic saving can escape a stalled storage
  request, and protected-save acknowledgements continue to be processed while
  Disable Warps is enabled.

The QFT implementation, Records journals, achievements, savestate format,
settings/binds ordering, and fixed ghost-storage capacities are unchanged.

## 日本語

V2.0.1 は Ghosts of Delfino 正式版の compatibility／safety hotfix です。

### Ghost 記録／再生

- Yoshi 搭乗時の記録 animation が Sunshine の範囲外 sentinel を参照し、hardware crash する問題を
  修正しました。retail Mario BCK の有効な 199 slot だけを使用し、unsupported pose は安全に
  fallback します。
- 新しい記録は ghost format V4 です。16-byte sample、15 分上限、file-size 上限、MEM2 slot は
  V3 と同じまま、sample ごとの Yoshi 搭乗／色と held-object identity を記録します。
- 1 run につき 7 種類の held object を記述できます。それを超えた場合も recording を失敗させず、
  held-but-unknown として残します。V3 ghost は引き続き読めます。V2.0.0 は V4 を誤読せず安全に
  拒否します。
- 将来の表示で過去 data が欠けないよう attachment state を今から保存します。この hotfix では
  Yoshi／held object 自体の描画はまだ行わず、従来の Mario／Piantissimo model を表示します。
- 高低差が大きい Watch で、非表示 Mario の移動に retail camera の vertical smoothing anchor も
  追従させ、camera が徐々に下へ取り残される問題を修正しました。

### PB protection／storage

- Ghosts tab に `PB ghost save` (`Ask`／`Auto-Save`／`Don't ask`) を追加しました。default は
  `Ask` で、region ごとに保存されます。
- `Ask` の A は protected save を開きます。B は PB protection だけを外して続行し、completed
  in-memory track を削除しません。通常の restart／departure 後も race target にできます。
- `Auto-Save` は最初の空き Personal slot に保存し、exact ACK 後だけ続行します。満杯、storage
  unavailable、error、timeout は PB を残したまま `Ask` に戻り、B でも `Ask` に切り替えられます。
- `Don't ask` は save せず、track を即時削除せずに続行します。ただし power-off、game reset、古い
  savestate の load は volatile data を保持できないため、必要な ghost は先に保存してください。
- Personal 45 slot が満杯でも overwrite しません。slot を選び X、A で delete confirm／B で cancel
  した後、catalog を更新して空いた slot を save 候補にします。通常の Personal／Imported delete
  も X の後に A／B confirmation が必要です。unsafe Personal slot は変更不可ですが、quarantine／
  future-version Imported file は不良 import を消せるよう同じ confirmation 後に削除できます。
- storage timeout と Disable Warps 中の protected-save ACK による modal lock も修正しました。

QFT、Records journal、achievement、savestate format、既存 setting／bind の順序、固定 storage
capacity は変更していません。
