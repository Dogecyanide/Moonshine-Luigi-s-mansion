# V2.0.0 "Ghosts of Delfino" Pre-release 9

## English

Pre-release 9 fixes the remaining Watch and Watch 2 failures found during the
PR8 hardware pass. The ghost file format is unchanged.

### Ghosts menu

- A rejected Watch or Watch 2 request no longer leaves the Ghosts tab trapped
  in its private chooser. If Ghost Display is Off, the menu returns to the
  Ghost Display row; A can enable it immediately, and tab switching and menu
  close work normally.
- C-stick Left/Right now jumps between the Ghost Library, Personal, and
  Imported sections. A activates or changes the selected row, matching the
  rest of the menu.
- Raw, release-gated input remains in place for confirmations and protected PB
  operations.

### Secret and multi-stage Watch

- Starting Watch on a secret-only ghost now reconstructs the recorded parent
  episode as the previous scene instead of incorrectly treating the secret as
  its own parent.
- A natural loading zone now continues Watch only when the loaded scene is the
  exact next recorded segment. Parent-to-secret and beach-to-hotel routes no
  longer stop with `Unexpected stage change`.
- Natural segment handoffs preserve the recording's absolute QFT timeline,
  including the recorded loading gap. Direct observer warps still translate a
  reset local clock to the recorded segment.
- Invisible Mario remains suppressed while a segment has no visible sample,
  and every failure/exit path restores a visible, controllable Mario.
- An unrelated stage change still ends Watch safely.

### Confirmed from PR8

- Retail Shine Select no longer crashed in hardware tests covering Bianco 4/5,
  Pianta 5, Ricco 8, Pinna 7, Noki 3, and Sirena 1.
- Normal-stage Race, Watch, and Watch 2 worked with both Shadow Mario and
  Piantissimo.
- Permanent rotating exception reports remain available as
  `susamune_crash_a/b.txt` and matching `.bin` files at the launcher-device
  root.

Records and achievement additions remain deferred until the complete ghost
hardware matrix is green.

Known format limitation: console-created ghosts do not use the optional V3
`PARENT_START` route-identity bit. Externally authored files carrying that bit
remain structurally valid, but live Race/Watch launch semantics for it are not
implemented yet. PR9 keeps exact route matching instead of guessing.

## 日本語

Pre-release 9 では、PR8 の実機テストで判明した Watch / Watch 2 の残りの
不具合を修正しました。ゴーストファイル形式は変更していません。

### Ghosts メニュー

- Ghost Display が Off の状態で Watch / Watch 2 を選んでも、Ghosts タブが
  専用選択画面に取り残されなくなりました。Ghost Display 行に戻るため、
  A ですぐに有効化でき、タブ移動とメニューを閉じる操作も通常どおり使えます。
- C スティック左右で Ghost Library、Personal、Imported の各セクションへ
  ジャンプします。A で選択行を実行・変更し、他のメニューと操作を統一しました。
- 確認画面と保護された PB 操作では、ボタンを一度離してから押す安全な入力処理を
  維持しています。

### Secret と複数ステージの Watch

- Secret 単独ゴーストの Watch 開始時に、Secret 自身を直前のシーンとして扱わず、
  記録された親エピソードを正しく復元します。
- 自然なローディングゾーンでは、読み込まれたシーンが記録上の次セグメントと
  完全一致する場合だけ Watch を継続します。親ステージから Secret、ビーチから
  ホテルへの移動で `Unexpected stage change` が出なくなりました。
- 自然なセグメント移動では、記録時のロード区間を含む絶対 QFT 時系列を維持します。
  Observer が直接ワープした場合は、リセットされたローカル QFT を記録時系列へ
  変換します。
- 表示可能なサンプルがない区間でも透明 Mario の操作を停止し、失敗・終了時には
  必ず表示された操作可能な Mario に戻します。
- 記録と無関係なステージ移動では、従来どおり安全に Watch を終了します。

### PR8 で確認済み

- 実機で Bianco 4/5、Pianta 5、Ricco 8、Pinna 7、Noki 3、Sirena 1 の
  retail Shine Select クラッシュが発生しないことを確認しました。
- 通常ステージの Race、Watch、Watch 2 は Shadow Mario と Piantissimo の
  両方で動作しました。
- 常設の例外レポートは、ランチャーデバイスのルートに
  `susamune_crash_a/b.txt` と対応する `.bin` として保存されます。

Records と achievement の追加は、ゴースト機能の実機テストがすべて通るまで
保留します。

既知の形式上の制限：本体で作成したゴーストは V3 の任意
`PARENT_START` ルート識別ビットを使用しません。このビットを持つ外部作成ファイルは
構造上は有効ですが、Race / Watch 開始時の意味はまだ実装されていません。PR9 は
推測せず、厳密なルート一致を維持します。
