# Susamune V2.1.0 Pre-Release 1 "Hot Streak"

Pre-Release 1 begins the English V2.1 development cycle with the production
Stage Loader, first streak-session loop, and a compact menu hierarchy.
Japanese translation remains a separate post-freeze milestone.

## Stage Loader and streaking

- Stage Loader uses the existing IL catalogue and the same guarded, two-phase
  IL warp path as the IL list.
- Its top option switches between one-shot Stageloader and Streaking.
- Streaking supports 1-99 required finishes and an optional keyboard-entered
  target time. A blank target accepts any eligible finish.
- Exact eligible finishes at or below the target increment the streak. A miss,
  assisted/ineligible result, wrong finish, reset, or ended attempt resets it.
- A result card identifies the route and outcome. Completion remains visible
  and stops automatic retries.
- Retries wait 90 frames and remain gated on direct-stage context, live async
  setup, normal director state, no demo/save transition, and no menu, Warp
  Wheel, or protected-PB prompt.
- The session uses a fixed 256-byte MEM2 slot and no general heap.

Stage-loader preset persistence and the full IL Segments feature are later
V2.1 milestones; the IL Segments route is visible as a placeholder in PR1.

## Menu

- Retail top level is now Shined, Settings, ILs, Creation, and Records.
- Settings contains Practice, Savestate, Timer, Gameplay, Display, Cosmetics,
  and Binds.
- ILs contains ILs, Ghosts, Stage Loader, and IL Segments.
- Existing stateful editors and Ghost/PB flows remain persistent and are
  delegated through the nested menu without heap allocation.
- B returns from a nested page. In Binds, X now clears while A still records.
- Protected PB saves route directly to nested Ghosts without title-string
  casting.

## Defaults and identity

- Fresh configurations default Input Display and Recent IL history to Off.
- QFT section history remains Off by default.
- Sunshine timer, PB fanfare, IL PB recording, and achievement notifications
  remain enabled.
- The development launcher is identified as Susamune Launcher DELTA.

Saved settings are never overwritten during installation, so existing users
retain their chosen values.

## Memory and compatibility

- Every linked console image is now hard-capped at 0x50000 bytes.
- The physical 0x80000 MEM1 mod region, 0x82000 arena reservation, and final
  0x40 scratch remain unchanged.
- The protected V2.0 QFT timer sources are unchanged.
- Race 2 remains cancelled.
