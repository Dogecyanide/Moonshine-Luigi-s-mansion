# V2.0.0 "Ghosts of Delfino" Pre-release 5

## English

Pre-release 5 is a hardware-safety hotfix for the input and Shine Select
failures found in Pre-release 4. It remains an experimental test build.

### Responsive confirmations and PB ownership

- Replaced the frozen-director prompt input with release-gated raw controller
  input. Confirmation screens now require a new press after opening and remain
  responsive on JP, US, and PAL.
- Restored a visible unsaved-PB confirmation instead of the PR4 repeat-action
  warning. Destructive exits, warps, restarts, savestate loads, and ghost-target
  changes cannot continue until every accepted unsaved PB is saved or explicitly
  discarded.
- Accepted PB ghosts now carry a stable runtime identity across record/playback
  buffer promotion. Saving prioritizes them, and only the matching successful
  storage acknowledgement marks them saved.
- Fixed Instant Restart leaving a discarded PB as a phantom Save candidate.
- Applied the same raw-input rule to the Ghost Race/Watch chooser and its Save
  and Delete confirmations.
- Moved Ghost Display and Ghost Opacity from the generic UI category into the
  Ghosts tab beside the race-target controls.

### Shine Select crash hotfix

- Removed the Watch-camera branch from the always-on JP/US/PAL patch manifests.
  Ordinary gameplay and retail Shine Select intros now execute the exact retail
  camera instruction.
- Watch installs the camera branch only after a viewer starts successfully and
  restores the exact regional retail word whenever Watch stops or resets.

### Launcher readability and music

- Black launcher text now has an eight-direction white outline, remaining
  readable over both the stock background and user panoramas.
- Restored optional user-provided `theme/bgm.mp3` playback with a bounded 4 MiB
  file limit, validation, looping, and an explicit stop/join/free sequence before
  every launcher exit or game handoff.
- The launcher still creates its `theme` directory automatically and accepts
  `theme/background.png` at exactly 1024x480. No copyrighted theme assets are
  included.

### Compatibility

- PR3/PR4 V3 `.smsghost` files remain compatible; no library reset is required.
- Settings, binds, PBs, Records, achievements, progress, and all prior PR2-PR4
  gameplay/customisation features remain intact.
- QFT timing, capture cadence, and result code are unchanged.

## 日本語

Pre-release 5 は、Pre-release 4 の実機テストで判明した input と Shine Select の
問題を修正する hardware-safety hotfix です。引き続き実験用 test build です。

### 応答する確認画面と PB ownership

- frozen director 内の input を、release-gated raw controller input に置き換えました。
  確認画面を開いた後は新しい press が必要で、JP／US／PAL で操作可能なままになります。
- PR4 の repeat-action warning の代わりに、見える未保存 PB 確認を復活させました。
  破棄につながる exit、warp、restart、savestate load、ghost target 変更は、受理済みの
  未保存 PB をすべて保存または明示的に破棄するまで続行しません。
- 受理済み PB ghost は record／playback buffer の promotion をまたぐ安定した runtime
  identity を持ちます。Save は PB を優先し、一致する storage ACK の成功時だけ保存済みに
  なります。
- Instant Restart で破棄した PB が phantom Save candidate として残る問題を修正しました。
- Ghost の Race／Watch chooser と Save／Delete confirmation にも同じ raw-input rule を
  適用しました。
- Ghost Display と Ghost Opacity を generic UI category から Ghosts tab の race-target
  controls の隣へ移動しました。

### Shine Select crash hotfix

- Watch camera branch を常時有効な JP／US／PAL patch manifest から削除しました。通常の
  gameplay と retail Shine Select intro は exact retail camera instruction を実行します。
- Watch が正常に開始した後だけ camera branch を install し、Watch stop／reset 時には
  exact regional retail word を復元します。

### Launcher の可読性と音楽

- 黒い launcher text に 8 方向の白い outline を追加しました。stock background と user
  panorama の両方で読みやすくなります。
- user 提供の `theme/bgm.mp3` を、4 MiB 上限、validation、loop、すべての launcher exit／
  game handoff 前の明示的な stop／join／free sequence 付きで復活させました。
- launcher は引き続き `theme` directory を自動作成し、正確に 1024x480 の
  `theme/background.png` を受け付けます。著作権のある theme asset は同梱しません。

### Compatibility

- PR3／PR4 の V3 `.smsghost` file は互換です。library reset は不要です。
- settings、binds、PB、Records、achievements、progress、および PR2-PR4 の既存機能は
  そのまま維持されます。
- QFT の timing、capture cadence、result code は変更していません。
