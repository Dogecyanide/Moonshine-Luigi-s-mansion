# Susamune V2.1.0 Pre-Release 2 "Hot Streak" Testing

This is the English development acceptance pass for Pre-Release 2. Japanese
translation is intentionally deferred until V2.1 feature and string freeze.

## Installation and data safety

1. Back up the eight files in `apps/susamune_launcher` before installing.
2. Hash `susamune.ini`, `susamune_ghosts`, PB/progress/Records journals,
   themes, BGM, backups, crash reports, and other user data.
3. Replace only the eight launcher-package files. Do not edit an ISO or any
   user-data path.
4. Confirm Homebrew Channel and the launcher identify the package as
   `Susamune Launcher DELTA` and
   `V2.1.0 Pre-Release 2 "Hot Streak"`.
5. Re-hash every preserved path after installation.

Existing settings remain authoritative. `Stage session display = Counter`
applies only when the new append-only setting has no saved value.

## Gate 1: menu and settings

- Confirm the retail top level is Shined, Settings, ILs, and Records.
- Open Settings and confirm its separators and these eight child pages:
  Practice, Savestate, Timer, Gameplay, Display, Cosmetics, Creation, Binds.
- Confirm ILs contains ILs, Ghosts, Stage Loader, and IL Segments.
- Confirm Creation opens normally from Settings and every nested page returns
  on a fresh B press without leaking input into gameplay.
- In Display, cycle Stage session display through Full notification, Counter,
  and Off. Close/reopen the menu and reboot once to verify persistence.

## Gate 2: playlist editor

- In Stage Loader mode, use C-stick up/down to move and left/right to jump
  catalogue worlds. A must append the selected IL without starting it.
- Add the same IL at least three times. All three occurrences must remain
  visible as separate ordered rows.
- Add routes from at least three worlds. Remove a middle occurrence with A and
  reorder two adjacent rows with C-stick left/right. No other row may change.
- Fill the playlist to 32 entries. A thirty-third add must be refused without
  corrupting the list.
- Clear the draft and confirm Run playlist refuses an empty list.

## Gate 3: playlist execution

- Run a playlist containing same-route duplicates and cross-world routes.
  Each exact eligible finish must advance exactly one position.
- Reset, die normally, finish ineligible, and interrupt an attempt. Each case
  must retry the same position, never skip or remove it.
- Open the menu during a run and edit the draft. The already-running playlist
  must retain its copied order; a later run must use the edited draft.
- Confirm Honey Skip and other death-finish ILs still count their authoritative
  result instead of being treated as an ordinary death.
- On final completion, show only the selected display feedback and end the
  running playlist after its brief completion notice.

## Gate 4: Streaking controls and display

- Switch the top Mode row to Streaking. Select an IL with A.
- Open Finishes with A. Verify the shared keyboard requires release after
  opening, accepts `1` through `999`, rejects blank/zero/non-numeric input,
  clears with Z, confirms with Start, and cancels with X+Start.
- Open Target time with A. Test blank, seconds, `M:SS.mmm`, invalid seconds,
  and the existing safe upper bound. X on the row must restore Any finish.
- In Counter mode, confirm a compact `current/goal` readout stays visible at
  the top-right default throughout the session and resets to zero on failure.
- In Full notification mode, confirm each outcome card is readable and never
  delays automatic retry. In Off mode, confirm retry/stats continue with no
  ordinary overlay.

## Gate 5: final streak report

- Complete a streak with several failures first. The final report must show
  the selected level, target or Any finish, final streak counter, qualifying
  completes/attempts, observed active time, successful average, and Golds `--`.
- The report is mandatory in Full, Counter, and Off modes.
- Holding A, B, or Start as the result arrives must not dismiss it. Release all
  report buttons, then press a fresh A, B, or Start to continue.
- Dismiss with B while D-up is held, and dismiss with B before pressing D-up.
  Instant Restart must remain disarmed until both B and D-up are released.
- The report must freeze gameplay without opening Pause, firing binds, opening
  Warp Wheel, loading a savestate, or accepting menu input.
- Finish with an unsaved protected PB, choose Save, and let its storage ACK
  complete while the result is pending. The PB flow must resolve first, then
  the streak report must appear without trapping the menu or controls.

## Gate 6: exit and lifecycle matrix

- Normal death, save-box Continue, a card error, ordinary Shine departure,
  secret/child transitions, and implicit retail exits must retain the session
  and return to its active route when safe.
- Pause Exit Area and Title must cancel the session, including when PB
  protection first requires Save or Discard.
- An IL-menu selection and a genuine Warp Wheel/chart course destination must
  cancel. A PB-rejected chart redirect must leave the session active.
- Current-area restart, full/parent restart, and Area Lock must retain it.
- Test a last-life game over. Record whether the pending session returns after
  the next direct stage; any hang, title-loop, or unsolicited destructive warp
  is a blocker.
- While a result is pending through death, save, loading, title, or a selector,
  confirm retail controls remain responsive. The report may capture input only
  after a live normal direct-stage frame exists.

## Gate 7: Creation and persistence

- In Settings > Creation, edit Stage session counter position and scale while
  viewing the live `3/5` preview. Confirm the same style is used by both modes.
- Save settings, reboot, and confirm the three new Creation keys persist.
- Verify the fixed Creation payload remains compatible with an existing PR1
  `susamune.ini`; all prior Creation layouts must be unchanged.

## Gate 8: regression and release blockers

- Test JP, US, and PAL on both console/Nintendont and Dolphin builds.
- Re-run ghost-format 25/25 and ghost-storage 18/18 tests.
- Verify QFT results, reset behavior, PB recording/protection, Ghost Watch,
  savestates, pause, Input Display, Records, achievements, and settings saves.
- Confirm every console blob is aligned at or below 0x50000 and every manifest
  retains 18 writes and a 0x82000 arena reservation.
- Stop on any stale stage pointer crash, load hang, QFT difference, heap warning,
  PB/ghost loss, settings reinterpretation, or SD write outside the established
  serialized services.
