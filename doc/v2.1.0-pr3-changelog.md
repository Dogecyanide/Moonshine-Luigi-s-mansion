# Susamune V2.1.0 Pre-Release 3 "Hot Streak"

Pre-Release 3 turns Stage Loader into a reusable route-planning tool and
corrects the exit lifecycle found during the first hardware playlist tests.
It includes the complete upstream V2.0.3 hotfix baseline.

## Stage Loader

- Playlist capacity is 120 entries. The same IL may appear more than once.
- Three built-in playlists are available: Fast Any%, All Secrets, and Reds
  World Tour.
- Seven custom playlists remain stored in the dual-generation SD journal.
- Fast Any% temporarily suppresses Fast Text for Pianta 5 only. The user's
  persisted Fast Text preference is never changed, and it becomes effective
  again as soon as that playlist position finishes or the session ends.
- Full notification, Counter, and Off now live in the Stage Loader menu.
- Completing a playlist opens the same session report used by Streaking.

## Exit and result lifecycle

- Exit Area now cancels an unfinished Stage Loader or Streaking session and
  returns through Sunshine's retail Exit Area path. It no longer substitutes
  a guarded course warp.
- Explicit Exit Area is an escape hatch even when Area Lock is enabled.
- Practice exits restore IL-owned flags first, then select the stable
  post-Corona Plaza. Practice warps into another level also reset the later
  retail Plaza return to post-Corona.
- A restart or other armed mod warp during a completed Shine demo waits behind
  the mandatory session report. The requested departure continues after the
  report and any threatened PB ghosts are handled.
- The report now uses eligible completes for `completes / attempts` and for
  average completion time. Golds remain reserved until segment grading lands.

## Persistence and compatibility

- Built-in playlists use compact generated route-ID tables and require no SD
  storage.
- Custom playlist V1 remains route-order-only. Loading a custom playlist does
  not inherit the built-in Fast Any% temporary action.
- No Settings IDs, bind IDs, IL IDs, achievement IDs, or existing disk fields
  were reordered. The Stage session display setting keeps its append-only ID.
- QFT timing sources are unchanged.
