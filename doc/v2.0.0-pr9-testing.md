# Susamune V2.0.0 "Ghosts of Delfino" Pre-release 9 Testing / テストガイド

## English

### Installation and identity

1. Back up the existing `susamune_launcher` folder and `susamune.ini`.
2. Install all eight files from the PR9 ZIP together. Do not mix mod binaries
   or `boot.dol` from another pre-release.
3. Confirm Homebrew Channel and the launcher both show
   `V2.0.0 "Ghosts of Delfino" Pre-release 9`.
4. Preserve the existing `theme`, `ghosts`, and import folders.

Run the PAL cases first, repeat the core cases on JP, and perform at least a US
smoke test when possible.

### 1. Ghost Display Off and menu controls

1. Set Ghost Display to Off.
2. Select a valid saved ghost and request Watch. Repeat separately for Watch 2
   after selecting a second ghost.
3. Expected: a warning appears, the action chooser closes, and selection lands
   on Ghost Display. The menu must remain fully responsive.
4. Press A. Ghost Display should turn On.
5. Confirm C-stick Left/Right wraps between the Ghost Library, Personal, and
   Imported section starts. C-stick Up/Down moves rows and A activates or
   changes the selected row.
6. Confirm L/R can change tabs and the configured menu button can close the
   menu after every rejected Watch request.

### 2. Secret-only Watch

Use known secret-only ghosts such as Bianco 3 Secret and Sirena 2 Secret.

1. Test Watch and Watch 2 with Shadow Mario primary, then Piantissimo primary.
2. Expected: the correct secret loads, the runner appears at the first recorded
   QFT, Mario remains invisible and cannot be controlled, and playback advances
   normally.
3. Exit once with B and once with Start. Mario must return visible and
   controllable in the correctly reloaded secret.
4. Repeat with Ghost Display toggled Off before launch; the Watch must not start
   until it is enabled.

### 3. Parent-to-child routes

Use a full route with at least two recorded segments, such as Bianco 3 to its
secret. Also test Sirena beach-to-hotel and a hotel/casino loading zone when a
matching ghost is available.

1. Start Watch and Watch 2 and let the invisible camera anchor follow the
   runner into the loading zone naturally.
2. Expected: no `Unexpected stage change` message. The exact next recorded
   segment loads, both ghosts reappear, and their QFT alignment is preserved
   across the recorded loading gap.
3. Test B/Start once during the transition and once after the child scene is
   live. Both must end Watch cleanly and restore normal play.
4. Force a different destination when practical. An unrelated scene must stop
   Watch safely, restore Mario, and must not leave intro-skip, bind suppression,
   Records suppression, or observer state active.

### 4. Normal-stage regression

1. Repeat Race, Watch, and Watch 2 in a normal level with both appearance
   choices and 25/50/75/100% opacity.
2. Confirm animation, model fallback, overlap, B/Start exit, completion reload,
   and fast-forward abort.
3. Confirm Watch grants no IL PB, Records result, achievement, or attempt-count
   credit. Normal play immediately after the cleanup reload must be eligible.
4. Far-separated runners may still make Sunshine's retail camera choose an
   awkward path; report regressions, but this is a known camera limitation.

### 5. Safety regression

1. Recheck retail Shine Select into Bianco 4, Bianco 5, and Pianta 5. Add one
   other episode if time permits.
2. Recheck the protected PB Save/Discard flow, including two unsaved PBs and a
   full personal library.
3. Recheck a savestate load, instant/full restart, Warp Wheel destination, and
   Exit Area after earning a PB.

If the Wii hard-crashes, leave it on the crash screen for about five seconds.
After reboot, preserve the newest/highest-generation
`susamune_crash_a.txt/.bin` or `susamune_crash_b.txt/.bin` pair from the
launcher-device root and send both files. A true exception-free hang may not
produce a report.

## 日本語

### インストールとバージョン確認

1. 現在の `susamune_launcher` フォルダーと `susamune.ini` をバックアップします。
2. PR9 ZIP の 8 ファイルを必ず一緒に導入します。他の pre-release の
   `boot.dol` や mod バイナリを混ぜないでください。
3. Homebrew Channel とランチャーの両方で
   `V2.0.0 "Ghosts of Delfino" Pre-release 9` と表示されることを確認します。
4. 既存の `theme`、`ghosts`、import フォルダーを保持してください。

まず PAL でテストし、主要項目を JP でも繰り返してください。可能なら US でも
最低限のスモークテストを行ってください。

### 1. Ghost Display Off とメニュー操作

1. Ghost Display を Off にします。
2. 有効な保存ゴーストで Watch を選びます。別に、2 つ目を選択して Watch 2 も
   試します。
3. 警告後にアクション選択が閉じ、Ghost Display 行へ戻ることを確認します。
   メニューが完全に操作可能でなければ失敗です。
4. A を押し、Ghost Display が On になることを確認します。
5. C スティック左右で Ghost Library、Personal、Imported の先頭へ循環移動し、
   上下で行移動、A で選択行を実行・変更できることを確認します。
6. Watch 拒否後も L/R のタブ移動と設定済みメニューボタンによる終了が使えることを
   確認します。

### 2. Secret 単独 Watch

Bianco 3 Secret、Sirena 2 Secret など、Secret 単独のゴーストを使用します。

1. Shadow Mario をメインにして Watch / Watch 2 を試し、次に Piantissimo を
   メインにして繰り返します。
2. 正しい Secret がロードされ、記録された最初の QFT でゴーストが表示され、
   Mario は透明かつ操作不能で、再生が正常に進むことを確認します。
3. B と Start でそれぞれ一度終了します。正しい Secret の再ロード後に Mario が
   表示され操作可能であることを確認します。
4. 起動前に Ghost Display を Off にした場合、有効化するまで Watch が開始しない
   ことを確認します。

### 3. 親ステージから子ステージへのルート

Bianco 3 から Secret など、2 セグメント以上の完全ルートを使用します。対応する
ゴーストがあれば Sirena のビーチからホテル、ホテル／カジノのローディングゾーンも
試してください。

1. Watch / Watch 2 を開始し、透明なカメラ用 Mario が自然にゴーストを追って
   ローディングゾーンへ入るまで待ちます。
2. `Unexpected stage change` が出ず、記録上の次セグメントが読み込まれ、両ゴーストが
   再表示され、記録されたロード区間をまたいで QFT が同期することを確認します。
3. 遷移中と子ステージ読み込み後に B / Start 終了を試します。どちらも安全に終了し、
   通常操作へ戻る必要があります。
4. 可能なら別の目的地への移動も試します。無関係なシーンでは Watch が安全に終了し、
   Mario が戻り、intro skip、bind 抑制、Records 抑制、observer 状態が残らないことを
   確認します。

### 4. 通常ステージの回帰テスト

1. 通常ステージで Race、Watch、Watch 2 を両方の外見と 25/50/75/100% 不透明度で
   繰り返します。
2. アニメーション、モデル fallback、重なり、B/Start 終了、完走後再ロード、
   fast-forward 中止を確認します。
3. Watch 中に IL PB、Records 結果、achievement、attempt count が加算されないこと、
   終了後の再ロードでは通常の記録が可能であることを確認します。
4. ゴースト同士が大きく離れると retail カメラが不自然な経路を選ぶ場合があります。
   悪化は報告してください。ただし現時点では既知の制限です。

### 5. 安全性の回帰テスト

1. retail Shine Select から Bianco 4、Bianco 5、Pianta 5 を再確認します。時間があれば
   もう 1 エピソード追加してください。
2. 2 つの未保存 PB と満杯の personal library を含め、PB の Save / Discard 保護を
   再確認します。
3. PB 後の savestate load、instant/full restart、Warp Wheel、Exit Area を再確認します。

Wii がハードクラッシュした場合、クラッシュ画面のまま約 5 秒待ってから電源を切ります。
再起動後、ランチャーデバイスのルートにある最新／最大 generation の
`susamune_crash_a.txt/.bin` または `susamune_crash_b.txt/.bin` のペアを保存し、
両方送ってください。CPU 例外を伴わない完全なハングではレポートが作られない場合があります。
