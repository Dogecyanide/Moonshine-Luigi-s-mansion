# Susamune V2.0.3 "Ghosts of Delfino" Testing / テストガイド

## English

This is the required Wii hardware acceptance pass for V2.0.3. Back up
`susamune.ini`, Records/PB data, and the Personal and Imported ghost folders.
Install every file from one package together. Homebrew Channel and the launcher
must both show `Susamune Launcher`, `V2.0.3 "Ghosts of Delfino"`, and the same
Build ID. Record the console region, game source, and result for every row.

### Gate 1: Yoshi visibility

1. Replay an existing V4 Yoshi ghost made before V2.0.3. Test Race, Watch, and
   Watch 2 through mount, sustained riding, and dismount. The mounted animation
   and a real Yoshi must both remain visible; the cyan marker is not acceptable.
2. With the current player's Yoshi still unhatched, replay that same ghost.
   Repeat after hatching and mounting the current player's Yoshi. The ghost
   Yoshi must render in both cases, and the current player's egg/Yoshi must not
   disappear, gain ghost colours, or retain changed shape visibility.
3. Record and replay fresh green, orange, purple, and pink Yoshi samples where
   each colour is available. Check position, yaw, rider pose, colour, and
   mount/dismount boundaries.
4. Use Watch 2 with two existing V4 Yoshi ghosts, then one Yoshi ghost paired
   with a fruit or spring ghost. Each runner must keep its own attachment and
   colour without flicker or a stale attachment.

### Gate 2: fruit and Noki spring attachments

1. Replay existing V4 coconut, papaya, pineapple, durian, and banana ghosts.
   Each fruit must still follow the correct right hand in Race, Watch, and
   Watch 2; release and identity changes must not leave a stale model.
2. In Noki Bay, record Mario carrying the exact `TJumpBase` spring, save it,
   reload it, and replay it in Race, Watch, and Watch 2. The spring must follow
   the correct ghost's right hand and must not substitute a fruit or another
   actor.
3. Replay a pre-V2.0.3 V4 spring recording. It must render without conversion or
   re-recording. If the exact spring source is unavailable in a replay scene,
   only the attachment must be hidden; playback must continue safely.
4. In Watch 2, exercise fruit-to-spring, spring-to-fruit, held-to-released, and
   two-spring combinations. No rebuild may crash, borrow a live actor, or attach
   one runner's model to the other.

### Known issue: Secret-only FLUDD invalidation

Hardware acceptance found that FLUDD use still does not reliably invalidate a
standalone Secret IL PB. This is a known, non-blocking V2.0.3 issue. Do not use
Susamune's saved Secret time as proof of a no-FLUDD run. Red-coin ILs and Full
routes remain eligible by design.

### Gate 4: rendering and release regressions

1. Test Mario, Piantissimo, Yoshi, every supported fruit, and the spring at
   `25%`, `50%`, `75%`, and `100%` Ghost opacity. The first three settings must
   be translucent; `100%` must be fully opaque. Repeat a mixed Watch 2 case.
2. Repeat stage transitions, direct-secret and parent-to-secret playback,
   B/Start cutscene skips, fresh B/Start exit, natural finish, and a safe failed
   route. Mario and the normal camera must always be restored.
3. Verify Personal slot 01 still shows its real name. Also retain the V2.0.2
   spaces-only fallback test: such a valid row must display `Unnamed ghost`
   without changing its duration, identity, actions, or delete target.
4. Exercise PB-save Ask/Auto-Save/Don't ask, full-library deletion, ordinary
   Race/Watch/Watch 2, Records, achievements, QFT, Warp Wheel, restarts,
   savestates, theme/BGM, and JP/US/PAL settings.
5. Perform an in-session reset/repatch and repeat one Yoshi, spring, fruit,
   standalone Secret, Reds, and Full check. Then cold boot and repeat the same
   smoke set. No stale model state or eligibility latch may survive.
6. Confirm the installed package and bundled `TESTING.md`/`CHANGELOG.md` identify
   V2.0.3 and contain no temporary ghost diagnostics or model-loader labels.

If the Wii raises a hard exception, leave the crash screen visible for about
five seconds before power-off. Preserve the newest matching
`susamune_crash_a.txt/.bin` or `susamune_crash_b.txt/.bin` pair from the root of
the launch device and mark that row failed.

## 日本語

これは V2.0.3 の必須 Wii 実機 acceptance test です。`susamune.ini`、Records／PB data、
Personal／Imported ghost folder を backup し、同じ package の全 file を一緒に導入します。
Homebrew Channel と launcher の両方が `Susamune Launcher`、
`V2.0.3 "Ghosts of Delfino"`、同じ Build ID を表示することを確認します。各 row で
console region、game source、結果を記録してください。

### Gate 1: Yoshi visibility

1. V2.0.3 より前に作成した既存 V4 Yoshi ghost を Race／Watch／Watch 2 で再生し、mount、
   riding、dismount を確認します。rider animation だけでなく実物 Yoshi も常に表示されること。
   cyan marker は不可です。
2. current player の Yoshi が unhatched の状態で同じ ghost を再生し、hatch／mount 後にも
   繰り返します。どちらも ghost Yoshi が表示され、player 側 egg／Yoshi が消える、ghost 色に
   なる、shape visibility の変更が残る、ということがないこと。
3. 可能な場所で green／orange／purple／pink Yoshi を新規 record／replay し、position、yaw、
   rider pose、colour、mount／dismount boundary を確認します。
4. Watch 2 で既存 V4 Yoshi ghost 2 体、次に Yoshi と fruit／spring の組み合わせを確認します。
   各 runner の attachment／colour が独立し、flicker や stale attachment がないこと。

### Gate 2: fruit／Noki spring attachment

1. 既存 V4 の coconut、papaya、pineapple、durian、banana ghost を再生し、Race／Watch／
   Watch 2 で正しい fruit が正しい右手に追従すること。release／identity change 後に stale model
   が残らないこと。
2. Noki Bay の exact `TJumpBase` spring を持って record／save／reload し、Race／Watch／
   Watch 2 で確認します。spring が正しい ghost の右手に追従し、fruit や別 actor に置換されないこと。
3. V2.0.3 より前の V4 spring recording も conversion／re-record なしで表示されること。replay
   scene に exact source がない場合は attachment だけを非表示にし、安全に playback を続けること。
4. Watch 2 で fruit→spring、spring→fruit、held→released、spring 2 個を確認し、rebuild 時に
   crash、live actor の借用、runner 間の attachment 入れ替わりがないこと。

### Known issue: standalone Secret の FLUDD invalidation

実機テストでは、FLUDD 使用後も standalone Secret IL PB が reliable に invalidate されません。
これは V2.0.3 の known／non-blocking issue です。Susamune の保存 time を no-FLUDD run の証明に
使用しないでください。Red-coin IL と Full route は仕様どおり eligible のままです。

### Gate 4: rendering／release regression

1. Mario、Piantissimo、Yoshi、対応する全 fruit、spring を Ghost opacity `25%`／`50%`／`75%`／
   `100%` で確認します。最初の 3 つは translucent、`100%` は fully opaque であること。mixed
   Watch 2 でも繰り返します。
2. stage transition、direct-secret／parent-to-secret、B／Start cutscene skip、fresh B／Start exit、
   natural finish、safe failed route を再確認し、Mario と通常 camera が必ず復元されること。
3. Personal slot 01 が実際の name を表示すること。V2.0.2 の spaces-only fallback も維持し、valid
   row が `Unnamed ghost` と表示されても duration、identity、action、delete target が変わらないこと。
4. PB-save Ask／Auto-Save／Don't ask、full-library deletion、通常 Race／Watch／Watch 2、Records、
   achievement、QFT、Warp Wheel、restart、savestate、theme／BGM、JP／US／PAL setting を確認します。
5. in-session reset／repatch 後に Yoshi、spring、fruit、standalone Secret、Reds、Full を 1 つずつ
   再確認します。cold boot 後にも同じ smoke set を行い、stale model state／eligibility latch が
   残らないこと。
6. installed package と bundled `TESTING.md`／`CHANGELOG.md` が V2.0.3 を示し、一時 ghost
   diagnostic／model-loader label がないこと。

hard exception 時は約 5 秒待って power-off し、launch device root の最新
`susamune_crash_a.txt/.bin` または `susamune_crash_b.txt/.bin` pair を保存して、その row を failed
と記録してください。
