# V2.0.0 "Ghosts of Delfino" Pre-release 2

## Ghosts / ゴースト

### English

- Replaced the cloned, sometimes-goopy Mario ghost with a visual-only model
  using the retail Shadow Mario silhouette from the tester's own disc or ISO.
- Ghost opacity now affects the complete 3D model instead of Mario's dirt
  effect. The cyan marker remains the safe fallback.
- Ghost movement uses an independent visual approximation instead of copying
  the current player's animation every frame.
- Fixed completed challengers remaining as the save target across many
  unrelated courses while another ghost was pinned.
- Added an exact-name warning before a manual course warp or retail Exit Area
  would discard an unsaved ghost. Delayed warps recheck ownership before exit.
- Pre-release 1 personal and imported `.smsghost` files remain compatible.

### 日本語

- 通常 Mario を複製した、ときどき goop 状態になる表示を廃止し、テスター自身の
  disc／ISO にある製品版 Shadow Mario の silhouette を使う見た目専用モデルへ
  変更しました。
- Ghost opacity が Mario の dirt 表現ではなく、3D モデル全体の透明度を変更する
  ようになりました。初期化できない場合は安全な cyan marker に戻ります。
- 現在の player animation を毎 frame コピーせず、独立した近似モーションで
  ゴーストを表示します。
- 別の ghost を pin している間、完走 challenger が無関係な course をまたいで
  長期間 save target に残る問題を修正しました。
- 手動 course warp または製品版 Exit Area で未保存 ghost が失われる場合、正確な
  名前を表示して確認します。待機中の warp は出発直前にも所有権を再確認します。
- Pre-release 1 の個人／imported `.smsghost` file は引き続き利用できます。

## Customization and launcher / カスタマイズとランチャー

### English

- Added horizontal standard-metadata layout.
- Expanded position and scale controls for Susamune notifications.
- Added independent Default/Always/Never controls for helmet, cap, shades,
  and Shine shirt.
- Added an option that disables the retail pause screen while preserving
  Start-based Susamune binds and editors.
- Added optional launcher themes using an exact 1024x480 `background.png` and
  a bounded `bgm.mp3`, with the stock background and silence as fallbacks.
- Updated the launcher and package branding to Pre-release 2 and added a full
  English/Japanese test guide.

### 日本語

- standard metadata の横並び layout を追加しました。
- Susamune notification の位置／scale 設定を拡張しました。
- helmet、cap、shades、Shine shirt に個別の Default／Always／Never 設定を
  追加しました。
- Start を使う Susamune bind／editor を維持したまま、製品版 pause 画面を無効に
  できる設定を追加しました。
- 正確な 1024x480 の `background.png` と、上限付き `bgm.mp3` を使う任意の
  launcher theme を追加しました。読み込めない場合は標準背景／無音に戻ります。
- launcher と package 表示を Pre-release 2 に更新し、英語／日本語の完全な
  test guide を追加しました。

## Gameplay fixes / ゲームプレイ修正

### English

- Sirena 8 practice now begins inside the hotel.
- Pinna EYG Full Restart returns to Pinna episode 3 on the beach instead of
  incorrectly loading Pinna 6.
- Speedup now invalidates IL, Records, and challenge eligibility.
- The configured Full Restart bind now works during death and the savebox.

### 日本語

- Sirena 8 practice が hotel 内部から開始するようになりました。
- Pinna EYG の Full Restart が誤って Pinna 6 を読み込まず、beach の Pinna
  episode 3 に戻るよう修正しました。
- speedup を使うと IL、Records、challenge の eligibility が無効になります。
- 設定済み Full Restart bind が death 中と savebox 中にも動作します。

## Important notes / 重要事項

### English

- This remains an experimental test build, not a release candidate.
- QFT timing and capture behavior were not changed.
- Shadow animation is an approximation; ghost files still record transforms,
  not full animation or gameplay state.
- Dolphin, CISO, and WiiVC may use the synchronized cyan fallback outside
  stages that already contain the native Shadow resource.

### 日本語

- 本ビルドは引き続き実験用であり、リリース候補ではありません。
- QFT の timing／capture 動作は変更していません。
- Shadow animation は近似です。ghost file は完全な animation／gameplay state
  ではなく transform を記録します。
- Dolphin、CISO、WiiVC では native Shadow resource が元からある stage 以外で、
  同期した cyan fallback を使用する場合があります。
