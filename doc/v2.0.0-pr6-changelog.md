# V2.0.0 "Ghosts of Delfino" Pre-release 6

## English

Pre-release 6 focuses on the remaining Shine Select crash, PB presentation,
and making Watch a proper route viewer. It remains an experimental test build.

### Shine Select and model lifetime safety

- Fixed two independent lifetime hazards in the native Shadow renderer. A new
  stage can no longer inherit a stale screen-texture pointer from the previous
  stage, and the loader-staged retail Shadow model is no longer modified and
  reused as if it were pristine.
- Retail Shadow and Piantissimo resources are copied from the user's own disc
  into a validated immutable MEM2 vault after the mod has been installed. Each
  stage receives a disposable Shadow working copy before its screen texture is
  attached.
- A missing or invalid model resource still fails safely to the 2D ghost marker.

### Route viewer and Piantissimo

- Watch and Watch 2 now warp to the first recorded route automatically. Mario
  remains an internal camera anchor, but is hidden, input-disabled, and excluded
  from movement while the retail camera follows the recorded runner.
- Multi-stage ghosts advance through their recorded routes. B, Start, or the end
  of the final segment stops the viewer and reloads the watched stage before
  normal play resumes.
- Watch does not add attempts, play/area time, deaths, achievements, or Attempt
  Counter results to the runner's persistent statistics.
- The cleanup reload arms a fresh normal attempt, so the first playable run
  after Watch can earn an IL PB normally.
- Added a `Ghost appearance` setting in the Ghosts tab. The primary/race ghost
  uses Shadow Mario or Piantissimo; Watch 2 uses the other model so the toggle
  swaps the two runners.
- The old Watch camera code patch is no longer needed for the route viewer.

### PB presentation

- An accepted unsaved-PB ghost remains protected, but Shine Get is allowed to
  finish its retail pose, camera, and result presentation before the confirmation
  appears on the final safe frame before departure.
- Explicit restarts, warps, IL starts, and savestate loads during the celebration
  still ask immediately because they would otherwise destroy the PB.

### Compatibility

- Existing PR3-PR5 V3 `.smsghost` files remain compatible; no library reset is
  required.
- Settings, binds, PBs, Records, achievements, progress, launcher panorama, and
  `bgm.mp3` remain compatible.
- QFT timing, capture cadence, and result code are unchanged.

## 日本語

Pre-release 6 は、残っていた Shine Select crash、PB presentation、そして Watch を
proper route viewer にすることに集中した build です。引き続き実験用 test build です。

### Shine Select と model lifetime safety

- native Shadow renderer にあった 2 つの独立した lifetime hazard を修正しました。新しい
  stage が前 stage の stale screen-texture pointer を引き継ぐことはなく、loader が stage
  した retail Shadow model を変更後に pristine data として再利用することもありません。
- user 自身の disc から取り出した retail Shadow と Piantissimo resource を、mod install
  後に validated immutable MEM2 vault へ copy します。各 stage は screen texture を付ける
  前に disposable Shadow working copy を受け取ります。
- model resource が missing／invalid の場合も、安全に 2D ghost marker へ fallback します。

### Route viewer と Piantissimo

- Watch／Watch 2 は最初の recorded route へ自動で warp します。Mario は内部 camera
  anchor として残りますが、hidden、input-disabled、movement excluded の状態になり、retail
  camera が recorded runner を追います。
- multi-stage ghost は recorded route を順番に進みます。B、Start、または final segment の
  end で viewer を停止し、normal play に戻る前に watched stage を reload します。
- Watch は runner の persistent statistics に attempts、play／area time、deaths、
  achievements、Attempt Counter result を加算しません。
- cleanup reload は fresh normal attempt を arm するため、Watch 後の最初の playable run
  でも通常どおり IL PB を獲得できます。
- Ghosts tab に `Ghost appearance` setting を追加しました。primary／race ghost は Shadow
  Mario または Piantissimo を使い、Watch 2 の runner 2 は反対側の model を使うため、toggle
  で 2 人を入れ替えられます。
- route viewer では以前の Watch camera code patch は不要になりました。

### PB presentation

- 受理済み未保存 PB ghost の保護は維持しながら、retail Shine Get の pose、camera、result
  presentation を最後まで表示し、departure 前の最後の安全な frame で confirmation を
  開くようにしました。
- celebration 中の explicit restart、warp、IL start、savestate load は、PB を破棄する
  action のため引き続き即座に確認します。

### Compatibility

- 既存 PR3-PR5 V3 `.smsghost` file は互換です。library reset は不要です。
- settings、binds、PB、Records、achievements、progress、launcher panorama、`bgm.mp3` は
  互換です。
- QFT の timing、capture cadence、result code は変更していません。
