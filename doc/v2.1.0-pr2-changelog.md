# Susamune V2.1.0 Pre-Release 2 "Hot Streak"

Pre-Release 2 turns the first Hot Streak prototype into two distinct practice
tools: an ordered Stage Loader playlist and a single-level Streaking session.
This remains an English development build. Japanese translation is deferred
until the V2.1 feature and string freeze.

## V2.0.3 foundation

- Pre-Release 2 now includes the complete upstream V2.0.3 hardware hotfix.
  This brings forward V4 ghost capture and validation, Yoshi and supported
  held-object playback, the Noki Bay spring attachment, Watch camera fixes,
  protected-PB save policies, and its other release fixes.
- Existing V3 and V4 ghosts remain compatible. The QFT implementation and time
  source are unchanged.
- V2.0.3 reserves part of the reset-replayed mod staging window for ghost
  attachments. The unchanged `0x50000` MEM1 working cap is now constrained by
  the stricter `0x3F000` packed-file ceiling; the build derives the exact code
  limit after header and hook-write overhead.

## Stage Loader playlists

- Stage Loader now queues up to 120 IL routes and runs them once in their shown
  order.
- The same route may appear more than once. Every occurrence is a distinct
  playlist position.
- A successful finish advances one position. A reset, ineligible result,
  wrong finish, interrupted attempt, or canceled internal warp retries the
  current position instead of skipping it.
- The editable draft and the running playlist are separate fixed buffers, so
  menu edits cannot mutate an active run.
- Seven custom playlists can be saved to and loaded from the launcher device.
  Each holds up to 120 route IDs in a CRC-checked alternating A/B journal. A
  missing file starts empty; a recognized future version disables writes
  instead of overwriting it.
- The catalogue uses the IL page's grouped navigation: C-stick up/down moves,
  C-stick left/right jumps worlds, and A adds or selects. Playlist rows can be
  removed with A and reordered with C-stick left/right.

## Streak sessions and results

- Streaking remains one selected IL with a keyboard-entered finish count and
  optional target time.
- A new display preference offers Full notification, Counter, and Off.
  Counter is the fresh-install default and remains visible at its Creation
  position throughout the session.
- Completing a streak opens a release-gated result screen with the level,
  target, final streak, qualifying completes/attempts, observed active QFT
  time, successful average time, and a reserved Golds field.
- The result screen observes the existing QFT clock and exact IL result; it
  does not own or modify timing.

## Exit behavior

- Deaths, save dialogs, ordinary retail departures, and route failures retain
  the session and return to the active playlist/streak route when the retail
  lifecycle is safe.
- Explicit IL selections, course Warp Wheel/chart destinations, Pause Exit
  Area, and Title end the session immediately.
- Pause Exit Area now restores temporary IL state atomically and always routes
  to post-Corona Plaza unless Area Lock intentionally replaces the exit. It no
  longer carries dry/flooded Plaza state from an earlier practice launch.
- Current-area and parent-area restart commands retain the session.
- A restart pressed on the same frame as the authoritative final IL result is
  deferred until after result processing. The finish wins and the restart edge
  is discarded; ordinary mid-attempt restarts still work normally.
- PB protection remains authoritative. No destructive warp is released before
  its threatened PB tokens are resolved.

## Menu and Creation

- Creation is now an option inside Settings instead of a top-level tab.
- Settings has nonselectable section separators for practice/gameplay,
  presentation, and tools/controls.
- Creation adds a Stage session counter editor with a live `3/5` preview and
  position/scale controls shared by Stage Loader and Streaking.
- The development package remains Susamune Launcher DELTA. Durable paths,
  magic values, and launcher directory names remain unchanged so a future
  product rename does not strand user data.

## Memory and persistence

- The Stage Loader runtime occupies 72 bytes of its existing 256-byte MEM2
  slot. Its 120-entry editable and active queues occupy one new fixed 256-byte
  MEM2 block after the crash mailbox. Neither uses heap allocation.
- Custom playlists use two 896-byte files on SD (1,792 bytes total). The
  mailbox occupies 928 bytes in the established configuration gap before the
  Records progress mailbox; all boundaries and cache-line ownership are
  compile-time checked.
- The counter style consumes the final seven reserved bytes of the existing
  576-byte Creation block; its size and all earlier field offsets are unchanged.
- The Stage Loader display setting keeps its original PR2 append-only ID. The
  merged V2.0.3 PB-save policy is appended after it; existing keyed ini values
  retain their meaning.
- The 0x80000 MEM1 region, 0x82000 arena reservation, and 0x40 scratch tail
  remain unchanged. With 18 hook writes, the reset-safe packed-file layout
  currently enforces a stricter `0x3EF50` code ceiling.
