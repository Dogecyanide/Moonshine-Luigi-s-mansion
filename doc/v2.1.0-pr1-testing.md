# Susamune V2.1.0 Pre-Release 1 "Hot Streak" Testing

This is the English development acceptance pass for Pre-Release 1. Japanese
translation is intentionally deferred until V2.1 feature and string freeze.

## Installation and data safety

1. Back up the eight files in apps/susamune_launcher.
2. Hash susamune.ini, susamune_ghosts, PB/progress/Records journals,
   themes, custom BGM, backups, and crash reports before installing.
3. Replace only the eight launcher-package files. Do not replace or edit user
   data, ISOs, or unrelated Homebrew Channel apps.
4. Confirm Homebrew Channel and the launch screen show
   Susamune Launcher DELTA and
   V2.1.0 Pre-Release 1 "Hot Streak".
5. Re-hash every preserved path and confirm it is unchanged.

Existing susamune.ini choices remain authoritative. The new OFF defaults below
apply only where no saved value exists.

## Gate 1: menu hierarchy

Confirm the retail top level is:

Shined | Settings | ILs | Creation | Records

Confirm Settings contains, in order:

Practice | Savestate | Timer | Gameplay | Display | Cosmetics | Binds

Confirm ILs contains, in order:

ILs | Ghosts | Stage Loader | IL Segments

- A opens a nested page and B returns to its parent.
- L/R still changes top-level tabs.
- Creation remains a distinct, easily accessible top-level page.
- In Binds, A records, X clears, B returns, and C-stick cancels recording.
- Exercise every existing modal editor and Ghost/PB confirmation. Modal input
  must not leak into parent navigation or configured binds.
- Trigger protected-PB handling from an IL warp while another IL child is
  selected. It must open directly at ILs > Ghosts and resume the exact held
  warp only after every threatened PB is saved or discarded.

## Gate 2: Stage Loader

1. Open ILs > Stage Loader.
2. Leave Mode on Stageloader; choose representative routes from every world
   and from direct/internal/loading-zone groups.
3. A must use the same guarded two-phase warp as the existing IL list. Verify
   exact parent episode, overlay, nozzle, and Plaza variants.
4. With an unsaved PB present, verify the sequential Save/Discard barrier
   before the selected route can start.
5. Verify disabled warps refuse the request without changing stage or session
   state.

## Gate 3: Streaking

1. Change Mode to Streaking.
2. Set Finishes to 1, 5, and 99; verify left/right wrap at the endpoints.
3. Open Target time. Test blank, 45, 45.500, and 1:23.456.
   START keeps a valid value, X+START cancels, Z clears, and invalid text stays
   in the editor with an error message.
4. With a blank target, finish the exact selected IL repeatedly. Each eligible
   finish increments once, shows a clear result card, waits about 1.5 seconds,
   and then uses the guarded IL start path again.
5. At the requested count, the card must say Complete and no further retry may
   arm.
6. With a target, test one result at/below the threshold and one above it.
   The first increments; the second resets the displayed streak to 0.
7. Test death/reset, wrong-route finish, Intro Skip, Fast Forward, savestate
   load, and observer-assisted play. None may earn a streak finish.
8. During result, Shine Get/demo, loading, selector, pause/save UI, and a PB
   prompt, retry must remain held. It may arm only in direct-stage context with
   a live director, _260 != 0, normal state, no demo, and no open mod overlay.
9. Switch back to Stageloader and launch once. The prior streak must be
   cancelled and must not pull the player back to its old route.

## Gate 4: defaults and regressions

With a fresh configuration, confirm Input Display, Recent IL history, and QFT
section history start Off. Confirm Sunshine timer, PB fanfare, IL PB recording,
and achievement notifications remain On.

Then run the V2.0 blocker smoke:

- Watch intro release-gating and fresh B/Start exit.
- Exact route playback through a loading zone.
- Ghost Save/Delete/Race/Watch/Watch 2 and storage failure recovery.
- Savestate save/load and every exit/failure restoration path.
- Shine Select, stage intro/materialise, pause/save UI, title return, and reset.
- JP, US, and PAL boot plus region-specific settings/PB loading.

Report the displayed Build ID, disc region, launch device, game device, and any
crash-report pair for every failure.
