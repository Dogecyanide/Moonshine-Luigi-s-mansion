# Susamune V1.2.0 Pre-Release 2

**Trial By Sunshine - ALPHA**

This test build focuses on making the Records prototype practical to verify.

## Changes since Pre-Release 1

- Achievements now open through Times, Challenges, Practice Craft, and Course
  Mastery categories.
- Eight deliberately easy alpha calibration achievements were appended as
  persistent IDs 6-13, bringing the prototype catalog to 14. These IDs must
  never be reordered, deleted, or repurposed, even if the test entries are
  later retired.
- Dirty console progress checkpoints after one minute, on app-context exit,
  and when the normalized course bucket changes. Restarts and internal scenes
  in the same course do not add writes. This reduces the unsaved tail that made
  regional attempts and deaths look stale; the journal layout is unchanged.
- Total Playtime now counts the whole boot session, including logos, title,
  loading, menus, and gameplay. Course and Creation time remain context-bound.
- JP now uses font-safe slash and star glyphs in Records and favourites.
- The configured Close Menu bind now works from nested Records pages.
- B+DUp keep-entry restart is back to a one-frame trigger. B+Z+DUp
  full/default restart remains a two-frame trigger.
- Compact QFT's live presentation is shifted back by one visual frame to match
  the native HUD. Core QFT timing, frozen values, results, PBs, and achievement
  thresholds are unchanged.
- The `Starred` settings tab is now named `Shined`. This changes only the label;
  saved favourites and their behavior are unchanged.

Achievement unlock sounds remain out of scope for this alpha. Dolphin Records
remain session-only; console progress continues to use the two-copy global
journal.
