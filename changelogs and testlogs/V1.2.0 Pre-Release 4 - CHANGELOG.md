# Susamune V1.2.0 Pre-Release 4

**Trial By Sunshine - ALPHA**

Pre-Release 4 is a focused correction pass over PR3. The active catalog is now
103 achievements after retiring a challenge that cannot be completed in every
supported region; no tiers, targets, or categories were added.

## Changes since Pre-Release 3

- Streak achievement rows now show live progress such as `0 / 5` and `2 / 5`.
- Streak continuity now follows completed IL results. This fixes routes whose
  starting entry differs from their result entry, especially GBS from Gelato 1
  and Ricco 100 from Ricco 3.
- Instant Restart after a recorded result no longer clears the streak. Deaths,
  abandoned or invalid attempts, savestate loads, and nonmatching completed ILs
  still break an unfinished streak.
- **NoHover** now has its intended rule: fruit is allowed, while Hover and
  Yoshi invalidate the attempt. Its menu requirement was corrected to match.
- **Hot Tub** is restricted to Corona Mountain and correctly re-arms after a
  genuine fresh restart. Savestate loading still invalidates it.
- Added `Misc > RESET > Reset Records` with two confirmations. It clears all
  achievements, streak progress, and JP/US/PAL Records statistics, then commits
  both copies of the console progress journal. It preserves PBs, settings,
  binds, and Creation layouts.
- Factory Reset continues to reset settings, binds, and layouts while
  preserving PBs and Records.

Because PB files are preserved, PB-derived achievements may return at boot or
PB-profile reconciliation after Reset Records. This is expected. QFT timing
and presentation code are unchanged in this build.
