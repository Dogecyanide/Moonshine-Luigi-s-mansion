# Susamune V1.2.0 — Trial By Sunshine

V1.2.0 is the rewards and recognition update. It adds a persistent achievement
system, a Records and statistics area, world-level PB summaries, and a large
launch catalog built around speed, consistency, challenge runs, course mastery,
and long-term milestones.

## Achievements

- Added **123 active achievements** across five categories:
  - 39 Times
  - 9 Challenges
  - 28 Course Mastery
  - 26 Streaks
  - 21 Special
- Added Bronze, Silver, Gold, Diamond, Demon, and Frontier tiers.
- Added tier-coloured unlock banners and a lightweight achievement chime.
- Added a default-on `Achievement notifications` option to the Records root.
  It controls only the unlock popup and chime; achievements still unlock,
  persist, and count toward Records while notifications are off. Any queued
  notifications are discarded while off, so re-enabling it cannot cause a
  delayed burst.
- Achievement notifications queue when several unlock at once. The chime is
  suppressed when a PB fanfare is already playing, while every banner still
  appears.
- Achievement details show the exact requirement when selected.
- Tier separators make long category lists easier to scan.
- Streak achievements show live progress such as `3 / 5` and reset on a failed,
  abandoned, invalid, or different IL.
- Stage Intro Skip and savestate loads invalidate timed/challenge achievement
  attempts. A savestate save alone does not invalidate an attempt.
- Added support for native-IGT achievements. These validate the completed IL and
  unlock on Shine collection after the in-game timer has stopped.
- Fixed native-IGT result capture to use each retail revision's finished timer.
  This corrects remaining-time achievements such as Hero of the Village and
  Surfin' Delfino on JP and avoids relying on unrelated timer fields elsewhere.
- Achievement IDs are append-only so unlocks survive catalog expansion. The
  retired region-incompatible challenge remains a hidden tombstone and is not
  included in the total.

## Records and statistics

- Added global and per-region statistics for:
  - Total playtime
  - Attempts
  - ILs finished and success rate
  - PBs earned
  - Deaths
  - Time spent in Creation
- Added world pages for Bianco, Ricco, Gelato, Pinna, Sirena, Noki, Pianta, and
  Delfino. Airstrip and Corona are folded into Delfino.
- World pages show time, attempts, finishes, completion rate, Any% PB sum, and
  All-IL PB sum. PB summaries use the current region and active PB profile.
- Total playtime now covers the whole running game rather than only live stages.
- Added `Reset Records` with confirmation. It clears statistics, achievements,
  and live streaks while preserving PBs, settings, binds, and Creation layouts.
- Factory Reset continues to reset configuration while preserving PBs and
  Records.

## Persistence

- Added a dedicated two-generation progress journal shared by achievements and
  statistics.
- On Wii/Nintendont, Records progress is shared across JP, US, and PAL when the
  same launcher device is used. Regional counters remain individually viewable.
- Progress checkpoints periodically and on meaningful scene/context changes.
- Existing qualifying PBs can silently backfill compatible achievements.
- Dolphin Records persistence remains session-only in V1.2.0; ordinary regional
  PB persistence is unchanged.

## Interface and practice polish

- Renamed the old Starred menu to **Shined**.
- Added nested Records, achievement, category, and world-stat menus.
- Records now sits immediately before Binds in the main tab order.
- Added `Creation > Mod Menu > Achievement popup` for changing the unlock
  banner's position and size. Tier colours remain fixed and cannot be edited;
  the preview remains visible while achievement notifications are disabled.
  Position and size persist with the other Creation layouts.
- Closing the menu works from nested Records pages.
- Fixed missing JP achievement/Shined markers and the JP achievement-count slash.
- Replaced unsupported western down-arrow and percent glyph usage with safe text.
- Made the tab strip deterministic instead of retaining a confusing historical
  scroll position.
- Restored one-frame `B + D-Up` Instant Restart input while keeping
  `B + Z + D-Up` at two frames.
- Corrected the live compact-QFT presentation being visually one frame ahead.
  QFT measurement, stored results, PBs, freeze behavior, and timing thresholds
  were not changed.

## Challenge and streak groundwork

- Added shared tracking for consecutive IL results, native countdown timers,
  hover/Yoshi use, stage and result origins, world totals, multi-profile PB
  coverage, and safe invalidation.
- Fixed result aliases so Gelato 8/GBS and other alternate entry routes feed the
  correct streak.
- Added validated stage-specific challenges including Exterminator, Hot Tub,
  NoHover, Mashathon, and Deja Vu.
- NoHover correctly allows fruit and forbids Hover or Yoshi while completing GBS
  from Gelato 1.

## Build and distribution

- Finalized the launcher as **Susamune Launcher**; ALPHA/RC branding has been
  removed from the public V1.2.0 build.
- Updated ISO layout metadata and BPS generation for current JP/US/PAL hooks.
- Release automation now builds from the immutable release tag.
- All release targets fit the 128 KiB V1.x mod region; the tightest target keeps
  1,508 bytes of headroom.
- Final raw console blobs are JP **128,024**, US **127,868**, and PAL
  **127,948** bytes, leaving 2,984 / 3,140 / 3,060 bytes free. Compared with
  V1.1.0, the final deltas are +10,160 / +10,076 / +10,068 bytes.
- Final raw Dolphin blobs are JP **129,500**, US **129,300**, and PAL
  **129,436** bytes, leaving 1,508 / 1,708 / 1,572 bytes free.
- Final launcher Build ID: **FAB0A9D2**. Artifact hashes are reported alongside
  the release.
