## Accepted alpha limitation

Stage Intro Skip eligibility is sampled when an IL finishes, matching the
existing PB policy. Turning Intro Skip off after using it can therefore make
that attempt eligible. This is recorded as a P2 alpha edge, not a new Pre2
regression. Savestate loading hard-disarms the attempt and cannot earn a PB or
achievement.

The separate V1.1 GitHub emulator-BPS failure remains an ISO-layout metadata
issue and is not part of this Wii launcher test build.
